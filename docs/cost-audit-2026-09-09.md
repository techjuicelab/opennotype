## 사용 시나리오

**실사용 측정값이 아닌 가정에 따른 예시**입니다. 월 30일, 녹음 1회 1분, 매회 전체 입력 2,000토큰(공통 지침 등 포함)·출력 400토큰, 재시도 없음으로 계산했습니다. 발화량, 녹음 횟수, 사전 크기, 선택 원문 길이에 따라 달라집니다.

| 하루 녹음 | 월 녹음 | 음성 인식 | 문장 정리 | 합계 예시 |
| --- | --- | --- | --- | --- |
| 10분 | 300분 | $1.35 | $0.43 | **$1.78** |
| 30분 | 900분 | $4.05 | $1.30 | **$5.35** |
| 60분 | 1800분 | $8.10 | $2.59 | **$10.69** |

계산식:

- 월 음성 인식 예시 = 월 녹음 분 × 0.0045달러
- 문장 정리 1회 예시 = (2,000 × 0.40 + 400 × 1.60) ÷ 1,000,000 = 0.00144달러
- 월 합계 예시 = 음성 인식 예시 + 호출 횟수 × 0.00144달러

1분씩 나누지 않는 실제 사용에서는 녹음 총시간과 문장 정리 호출 횟수를 따로 계산해야 합니다. 짧게 자주 호출하면 고정 지침도 매번 입력으로 전송됩니다. 캐시 입력을 계측할 때는 전체 입력에서 캐시 입력을 빼고 각각의 단가를 적용해야 합니다.

로컬 음성 인식으로 바꾸면 음성 인식 API 요금은 없어지지만 문장 정리 API 비용과 로컬 연산·전력 비용은 남습니다. 위와 같은 텍스트 사용량이라면 하루 30분 예시의 API 비용은 월 약 $1.30입니다. 실제 로컬 전사 품질·속도와 입력 토큰량은 별도 평가가 필요합니다.

참고로 공식 표의 `gpt-4o-mini-transcribe`는 분당 $0.003입니다. 하루 30분·월 30일에서 현재 전사 모델 대비 절약되는 음성 비용은 월 $1.35입니다. 이 숫자가 전사 품질 동등성을 의미하지는 않습니다.

HTTP 요청 횟수가 실제 청구 횟수와 항상 같지는 않습니다. 취소·네트워크 오류·출력 형식 검증 실패도 무료였다고 단정할 수 없습니다. 응답을 받지 못한 요청은 비용 미확인으로 다뤄야 합니다.

1. **사용량 계측:** 음성/텍스트 단계, 제공자, 요청 모델과 실제 응답 모델, 요청 식별자, 음성 길이, 입력·캐시·출력 토큰, 성공·실패·취소·재시도 상태를 기록합니다. 출력 검증 실패 전에 메타데이터를 수집합니다.
2. **내용 없는 비용 장부:** 개인 녹음이나 원문 없이 사용량만 따로 저장해, 텍스트 기록을 꺼도 비용 기록이 사라지지 않게 합니다. 과거 기록은 0원이 아닌 집계 시작 전으로 표시합니다.
3. **화면:** 홈에는 오늘/이번 달 예상 비용과 사용 시간, 상세에는 음성 인식·문장 정리 비용 및 비용 미확인 요청 수를 표시합니다. 금액은 제공자 청구액과 구별하고 요금표 기준 날짜를 남깁니다.
4. **절감:** 실패한 단계부터 재처리하는 방식과 사전 전송량을 먼저 검토합니다. 중간 전사문을 저장한다면 암호화·보관 기간·기록 설정과의 관계도 설계해야 합니다.
5. **예산:** 필요하면 전용 OpenAI 프로젝트의 월 한도와 알림을 설정합니다. 계정이나 한도는 이번 점검에서 변경하지 않았습니다.

[공식 지출 한도 문서](https://developers.openai.com/api/docs/guides/spend-limits)에 따르면 알림은 요청을 중단시키지 않으며, hard spend limit은 한도 도달 시 429로 요청을 중단합니다. 적용 지연으로 설정 금액을 소폭 초과할 수 있습니다. 앱 내부 비용 추정과 계정 전체 청구 한도는 별개입니다.
