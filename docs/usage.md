# 사용량과 비용 통계

OpenNoType의 **사용량** 화면은 이 Mac에서 이 앱으로 처리한 음성과 API 요청을 모델별로 보여 줍니다. 공급자의 계정 전체 청구 내역을 가져오는 기능은 아닙니다.

이 문서는 2026-09-10 구현과 해당 빌드의 가격표를 기준으로 합니다. 통계를 지원하는 버전에서 **사용량 통계 기록**이 켜진 뒤의 요청부터 기록합니다. 설정의 기본값은 켜짐이며, 이전 버전의 문장 기록에서 과거 토큰이나 비용을 추측해 복원하지 않습니다. 다른 Mac, 다른 앱, 공급자 웹사이트에서 사용한 요청도 포함하지 않습니다.

## 화면에서 확인할 수 있는 내용

사이드바의 **사용량**을 열면 다음 내용을 확인할 수 있습니다.

- 조회 기간: 최근 7일, 이번 달, 전체 기록. 날짜 경계는 Mac의 현재 달력을 사용합니다.
- 제공자: OpenAI, Groq, OpenRouter, Claude 또는 이 Mac의 로컬 처리.
- 확인 가능한 비용: 공급자 보고 금액과 단가 기반 추정 금액의 합계, 금액을 확인하지 못한 요청 수.
- API 요청 수, 작업 수, 자동 재시도 수, 음성 처리 길이, 집계된 입력·출력 토큰.
- 제공자·응답 모델·처리 단계별 사용량. 음성 인식과 문장 처리는 별도로 묶습니다.
- 일별 처리 활동: 선택한 조건 중 최대 최근 30일. 전체 기록을 선택해도 차트의 범위만 30일이며 합계에는 보관된 전체 기록이 반영됩니다.
- 최근 요청 최대 20개: 요청별 상태, 비용 구분, 토큰 세부 항목, 단가 확인일과 비용 근거 링크.

응답이 요청한 모델 별칭과 다른 모델명을 알려 주면 **응답 모델**로 집계하고, 요청 상세에는 원래 요청 모델도 표시합니다. 모델명이 응답에 없으면 요청한 모델명을 사용합니다.

## 비용 표시의 네 가지 의미

| 표시 | 계산 기준 | 읽는 방법 |
| --- | --- | --- |
| 공급자 보고 | API 응답이 알려 준 요청별 금액. 현재 수집 경로는 OpenRouter의 `usage.cost`입니다. | 해당 요청에 보고된 금액이며 계정 전체 청구액과는 구분합니다. |
| 추정 | 확인된 모델의 공개 단가와 응답 토큰 또는 제출한 음성 길이로 계산합니다. | 무료 한도, 계정별 할인 등을 적용하기 전의 참고 금액입니다. |
| 미확인 | 비용 응답이 없고 적용할 단가·사용량·과금 항목을 충분히 확인할 수 없습니다. | 0원이 아닙니다. 비용 합계에서 제외하고 미확인 요청 수에 포함합니다. |
| 로컬 · API 비용 없음 | 이 Mac에서 수행한 로컬 음성 인식입니다. | 그 단계의 API 비용은 0입니다. 이어지는 클라우드 문장 처리 비용은 별도입니다. |

**확인 가능한 비용**에는 공급자 보고 금액과 추정 금액만 더합니다. 누락된 비용이 있을 때 이 합계가 실제 사용액 전체라고 해석하면 안 됩니다. 소액도 0처럼 보이지 않도록 0보다 크고 US$0.0001보다 작은 금액은 `< US$0.0001`로 표시합니다.

OpenRouter는 응답에 사용량 정보를 자동 포함하므로 통계 수집만을 위한 추가 API 요청을 만들지 않습니다. 응답에 비용이 없으면 기반 모델의 직접 API 가격을 가져와 대신 계산하지 않습니다. [OpenRouter 사용량 명세](https://openrouter.ai/docs/cookbook/administration/usage-accounting)

## 요청·재시도·음성 길이 계산

한 번의 받아쓰기 작업에도 클라우드 음성 인식과 문장 처리라는 두 요청이 생길 수 있습니다. 로컬 음성 인식을 사용하면 로컬 처리 한 건과 클라우드 문장 처리 한 건으로 기록하며, **API 요청 수**에는 클라우드 요청만 포함합니다. 로컬 모델 다운로드와 화자 필터 준비·목소리 등록은 현재 사용량 집계 대상에 포함하지 않습니다.

- 실제로 시작한 HTTP 요청마다 별도 기록을 만듭니다. 요청 전 로컬 유효성 검사에서 중단된 경우는 API 요청으로 세지 않습니다.
- 자동 재시도도 추가 요청으로 셉니다. 현재 전송 코드는 일시적인 `429`, `502`, `503`, `504` 응답에 한해 짧은 대기가 가능하면 한 번 더 시도합니다. 연결 실패로 처리 여부가 불명확한 요청은 자동 재전송하지 않습니다.
- **다시 처리**에서 사용자가 실행한 복구는 새 작업입니다. 원래 실패한 작업의 비용을 덮어쓰거나 취소하지 않습니다.
- 음성 처리 길이는 응답의 음성 길이가 있으면 그 값을, 없으면 실제 제출한 음성 파일의 길이를 사용합니다. 화자 필터가 적용된 클라우드 요청은 필터를 거친 파일 기준입니다. 로컬 음성 인식은 실제 처리한 파일 또는 PCM 길이를 사용합니다.
- 음성 길이 합계에는 재시도와 다시 처리가 포함됩니다. 따라서 사용자가 처음 녹음한 고유 시간보다 길어질 수 있습니다. 실패 요청의 제출 길이를 기록해도 그만큼 청구되었다고 확정하지 않습니다.

HTTP 응답을 받으면 사용량을 먼저 저장한 뒤 생성된 문장의 형식을 확인합니다. 따라서 응답 텍스트가 잘못되어 결과를 거부했거나, 음성 인식 뒤 문장 처리가 실패했어도 이미 확인된 사용량은 남습니다. **응답 수신**은 정상 HTTP 응답을 받았다는 뜻이며, 문장 생성·자동 입력까지 모두 성공했다는 뜻은 아닙니다.

취소·연결 실패도 시작된 요청이면 기록합니다. 서버에서 이미 처리했는지 알 수 없는 경우 비용은 미확인으로 남깁니다. 취소 직전에 받은 사용량은 저장을 마친 뒤 취소를 처리하며, 공급자가 금액을 직접 보고했다면 실패 상태라도 그 금액을 보존합니다. 앱이 강제 종료되어 응답을 받지 못한 요청의 사용량을 나중에 공급자에서 복원하는 기능은 없습니다.

## 토큰 세부 항목

토큰 수는 공급자가 응답한 수치만 사용합니다. 미제공 항목은 **미제공**으로 표시하며 문장 길이로 추측하지 않습니다. `null`, 참·거짓, 음수, 소수 토큰, 유한하지 않은 수와 숫자 문자열은 유효한 토큰으로 받아들이지 않습니다. 명시적으로 보고된 0은 0으로 유지합니다.

| 제공자·경로 | 수집하는 정보 |
| --- | --- |
| OpenAI Responses | 입력·출력 토큰, 입력 중 캐시 읽기·쓰기, 출력 중 추론 토큰 |
| OpenAI 음성 인식 | 응답에 따라 음성 초 또는 입력·출력 토큰과 입력 중 오디오 토큰 |
| Groq | `usage`, 또는 제공될 경우 `x_groq.usage`의 입력·출력과 캐시·추론 세부 항목 |
| OpenRouter | 입력·출력, 캐시 읽기·쓰기, 오디오·추론 세부 항목 및 `usage.cost` |
| Claude | 일반 입력, 출력, 캐시 읽기, 캐시 쓰기 토큰을 각각 보존 |

OpenAI·Groq 등의 입력 토큰에는 캐시 읽기가 포함됩니다. 비용 계산 시 일반 입력과 캐시 입력을 나누되, 화면의 전체 입력 합계에 캐시를 다시 더하지 않습니다. 오디오 입력과 추론 토큰도 각각 입력·출력의 세부 항목이므로 전체 토큰에 다시 더하지 않습니다. [OpenAI Responses 스키마](https://raw.githubusercontent.com/openai/openai-python/main/src/openai/types/responses/response_usage.py), [OpenAI 음성 응답 명세](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create), [Groq 사용량 스키마](https://raw.githubusercontent.com/groq/groq-python/main/src/groq/types/completion_usage.py)

Claude의 `input_tokens`는 **캐시를 제외한 입력**입니다. 모델별 입력 합계에는 일반 입력 + 캐시 읽기 + 캐시 쓰기를 더합니다. 요청 상세에는 이 세 항목을 분리해서 표시합니다. 현재 추정 계산은 캐시 읽기만 반영하며, 캐시 쓰기가 있으면 쓰기 유지 시간에 따른 가격을 임의로 정하지 않고 비용을 미확인으로 남깁니다. [Claude 캐시 토큰 정의](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)

일반 입력·출력 토큰이 있지만 캐시 내역이 없을 때는 표준 입력 단가로 추정하고 그 조건을 요청 상세에 표시합니다. 캐시를 포함해 입력을 보고하는 제공자에서 캐시 수치가 전체 입력보다 크거나, 추론 수치가 출력보다 큰 경우 등 관계가 맞지 않으면 비용 추정을 하지 않습니다. 별도 오디오 토큰 과금, 캐시 쓰기 과금 등을 정확히 계산할 수 없는 요청도 미확인으로 둡니다.

## 이 빌드의 공개 가격표

가격 확인일은 **2026-09-10**입니다. 아래는 현재 앱이 비용 추정에 사용하는 제한된 가격표이며, 지원하는 API 모델의 전체 목록은 아닙니다. 모델별로 공식 단가와 필요한 과금 조건을 확인한 경우에만 적용합니다.

각 요청을 기록할 때 계산 결과, 적용 단가, 출처, 확인일을 함께 저장합니다. 이후 앱의 가격표가 바뀌어도 기존 기록을 새 가격으로 다시 계산하지 않습니다. 현재 가격표는 실시간으로 갱신되지 않으며, 사용자 지정 모델이나 새로 반환된 모델 ID가 표에 없으면 그 비용은 미확인입니다.

## 기록 보관과 설정

통계 수집은 **설정 → 개인정보 → 사용량 통계 기록**에서 켜고 끕니다. 결과 문장의 기록 저장 여부와 별개입니다. 문장 기록을 꺼도 통계는 켜 둘 수 있으며, 문장 기록의 보관 기간이 통계에 적용되지 않습니다.

사용량은 이 Mac의 기존 암호화 저장소 안에 별도 목록으로 저장합니다. 통계에는 작업·요청 식별자, 시각, 제공자와 모델, 처리 단계·상태, 요청 횟수, HTTP 상태, 응답 토큰, 음성 길이, 비용과 가격 근거만 포함합니다. 프롬프트, 인식 문장, 결과 문장, 녹음 원음, API 키와 원본 응답 본문은 통계에 저장하지 않습니다. 실패한 녹음의 별도 복구 보관 정책은 사용량 기록과 구분합니다.

- **보관 한도:** 날짜·요청 식별자 순으로 최근 10,000건까지 보관합니다. 초과하면 오래된 기록이 제외되고 화면에 제외 건수를 알립니다. 전체 기록 합계도 현재 남아 있는 기록 기준입니다.
- **기록 끄기:** 새 수집을 중단하고 기존 통계는 유지합니다. 진행 중인 작업에서 아직 수집되지 않은 이후 응답도 저장하지 않습니다. 끄기 전에 수집되어 저장이 시작된 기록은 뒤늦게 반영될 수 있습니다.
- **다시 켜기:** 이후 시작한 처리부터 수집을 재개합니다. 꺼져 있던 동안의 사용량이나 이미 진행 중이던 작업의 빈 구간을 채우지 않습니다.
- **초기화:** 사용량 화면의 **사용량 기록 초기화…**에서 확인 후 실행합니다. 처리 중에는 초기화할 수 없습니다. 통계만 지우고 새 기록 기간을 시작하며, 문장 기록·개인 사전·복구 녹음과 공급자의 실제 청구 내역은 그대로 유지합니다.
- **저장 실패:** 결과 처리와 별도로 누락 가능성 경고를 표시합니다. 나중에 다른 요청이 정상 저장되어도 과거 누락은 사라지지 않으므로 경고가 유지됩니다. 경고 상태는 앱을 다시 열어도 남으며, 통계 초기화가 성공하면 해제됩니다. 초기화에 실패하면 기존 기록을 보존합니다.

통계 초기화는 공급자에게 요청을 취소하거나 환불하는 동작이 아닙니다. 저장 한도로 제외되거나 초기화한 요청을 나중에 다시 받아 합계에 끼워 넣지 않도록 저장소에서도 오래된 기록을 차단합니다.

## 실제 청구액과 대조할 때

앱의 비용 표시는 **USD 기준 참고 통계**입니다. 무료 한도, 세금, 크레딧, 계정별 계약·할인, 환율을 별도로 조회하거나 반영하지 않습니다. 공급자가 응답에 이미 반영한 금액을 다시 조정하지도 않습니다. 로컬 비용 0에는 Mac의 전력·하드웨어 비용이 포함되지 않습니다.

계정 전체 사용액은 다른 앱의 요청, 기록 기능을 꺼 둔 기간, 보관 한도로 제외된 기록, 저장 실패, 종료 전에 응답을 받지 못한 요청 때문에 앱 합계와 달라질 수 있습니다. 최종 결제·잔액·청구 내역은 사용하는 공급자의 대시보드에서 확인해야 합니다.
