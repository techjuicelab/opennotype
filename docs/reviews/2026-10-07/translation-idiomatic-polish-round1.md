# 번역 관용 표현 보강 1차 비교

1차 후보는 채택을 보류했다. 24회 호출은 모두 HTTP 200으로 완료됐고 네 AI 평가자가 명확한 원문의미 변경을 보고하지 않았지만, 일본어 전달 의도를 표현하는 핵심 사례에서 후보가 덜 자연스러워졌다. 신규 사례 두 개에도 약한 기존 결과 선호가 있었다. 이는 자연스러움 개선 완료나 원어민 수준의 검증 결과가 아니다.

이 보고서는 2026-10-07의 1차 실험을 고정 기록한다. 후속 2차 후보는 별도로 검증 중이며 그 결과를 이 회차의 성과로 합치지 않는다. 이 1차 후보의 공개 배포·설치·실제 음성 입력 완료를 주장하지 않는다.

후보는 1차 번역과 선택적 다듬기의 최종 점검에 같은 짧은 관용 표현 지침을 사용했다. 어휘 강도, 같은 명제·기능의 헤지 통합, 뜻풀이와 전달 의도의 구별, 미도입 제안과 진행 중 활동의 중단을 구분하는 내용이다. 특정 단어 금지나 사용자 정답 문장 삽입은 사용하지 않았다. 새 호출 단계나 모델 선택을 추가하는 변경이 아니다.

| 코호트 | 입력·단계 | 비교 단위 | 이번 호출 수 |
|---|---|---:|---:|
| 신규 합성 8개 | 각 원문을 기존/후보 지침으로 각각 처음 번역 | 8쌍 | 16회 |
| 기존 사용자 예시 4개 | 같은 원문과 같은 고정 번역 초안을 기존/후보 지침으로 각각 다듬음 | 4쌍 | 8회 |
| 전체 | 두 처리 단계를 분리해 평가 | 12쌍 | 24회 |

신규 코호트는 [사전 고정 합성 명세](../../fixtures/translation-idiomatic-polish-holdout.json)의 영어 4개·일본어 4개다. 기존 초안 코호트는 영어 2개·일본어 2개다. 기존 4개의 비교에는 새 초안 생성 호출이 포함되지 않았으며, 기존 지침의 다듬기와 후보 지침의 다듬기를 같은 초안에 적용했다. 이번 24회는 이전 번역 다듬기 실험의 호출 수와 별개다.

공통 설정은 OpenRouter의 `openai/gpt-6-luna`, `medium` 추론이다. 각 arm은 한 번 호출했고 재시도와 Jev 검토는 사용하지 않았다. 같은 쌍의 요청 입력은 동일했다. 관측된 24개 사용량 이벤트와 24개 HTTP 200은 API 완료 근거이며, 번역 품질 합격 개수가 아니다. API 사용량 이벤트의 비용 합계는 $0.006623835로 기록됐다.

## 잠금 평가와 결과

네 Codex AI 평가자는 원문 조건, 의미 보존, 유창성 0–3점과 문체 주의를 각각 기록했다. 이후 선호 판독 파일의 SHA를 잠그고 A/B 대응표를 공개했다. 아래 숫자는 각 평가자의 **후보 선호 / 기존 선호 / 동률**이다.

| 평가자 | 전체 12쌍 | 신규 첫 번역 8쌍 | 기존 동일 초안 다듬기 4쌍 |
|---|---|---|---|
| 루트 | 3 / 3 / 6 | 1 / 2 / 5 | 2 / 1 / 1 |
| 코어 | 3 / 1 / 8 | 1 / 0 / 7 | 2 / 1 / 1 |
| UI·언어 | 4 / 3 / 5 | 1 / 2 / 5 | 3 / 1 / 0 |
| 검증 | 3 / 3 / 6 | 1 / 2 / 5 | 2 / 1 / 1 |

서로 다른 48개 표본이 아니라 **네 AI가 같은 12쌍을 평가했다**. 평가자 차이를 독립 표본 수로 늘리거나 집계 선호를 통계적 효과로 해석하지 않는다. 전원이 명확한 의미 실패를 표시하지 않았다는 결과도 표현 품질 전체의 합격이나 모든 의미 오류의 부재를 보장하지 않는다.

## 시험 설계의 한계

- 신규 8개는 이전 문제 방향을 아는 AI가 작성한 선정 합성 사례다. 실제 사용자 집단이나 언어 전반을 대표하지 않는다.
- 평가자는 개선 방향과 현재 지침을 알고 있었다. 기존 4개 원문과 과거 표현에도 노출돼 있었으며, 가린 것은 arm의 실제 라벨이다. 사람 원어민 평가가 아니다.
- 최초 프로토콜은 최종 후보 소스 동결 전 root/core/UI에 해시·개수만 공유하는 것이었다. 실제로는 루트가 하네스 스키마 준비를 위해 동결 전에 봉인된 신규 입력·기준을 열람했다. 이는 프로토콜 이탈이며, 모든 참여자가 끝까지 신규 원문에 비노출이었다고 주장할 수 없다.
- 이 이탈은 루트의 조율 메시지와 독립 검증 메모에 기록됐다. 정확한 열람 시각은 독립 관측하지 않았다. 봉인 명세 자체는 변경하지 않았고 코어·UI는 최종 후보 소스 동결 통보 뒤 읽었다는 보고를 남겼다. A/B 라벨은 네 평가 파일 잠금 후 공개했다.
- 한 모델·설정의 입력별 단일 출력 비교다. 같은 제공자 설정을 사용했지만 OpenRouter의 하위 제공 경로를 별도로 고정한 시험은 아니다.
- 실제 마이크·STT 손실·사용자 앱 입력·Jev 검토·설치 앱의 이 후보 실행은 평가하지 않았다. 민지의 성별도 이번 평가 범위에서 제외했다.
