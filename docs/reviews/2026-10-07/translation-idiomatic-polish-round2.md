# 번역 관용 표현 개선 2차 검증 준비 기록

2026-10-07 현재, 후보 `6d5791c5db0b8fdcbc075d54cd9dac69de7d9129`의 소스 조립·오프라인 계약·정식 CI·로컬 후보 번들 검증을 마쳤다. **2차 모델 호출은 1Password 실행 인증 대기로 아직 0회이며, 품질은 미평가다.** main 반영과 후보 앱 설치·실행은 보류한다. 계획한 24회를 HTTP 실패나 품질 실패 24회로 집계하지 않는다.

[1차 검토 기록](translation-idiomatic-polish-round1.md)은 유지한다. 1차는 실제 24회 호출·12쌍을 평가했지만 `TIPK03_ja_intent`의 유창성 회귀와 일부 약한 후퇴가 남아 채택을 보류했다. 그 결과가 이번 후보의 개선 목표이며, 새 후보의 효과를 입증하는 결과는 아니다.

이번에는 공유 블록의 앞 4줄을 정제했다. 각 절의 참여자·행동·화행·인접 절 관계를 먼저 파악하고, 그 관계에서 목표 언어의 자연스러운 서술어와 근거 있는 논항을 구성하도록 안내한다. 전달하려는 내용과 발화 자체의 목적·가치·정의를 구별하며, 미지정 역할·시각과 행동별 횟수의 귀속을 유지한다. 자연스러운 명사절도 허용한다. 사용자 정답 문장, 특정 단어 금지 목록, 앱별 표현을 넣지 않았다.

이 블록은 1차 번역과 선택적 번역 다듬기의 최종 검사에서 함께 사용한다. 독립 조건·약속·의무·부정·강조를 지우거나, 명시된 강도를 낮추거나, 제안 거절을 진행 중인 활동의 중단으로 바꾸도록 허용하지 않는다. 기본 모델·사용자 선택·추가 호출 정책을 자동 변경하지 않는다. 프롬프트 변경에 따른 입력 토큰이나 실제 요금의 불변을 보장하는 것은 아니다.

## 봉인 입력과 최대 24회 계획

신규 입력과 기준은 소스 최종 동결 전에 `2026-10-07T12:36:30.446985+00:00`에 봉인했다. 영어 2개·일본어 2개이며 참고 정답 문장은 없다. 봉인 기록상 이 시점에는 후보 소스가 아직 동결되지 않았고, 신규 본문은 root·core·UI에 공유되지 않았다. 이 입력은 앞선 실패 방향을 아는 AI가 작성한 선정 사례다.

| 비교 단계 | 입력·초안 관계 | 쌍 | 최대 호출 |
| --- | --- | ---: | ---: |
| 기존 4개 정제 | 기준·후보에 동일한 기존 초안을 전달 | 4 | 8 |
| 신규 4개 1차 생성 | 같은 원문·설정으로 기준·후보 각각 생성 | 4 | 8 |
| 신규 4개 최종 정제 | 각 소스 조건에서 생성한 자신의 실제 초안을 정제 | 4 | 8 |
| 합계 | 기존 4개 + 신규 4개 원문 | 12 | 24 |

신규 생성과 최종 정제는 **같은 신규 4개 원문에 대한 종속 관측**이다. 이를 독립 신규 8사례로 세지 않는다. 신규 최종안은 1차 초안 차이와 정제 지침의 효과를 함께 포함하므로, 정제만의 효과는 동일 초안을 사용하는 기존 4쌍과 구분한다.

계획은 OpenRouter `openai/gpt-6-luna`, `medium`, 최대 동시 요청 2개, 자동 재시도 없음, Jev 없음이다. 원문·profile·목표 언어·사전은 유지하고, 신규 정제 단계에서 다른 조건의 초안을 재사용하지 않는다. 각 실제 생성 초안이 나온 뒤 그 초안으로 구성한 정확한 정제 요청을 export·해시한 다음 정제를 1회 호출하도록 준비했다.

## 소스 조립과 오프라인 계약

기준·후보 각각 28개 소스의 SHA를 동결 레지스트리와 대조했고, 후보는 현재 작업 소스와 일치했다. 실제 최초 요청 16개의 프롬프트 바인딩을 확인했다. 신규 정제 요청의 실제 바인딩은 모델 생성 초안이 있어야 확정되므로 아직 대기 중이다.

별도 오프라인 검증에서는 일반·비신뢰 placeholder 초안을 사용한 파생 요청 16개를 export했다. 같은 placeholder를 사용하는 조건 간 입력 8쌍이 같고, 초안이 지침 문자열에 보간되지 않으며, 초안 이외의 원문·설정이 생성 요청과 같음을 확인했다. 평가 기준은 모델 payload에 전달하지 않는다. placeholder는 모델 출력이 아니며 라이브 실행 입력 목록에서도 제외된다. 이 검증은 요청 조립 경계의 증거로만 사용한다.

## 정식 CI

후보 commit에 연결된 [PR CI 37622641805](https://github.com/techjuicelab/opennotype/actions/runs/37622641805)와 [push CI 37622636009](https://github.com/techjuicelab/opennotype/actions/runs/37622636009)가 모두 성공했다.

각 실행에서 고유 XCTest 899개가 시작되어 897개 통과·기존 LocalAudio 통합 검사 2개 건너뜀·실패 0개였다. Python 계약 검사는 각 198개 통과·건너뜀 0개다. 1차 후보와 XCTest 식별자 집합이 같고, 번역 다듬기 관련 35개와 기본 프롬프트 golden 검사가 각 1회 통과했다. 개발 앱 빌드·artifact 업로드도 각 성공했으며 artifact의 commit 연결을 확인했다.

이는 코드·회귀 계약 검사 결과다. 2차 모델 품질, 실제 마이크, 자동 입력, 후보 앱 런타임의 합격을 뜻하지 않는다. 별도 로컬 Python 실행의 건너뜀 수를 정식 CI 수치와 혼합하지 않는다.

## 현재 판정과 평가 한계

현재 판정은 **실행 준비 완료·품질 미평가·main 및 설치 보류**다. 1Password 실행 인증 대기로 모델 호출 단계에 진입하지 않았다는 root의 확인과 준비 proof를 함께 근거로 실제 호출 0회를 기록한다. 결과 파일이 없다는 사실만으로 모든 실행 상황의 API 호출 0회를 추론하지 않는다. 향후 요청 중 timeout이나 중단이 발생하면 저장 응답 유무와 원격 요청 상태를 따로 확인해야 한다.

실측 후에는 의미·화행·강도·말투 보존과 자연스러움을 나누고, 기존 동일 초안 4쌍·신규 생성 4쌍·신규 최종 4쌍을 각각 보고해야 한다. HTTP 200이나 보호 검사 통과는 의미·자연스러움 합격이 아니다. 이 기록에는 새 품질 결과나 원어민 수준 합격 판정이 없다.

1차의 root 사전 입력 열람은 [1차 보고서](translation-idiomatic-polish-round1.md)에 남긴 프로토콜 이탈이며 이번 기록으로 지우지 않는다. 2차 신규 본문의 소스 동결 전 비공유는 별도 작성·동결 기록에 따른다. 앞선 실패 방향을 아는 AI 작성자·검토자의 평가이며 사람 원어민 검수나 대표 표본이 아니다. 조건당 단일 확률적 응답을 계획하고, OpenRouter 상위 공급 경로도 고정하지 않는다. 실제 마이크·대상 앱 삽입·Jev 검증은 계획 범위 밖이다.
