## 품질·설치 검증 범위

- 단위·모의 공급자 시험은 실제 API 정확도 또는 자동 입력 성공을 뜻하지 않는다.
- 설정 복구와 보관 시험은 격리된 UserDefaults 및 임시 암호화 합성 저장소에서 실행한다.
- 실제 음성의 한영 고유명사·반복·철자·숫자와 앱별 입력, 실제 OpenNoType 공개 앱 두 버전의 Sparkle 교체는 [설치 및 실사용 검증 목록](installation-verification.md)으로 별도 확인한다.
- 검토 한도를 우회하는 무조건 분할·실패 시 자동 통과는 하지 않는다. 긴 녹음은 짧게 나누거나 결과를 직접 검토한다.
- Developer ID·Apple 공증은 이번 범위에 포함하지 않는다. ad-hoc 앱 교체 후 Keychain/TCC 재승인은 macOS에서 직접 확인해야 한다.
