# 프롬프트 내용 검토와 결과 제공 분리

## 문제와 정책 변경

사용자의 독서 기록 요청은 알림을 희망하면서 도입 여부를 미정으로 두었다. 원문의 미정은 정상적인 작업 맥락이며 프롬프트를 만들기 전에 결정할 이유가 없다. 기존 설치본에서는 최종 후보의 `omissions` 신호가 기준에 미달하면 전체 결과를 보류하고 복사를 막았다. 네 축의 모든 신호를 완성 여부로 취급한 것이 반복 보류의 직접 원인이다.

새 정책은 사용자가 확인하고 직접 다른 AI에 전달하는 프롬프트의 성격에 맞춰 검토 관측과 제공 여부를 분리한다. 점수 임계값이나 모델을 낮추거나 바꾸지 않는다.

| 결과 | 제공 정책 |
| --- | --- |
| 유효한 검토, 네 축 기준 충족 | 프롬프트 제공 |
| 의도·임의 추가·누락 중 기준 미달 | 참고 표시와 함께 프롬프트 제공·복사 허용 |
| 기존 지침 우회 검토 기준 미달 | 후보 확인만 허용, 제공 보류 |
| 생성·형식·검토 응답 오류 또는 취소 | 해당 단계 중단 |

내용 참고 표시는 작은 문체 차이만을 뜻하지 않는다. 중요 조건 누락도 포함할 수 있다. 현재 네 축의 스칼라 응답으로 오류의 심각도나 누락된 문장을 알아냈다고 주장하지 않는다. 생성 지침은 여전히 독립 조건과 희망·미정·부정·수량을 보존하도록 요구하며, 검토 우려가 있으면 한 번만 자동 복구한다. 그 뒤의 유효한 내용 검토 우려는 추가 결정·승인 창이나 필수 재생성으로 이어지지 않는다.

예를 들어 `알림 기능을 희망하지만 도입 여부는 아직 미정입니다.`는 완성된 요청에 포함할 수 있다. `도입 여부를 결정해 주세요.`나 `추후 결정하겠습니다.`로 바꾸지 않는다. 프롬프트를 복사하는 행위도 알림 도입을 결정하는 행위가 아니다.

## 적용 범위

- `PromptCompositionReviewResult.accepted`와 네 축의 원본 판정·통과 신호 0.8·확신 0.6은 그대로 보존한다. 별도의 `deliveryDisposition`으로 제공 여부를 결정한다.
- 초안 → 첫 검토 → 필요 시 한 번 복구 → 최종 검토의 호출 상한을 유지한다. 자동 재시도·다른 모델 선택·추가 API는 없다.
- 프롬프트 결과는 명시적 클립보드 복사만 수행한다. 대상 AI 실행·자동 입력·자동 제출은 하지 않는다.
- 기록에는 당시 제공 상태와 참고 항목을 함께 저장한다. 과거 기록에 이 필드가 없으면 검토 통과를 추정하지 않는다. 기록 재처리도 참고 상태를 표시한다.
- 받아쓰기·번역의 생성·검토·자동 입력 정책은 변경하지 않는다. 로컬 형식·코드 검사와 기존 지침 관련 검토 차단을 유지한다.

## 검증 구분

사용자 화면의 최종 판정 조합(의도 통과 84%/확신 76%, 추가 통과 93%/89%, 누락 문제 있음 46%/30%, 기존 지침 100%/100%)을 고정한 회귀 검사는 새 정책의 제공 동작을 확인한다. 이는 같은 모델을 다시 호출해 같은 결과가 나왔다거나 모든 원문 조건이 보존됐음을 증명하는 시험이 아니다.

로컬 production 직접 컴파일 검증은 Core 111개 메서드·2,336 assertions, App/Platform 54개 메서드·691 assertions, 독립 계약 222 checks 모두 실패 0이다. 이는 정식 XCTest 실행과 구분한다. Python 200개도 통과했다(환경·선택적 통합 검사 3개 skip). 전체 SwiftUI 앱 빌드와 엄격 서명 검사도 통과했다.

독립 검사는 의미 세 축의 27조합과 낮은 신호·확신, 기존 지침 관련 경계값, 형식·통신 실패·취소, 복구 호출 상한, 이전 기록 호환, 참고 결과의 복사 가능 상태를 확인했다. App/Platform 검사는 녹음 복구·원문 재생성·기록 재처리에서 참고 상태 보존과 자동 입력의 격리를 확인했다. 로컬 Python 첫 실행의 독립 Swift 컴파일 의존성 오류 두 건은 공유 제공 상태 타입을 기존 공통 소스에 배치해 수정했다.

정식 CI와 실제 설치 상태는 [PR #28](https://github.com/techjuicelab/opennotype/pull/28) 및 로컬 검증 근거에서 별도로 기록한다. 기존 구조 응답 후보의 실제 모델 검증은 1Password 인증 시간 초과로 아직 실행되지 않았으며, 이를 새 제공 정책의 의미 품질 근거로 사용하지 않는다.
