# 누락 복구에서 다른 요구를 잃는 문제

사용자가 `a4e281e` 테스트 앱에서 나열형 독서 기록 요청을 녹음한 뒤 최종 보류 화면을 제공했다. 실행 중인 앱의 원문·초안·최종 후보·판정을 직접 대조해 보존했고, 같은 원문을 수정 없이 한 번 더 텍스트 재생성해 같은 유형의 결함을 재현했다. 실패 원음은 재전송하지 않았고 암호화된 녹음 파일 hash도 유지했다.

## 관측

첫 초안은 사용자가 말하지 않은 감상·줄거리를 만들지 말라는 조건을 누락했다. 최종 후보는 이를 복구했지만, 알람을 희망하면서 도입은 미정이라는 상태를 `알림 기능은 옵션으로 두세요`로 바꿨다. 최종 omissions는 pass를 선택했어도 신호 0.51·확신 0.27로 기준 미달이었다. 이는 실제 조건 손실이 있는 보류이며 과도한 보류로 집계하지 않는다.

같은 원문의 추가 재생성도 알람을 `옵션으로 두어 추후 결정`하도록 바꾸고 문구 조건을 누락했다. 최종 omissions는 신호 0.67·확신 0.51로 다시 보류됐다. 생성 2회·검토 2회, 자동 재시도 0회이며 음성 인식은 다시 호출하지 않았다.

인식 원문의 `앱을 붙이고`와 `알람`은 관측 그대로 유지했다. `아까 문구 얘기는 빼먹었는데 짧고 담백하게`는 대상이 명확하지 않아 제품 문체라고 임의 확정하지 않는다. 범위를 새로 정하지 않고 `문구는 짧고 담백하게`처럼 중립적으로 보존할 수 있다. 이 불명확성을 확정적인 제품 문체 누락으로 중복 집계하지 않는다.

Production Runner와 실제 prompt builder를 추적한 결과 원문 504 UTF-8바이트는 잘림 없이 두 생성과 두 검토에 전달됐다. 복구 요청에는 누락된 초안도 함께 포함됐다. 원문에서 다시 쓰라는 기존 지시가 있어도 모델이 그 초안의 틀을 따라가며 한 조건을 복구하는 대신 다른 조건을 떨어뜨릴 수 있다는 가설을 분리했다. 최초 작업의 초안 판정 수치는 화면에 남아 있지 않아 이후 모의 trace의 flags를 실제 관측으로 취급하지 않는다.

## 입력 구조 변경

원문을 문장 범위로 나눈 순서 있는 `source_segments`를 보조 데이터로 제공한다. 조각들을 연결하면 원문과 정확히 같으며 요건·역할·중요도 분류, 인식 오류 보정이나 문구 추정은 하지 않는다. 정정·인용·설계 예시의 의미는 여전히 전체 원문에서 판단한다. JSON 밖 지침으로 원문을 옮기지 않으며 모든 조각은 인용 데이터 경계를 따른다.

첫 검토에 omissions가 포함되면 두 번째 생성의 모델 payload에서 초안을 제외하고 원문으로 재구성한다. 초안 보존 분기를 지시하는 polishing 계약 대신 별도의 reconstruction 계약을 사용한다. 다른 위험만 있는 repair는 기존의 초안 비교를 유지한다. 내부 `ProcessingRequest.promptDraft`는 그대로 두어 앱의 단계·화면 증거와 최종 출력의 엄격한 검사를 유지한다.

입력 원문 12,000바이트·요청 64,000바이트 상한을 유지한다. 보조 조각 때문에 예산을 넘으면 조각만 생략하며 원문을 자르지 않는다. 원래 요청 자체가 예산을 넘으면 기존처럼 거절한다. 출력 `{text}` schema, 모델·추론 강도·토큰·timeout, 최대 생성 2회·검토 2회, 네 축·0.8/0.6 기준과 최종 보류는 바꾸지 않는다.

## 검증과 남은 확인

Production 소스를 직접 컴파일한 Core 하네스는 58메서드·878 assertion, 독립 계약 검사는 238개 모두 실패 0이다. Provider 14메서드·1,725 assertion을 두 번, Runner 23메서드·312 assertion을 실행해 정상·JSON 오류·빈 출력·코드·최종 말줄임표·429·시간 초과·취소의 경계가 유지됨을 확인했다. 이는 입력 구조와 오류 경계 검증이며 모델의 의미 보존 성공률을 증명하지 않는다. 로컬 CLT 하네스와 정식 XCTest 실행은 구분한다.

실제 API 비교는 사용자 원문과 별도 도메인 두 원문을 수정 전후 각각 한 번씩 처리하도록 제한했다. 기대판정·보존 조건은 모델 입력에 포함하지 않으며 동일 모델·검토·호출 상한을 사용한다. 비교 배치는 1Password CLI 인증 시간 초과로 아직 API 요청을 전송하지 못했으므로 효과를 확정하지 않는다. 원래 관측·동결 소스·hash·하네스·비교 자료는 `build/prompt-preservation-2026-10-08/`에 보관한다.
