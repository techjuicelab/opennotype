# 새 프롬프트 녹음의 결과 표시·실패 처리

사용자는 같은 발화를 다시 녹음한 뒤 입력·기록·결과가 사라졌다고 보고했다. 설치본 `d69df70`을 읽기 확인했을 때에는 22:10의 새 녹음이 음성 인식 1회·생성 2회·검토 2회를 완료했고, 복사 가능한 최근 결과와 기록 2건(22:03, 22:10)이 존재했다. 22:10 요청에는 재처리 표시가 없었다. 이 관측만으로 사용자에게 보였던 순간의 화면이나 별도 시도의 소실 원인을 확정하지 않는다.

프롬프트 모드는 다른 앱에 자동 입력하지 않고 결과를 확인해 복사하는 기존 계약을 유지한다. 정상 처리의 음성 바는 완료까지 유지되며 페이지 이동 자체가 결과를 삭제하는 경로는 찾지 못했다. 다만 완료 카드가 홈 안내·입력 준비·모드 카드 아래에 있고, 같은 홈 화면에서 완료되면 기존 스크롤 위치를 유지해 결과를 놓치기 쉬웠다. 실제 설치본의 홈 스크린샷에서도 첫 화면에는 안내·입력 준비·모드 카드만 보였고, 접근성 트리에 존재하는 완료 결과는 아래쪽 화면 밖에 있었다.

코드와 재현 테스트에서는 별도 실패를 확인했다. 새 작업의 `generation` 교체가 완료된 이전 프롬프트까지 즉시 삭제해, 녹음 시작 실패에도 이전 결과가 사라졌다. 또 녹음 파일을 받지 못한 종료는 오류 안내 없이 대기로 돌아갔다. 짧음·낮은 음량으로 거절한 녹음은 API·새 기록 없이 종료하므로 이 경우도 기존 결과와 안내를 함께 남기는 편이 적절하다.

수정은 다음과 같다.

- 완료된 이전 프롬프트 화면은 새 프롬프트 녹음 중 유지하고, 처리 가능한 녹음이 준비되면 교체한다. 새 녹음 시작 실패·파일 없음·짧음·낮은 음량에는 이전 결과를 보존한다.
- 파일 없음에는 오류를 표시하고, 프롬프트 무음 종료에는 원인 안내와 음성 바 알림을 표시해 홈을 연다. 음량·시간 기준은 바꾸지 않는다.
- 이전 결과를 유지하는 동안 새 작업과 구분하는 문구를 표시한다. 완료 카드는 홈 소개 바로 아래로 옮기고 홈에서 작업이 끝나면 위로 이동한다.
- 명시 취소와 개인정보·연결 설정에 따른 권한 철회는 기존처럼 진행 중 작업과 늦은 결과 게시를 막는다. 화면 보존은 완료된 임시 표현 상태에만 적용하고, 이전 작업의 실행 권한을 복구하지 않는다.
- 저장 설정 설명을 현재의 참고 경고 포함 결과 제공 정책에 맞춘다.
