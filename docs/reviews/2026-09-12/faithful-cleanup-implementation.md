## 반영한 처리 규칙

`DictationCleanupInstructions.swift`를 실제 `ProcessingPrompt`의 받아쓰기·번역 경로에 연결했다. 기존 음성 인식 결과는 로컬 정규식으로 고치지 않고, 원문 그대로 JSON 데이터에 넣는다. 문장 정리는 기존 모델 요청 한 번으로 수행한다.

| 변경 | 기대하는 동작 |
| --- | --- |
| 중복 의미 합치기 | 같은 요청을 여러 번 말해도 한 번으로 정리하며, 중간이나 뒤에 추가한 대상·기한·조건은 함께 보존한다. |
| 재시작 정보 승계 | 버려진 시작 구절에만 있는 유효한 행동·이름·장소를 최종 문장에 이어받는다. |

선택 문장 수정에는 새 반복 정리 계약을 적용하지 않는다. 해당 모드는 사용자가 요청한 범위의 수정 규칙을 유지하며, 공통 사전 안내만 명확해졌다. 처리 제공자·기본 모델·전송 횟수·사용량 수집 경로는 유지한다. 입력 프롬프트가 길어졌으므로 입력 토큰·실제 지연·비용이 같다고 주장하지 않는다.

## 기존 비교 보고서의 해석

기존 [120b/20b A/B 보고서](../2026-09-11/gpt-oss-120b-vs-20b-ab.md)는 이번 구현 전에 다른 작업에서 만든 자료다. 그 자료를 읽어 다음 수정 근거를 얻었으며, 이번에 같은 호출을 재실행한 것은 아니다.

- D02는 두 모델의 6개 출력에서 폐기된 오전 10시가 남았다. 당시 기대값도 `리뷰` 행동을 누락하므로 새 평가에서는 시간뿐 아니라 리뷰를 보존하도록 했다.
- D09는 6개 출력에서 보존해야 하는 `커미` 리터럴이 바뀌었다.
- D16은 성공 응답 5개 모두 일반적인 사과 행위를 `SAGWA`로 바꿨다. 다른 1건의 HTTP 429는 내용 실패와 별도로 센다.
- D15는 20b의 3개 출력이 문맥의 영문 번역·서명 추가 지시를 따랐다.
- 표의 `ok`는 응답 형식·전송 상태이며 의미 품질 점수가 아니다. D17의 빈 출력은 필러 전용 입력의 정상 결과였고, D18에서 실제 빈 출력은 없었다. `failureSignal`에 적힌 예상 오답을 실측 실패로 세지 않는다.

자동 테스트는 원문·Unicode·모드·사전·문맥의 요청 계약과 기존 기능 회귀를 확인한다. 32개 문장에 대해 실제 모델이 올바르게 정리했다는 뜻이 아니다. 프롬프트 내부 점검 역시 독립 검증기가 아니므로 의미 유실이 없다고 보장할 수 없다.

## 전후 비교 실행

`CleanupEvaluationTests`는 앱과 같은 `ProcessingPrompt.build`에서 요청을 만든다. export는 키를 읽거나 네트워크를 호출하지 않는다. 비용 비교 도구도 기본은 dry-run이며 실제 호출에는 `--execute`가 필요하다.

```sh
OPENNOTYPE_CLEANUP_EXPORT=/tmp/opennotype-cleanup-after.json swift test --filter CleanupEvaluationTests
python3 scripts/compare-cleanup.py \
  --before docs/reviews/2026-09-12/evidence/cleanup-before.json.gz \
  --after /tmp/opennotype-cleanup-after.json \
  --ids FC01,FC04,FC06,FC08,FC09,FC13,FC18,FC19,FC20,FC25,FC26,FC31,FC32 \
  --output build/quality-eval/plan.json
```

평가 도구는 정해진 Groq HTTPS 주소만 사용하고 리다이렉트·자동 재시도를 하지 않는다. 전체 계획을 공개 단가, 입력 UTF-8 바이트에 기반한 보수적 토큰 상한, 출력 1,024토큰으로 먼저 계산하며, 한도보다 큰 계획은 실행하지 않는다. 기본 예약 한도는 US$0.10이며 실제 공급자의 계정 청구 한도를 설정하는 기능은 아니다. 실패·사용량 미제공 건도 예산 예약을 돌려주지 않는다. 앱의 출력 한도는 16,384토큰이므로 긴 문장 평가에서는 이 차이를 함께 해석해야 한다.

실제 실행을 선택할 때만 `GROQ_API_KEY` 환경변수를 사용한다. 키나 인증 헤더·서버 오류 본문은 결과에 기록하지 않는다. 결과 JSON과 Markdown은 모델·프롬프트·fixture 해시, 결과 문장, 상태·지연·토큰·참고 비용을 남긴다. 기대 문장 완전 일치와 의미 보존의 사람 검토를 분리하며, 형식 오류·의도된 빈 결과·의미 있는 입력의 빈 결과를 별도 표시한다.

앞으로 실제 평가를 하더라도 동일 입력의 전후 결과에 대한 증거이며, 자연 음성의 STT 정확도나 Typeless 대비 우위를 입증하는 것은 아니다. 전사 단계에서 이미 유실된 단어는 문장 정리 지침만으로 확실하게 복원할 수 없다.
