# 네이티브 기록 화면 확인

2026-09-12, 별도 번들 `app.opennotype.usage-preview`, DEBUG 빌드, 버전 0.1.9 (10), 창 제목 `OpenNoType · 디자인 검증용 샘플`에서 확인했다. 화면 상단에도 합성 기록임을 안내한다. 실제 기록·키를 읽지 않고 녹음과 네트워크를 거부하는 기존 preview 경계를 사용했다.

라이트와 다크 화면을 직접 확인하고 접근성 트리로 다음 요소를 펼쳤다.

- 받아쓰기: 보관된 결과·결과 복사, 인식 원문·원문 복사, 현재 설정으로 다시 처리.
- 재처리 안내: Groq, openai/gpt-oss-120b, 해당 앱의 현재 프로필·말투, 현재 개인 사전, 추가 API 비용 가능성, 기존 결과 보관, 당시 입력창 문맥 부재.
- 번역: 영어 결과와 한국어 인식 원문, 현재 번역 언어 `English (United States)`, 당시 번역 언어가 기록에 없다는 안내.
- 선택문 수정: 보관된 결과와 음성 수정 지시를 구분하고, 당시 선택 문장이 없어 다시 처리할 수 없다는 안내.

두 테마에서 카드·본문·버튼·안내가 겹치지 않고 스크롤로 내용을 확인했다. 기존 화면 크기에서 수행했으며 모든 확대율·접근성 설정을 시험한 것은 아니다. 복사 버튼의 실제 클립보드 변경, 실제 재처리 API 클릭, 사용자의 기록·키 저장·외부 앱 삽입은 이 화면 점검에 포함하지 않았다. 재처리 상태 전환·단일 처리 요청·사용량·취소·삭제 경계는 별도의 AppModel 회귀 테스트로 확인했다.
