# Jev 추가 도움 기능 — 0.1.19(21)

## 적용 범위

사용자가 요청한 일곱 활용안을 구현했다. [사용 위치·전송 범위·호출 상한](../../jev-review.md#추가-도움-기능--0119)은 기능 안내에 정리했다.

- 승인한 앱·프로젝트 이름만 사용하는 로컬 후보 검색과 확인 사전 저장.
- 기존 요청 안에서 숫자·부정·조건·의도·이름의 세부 위험 축을 추가.
- 승인 정답 1~5개, 같은 제공자의 가격이 알려진 모델 2~3개의 비용 우선 비교·명시적 적용.
- 강한 기존 검토 신호에 생성 1회+검토 1회의 자동 개선안 준비 옵션.
- 비어있지 않은 원문과 결과의 완전 일치 및 표기 후보 없음에서만 검토 생략하는 절약 옵션.
- 수정 전에 지시가 모호하거나 검토가 실패하면 입력을 보류하고 명확한 지시로 복사 전용 수정안을 만드는 옵션.
- 해결되지 않은 이름 또는 강한 의미 신호에서 동일 Groq/OpenAI 제공자의 다른 지원 모델로 현재 녹음을 한 번 더 인식하고 비교하는 옵션.

새 자동 옵션은 기본 꺼짐이다. 기본 언어는 영어, 한국어 선택과 기존 설정·키를 유지한다. 음성 인식·문장 정리·Jev의 제공자는 독립적으로 선택한다. 비교 추천이 현재 설정을 자동으로 바꾸거나 Jev 개선안이 이미 입력한 글·원결과·기록을 덮어쓰지 않는다.

재인식의 두 인식문은 Jev의 텍스트 비교 입력이다. 실제 음성을 기준으로 어느 문장이 맞는지 고르는 모델로 설명하지 않는다. 다른 인식 결과를 선택하면 직접 복사하거나 명시적으로 정리·검토한 뒤 복사한다. 기존 녹음 수명과 실패 복구 정책을 확장하지 않는다.

## 실제 TypeSafe 요청 검증

2026-10-01에 제품의 DecisionClient·1.5초 제한·재시도 없음으로 합성 문장 8건을 실행했다. 1Password op run 런타임 주입만 사용했다.

TypeSafe는 청구 비용을 보고하지 않았으며 유효 입력 토큰 8,697개와 참고 단가로 추정했다. 합성 텍스트 8건의 신호 일치이며 일반 정확도나 실제 마이크 품질 측정이 아니다. 실제 음성, 희귀 이름 Choice, no_applicable_edit, uncertain은 이 실제 API 표본에 포함하지 않았다. typed parser·오류·시간초과·취소는 회귀 검사로 따로 확인한다.

## 실제 모델 비교 경로 검증

제품 ProviderClient·DecisionClient·JevModelComparison을 사용했다. 합성 승인 정답은 “JEV로 OpenNoType을 개선하고 싶어요.” 한 건, 생성 모델에는 이 정답을 전달하지 않았다. OpenRouter 두 모델과 TypeSafe 검토를 총 4회 요청했으며 HTTP 200, 재시도 0회였다.

| 모델 | 이 사례의 검사 | 생성 시간 | 생성+검토 합계 비용 |
| --- | --- | --- | --- |
| GPT OSS 20B | 1 / 1 | 4.032초 | $0.000096540 |
| Qwen3.7 Flash | 1 / 1 | 1.229초 | $0.000124948 |

사전 예약 $0.010142608, 전체 6.349초, 합계 $0.000221488이었다. 비용 우선 정책으로 GPT OSS 20B를 제안했으며 설치된 문장 모델 설정은 변경하지 않았다. 생성 비용은 OpenRouter 보고, 검토 비용은 TypeSafe 참고 단가 추정이다. 이 한 사례만으로 모델의 일반 한국어·영어 정확도나 속도 우위를 주장하지 않는다.

이 실측 뒤 고정표기 검사에 CamelCase를 추가했다. 두 실제 응답 모두 정답과 같은 JEV/OpenNoType 표기이므로 새 조건도 충족하며, OpenNoType를 OpenType·Opennotype·한글 음차로 바꾸거나 누락하면 추천을 거부하는 회귀를 추가했다.
