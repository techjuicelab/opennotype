# Jev 검토 기능 검증 — 2026-10-01

## 구현 범위

0.1.12 소스에 기본 꺼짐인 Jev 검토를 추가했다. 기존 OpenRouter 키로 받아쓰기 결과의 의미 변경·추가·누락을 검사하고, 영문 후보 선택을 제안한다. 입력 후 비동기 검토와 입력 전 보호를 구분한다. 보호 기준은 최대 위험 점수 0.9, API 응답 제한은 1.5초이며 실패 시 기존 결과를 유지한다. [동작·전송·보관 안내](../../jev-review.md).

## 로컬 검증

- production Core의 전송·응답 파서에 대한 XCTest 본문을 headless adapter로 실행: 16/16 통과.
- production AppModel/Core/Runtime을 컴파일하고 앱 흐름 XCTest 본문을 headless adapter로 실행: 17/17 통과. 실제 마이크·손쉬운 사용 입력 대신 주입한 경계를 사용했다.
- Python suite: 157개 실행, 실패 0, 환경에 따른 건너뜀 1. Jev 벤치마크의 신규 검사는 14개다.
- macOS 26.5 SDK로 최종 SwiftUI release 앱 빌드와 `codesign --verify --deep --strict` 통과. 이 Mac의 기본 macOS 27 SDK 매크로 문제는 기존 preflight가 호환 SDK를 선택해 처리했다.
- 로컬 CLT에는 XCTest가 없어 정식 `swift test`는 별도 GitHub Xcode 환경에서 확인한다. headless 결과를 정식 XCTest 실행으로 표기하지 않는다.

검사 범위에는 취소·새 작업 경합·검토 해제·기록 삭제, 이전 설정 스냅샷, 기록 저장과 검토의 독립성, 시간 초과·실패, 고위험 입력 보류, 표기 제안의 한글 유지·폐기된 단어 제외, 리다이렉트 차단·응답 크기·타입 검증·비용 미확인이 포함된다.

## 실제 API 연결과 평가 상태

개인 발화가 없는 합성 문장 한 건으로 OpenRouter Decisions API에서 HTTP 200을 확인했다. 모델은 `typesafe/jev-1.13-20260917`, 공급자는 TypeSafe였다. 응답은 약 0.595초, 보고 비용은 $0.00001554였다. 이 연결 검사는 Noul 질문 한 개만 사용했으므로 production의 전체 질문 묶음에 대한 정확도·속도 결과가 아니다.

72개 평가 fixture와 production 요청·파서를 공유하는 벤치마크를 준비했다. 실제 응답을 보기 전에 라벨을 독립 검토하고 불확실성→확정 약속, 자기수정 목적지, 명시적 한글·인용 보존 기준을 정리했다. fixture SHA-256은 `805363c07b4dbbb7e9c5d9e35ec96e929441018e738a32ca249f71cdb7018ff1`이다.

72개 실측은 1Password 인증 대기 시간 초과로 시작되지 않았다. 현재 자료로 한국어 정확도 향상, 기존 모델보다 빠름, 보호 임계값이 충분하다고 주장하지 않는다. 이후 측정에서는 성공 응답만의 정확도와 전체 요청 대비 검사 완료율, 1.5초 초과율, 비용 미확인을 함께 보고해야 한다.

평가 한계: 72개 결과는 독립 원문 36개이며, 정상 사례 36개 중 23개는 마침표 외 원문과 같다. `uncertain`은 독립 상황 한 개뿐이다. 문장 생성이나 실제 음성 인식의 종단 품질을 평가하지 않으며, Choice 정답률이 최종 결과에 필요한 제안인지를 보장하지도 않는다. 자동 치환·사전 학습·모델 라우팅은 이번 구현에 포함하지 않았다.
