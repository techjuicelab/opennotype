# 0.1.13 저가 문장 모델 비교와 설치 검증

검증일: **2026-10-01 미국 동부 시간**. 기능 버전 0.1.13, 빌드 15. OpenRouter 공개 카탈로그에서 저가·최근 등록 후보를 확인한 뒤 실제 API 키로 합성 문장을 평가했다. 음성 인식과 Jev 호출을 이 문장 모델 점수에 섞지 않았다.

## 결과와 선택

**GPT-6 Luna**를 한영 혼합 받아쓰기의 첫 비교 후보로 권한다. 같은 16개에서 의미·언어/표기·정리 조건을 모두 충족했고 중앙 응답 시간은 1.02초였다. **DeepSeek V4.1 Flash**도 같은 조건을 충족했지만 3.75초였다. **Qwen3.7 Flash**는 낮은 비용과 0.96초 응답의 후보지만 표기 복원 1개와 반복 정리 1개에서 부족했다.

Solar Mini 4는 한국어 지원과 낮은 단가만으로 추천하기 어려웠다. T01에서 테스트 요청과 키 공개 금지를 삭제했고, 영어 두 문장을 한국어로 번역했다. Solar Pro 4는 같은 의미 오류는 없었지만 빈 출력 1개와 표기·정리 미완성이 있었다. GPT OSS 20B는 11개가 빈 content로 응답하여 앱이 거부했다. 이는 이번 공급자 경로와 조건의 관측이며 모델 전체의 고정 성능으로 일반화하지 않는다.

기존 Qwen3 30B와 MiMo는 각각 7개/1개 HTTP 429를 반환했다. 호출 실패를 좋은 품질로 처리하거나 비용 0으로 세지 않았다. 앱은 추가한 20개 선택지를 유지하며 계정·공급자 상태에 따라 사용 가능 여부가 달라질 수 있음을 안내한다. 기존 선택 모델은 자동으로 바꾸지 않았다.

## 방법과 한계

- 20개 모델×1문장 호환 확인 후 11개×16문장 본평가: 총 196회, 자동 재시도 없음.
- 요청은 실제 `ProviderClient`에서 캡처하고 응답도 같은 파서로 검사했다. 평가에만 출력 상한 1,024토큰을 사용했으며 앱 기본 16,384와 다르다. 긴 문장에는 추가 검증이 필요하다.
- 요청 제한 30초·동시 4개, 순서는 문항별 회전. 시간대·공급자·캐시·동시 실행의 영향이 있다. 반복 통계나 일반적인 정확도 추정이 아니다.
- 조건별 검토자는 모델 이름·가격을 가린 A~K 출력과 문항 조건만 읽었다. 별도의 Codex 에이전트가 의미·표기·정리를 구분해 판정했고 주 에이전트도 원문 결과를 확인했다. **사람의 블라인드 평가가 아니라 어시스턴트의 검토**다.
- 정규식 보조 점수는 의미 정확도가 아니다. 예를 들어 GPT-6 Luna의 `1만 2천 원`은 자동 규칙에 걸렸지만 의미는 12,000원으로 같아 조건 검토에서 통과했다.
- 보수적 예약 비용 합계 $0.2554972860. 두 실험의 보고된 비용 합계 약 **$0.01897**, 비용 미확인 요청 10개. 계정 청구 한도나 최종 명세서 확인은 아니다.
- 실제 사용자 녹음, STT 오류, 장문, 자동 입력, Jev 판정의 품질은 본평가 범위 밖이다.

## 앱·회귀 검증

- 실제 Core 제공자 테스트 26개 + 경계 검사 2개, 카탈로그/메뉴 테스트 9개, 비교 도구 Core 검사 17개 통과. 로컬 CLT에는 XCTest가 없어 headless 방식이며 정식 XCTest CI와 구분한다.
- Python 회귀 171개: 170 통과, 로컬 환경 관련 1개 skip, 실패 0.
- release 앱 빌드·엄격한 ad-hoc 서명 검증 후 `/Applications/OpenNoType.app`에 0.1.13(15) 설치. 이전 0.1.12는 로컬 백업으로 보존.
- 실제 앱 화면에서 20개 모델·단가·단위·기준일 표시, 기존 Groq STT/Qwen 문장 선택/TypeSafe 검토 설정 보존 확인.
- 설치 앱의 Jev 합성 연결 시험: TypeSafe 직접 **0.21초**, OpenRouter **0.26초**, 모두 성공. 테스트 후 TypeSafe 직접 + 입력 후 검토로 복원. 한 번의 연결 시험이며 지연 보장/정확도 결과가 아니다.

커밋의 정식 CI 결과와 설치된 최종 바이너리 식별값은 PR 검증 기록에서 확인한다. 공개 릴리스·main 병합·Developer ID 공증은 이번 작업에 포함하지 않았다.
