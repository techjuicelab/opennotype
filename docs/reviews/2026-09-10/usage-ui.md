## 수집과 비용의 경계

통계는 이 Mac의 OpenNoType에서 기능을 켠 뒤 시작한 처리에 한한다. 과거 문장 기록에서 토큰·비용을 역산하지 않으며 공급자의 계정 전체 사용액을 조회하지 않는다. 통계 수집을 위한 추가 유료 요청도 만들지 않는다.

사용량은 실제 HTTP 시도마다 기록한다. 음성 응답 뒤 문장 처리가 실패하거나, 응답 텍스트가 형식 검사에 실패하거나, 응답을 받은 뒤 취소해도 이미 확인된 사용량을 남긴다. 서버 처리 여부를 확인하지 못한 실패·취소는 금액 미확인으로 기록한다. 로컬 음성 인식은 API 요청 횟수에 더하지 않는다.

비용은 정적으로 확인한 공개 단가와 공급자 응답에 근거한 참고 통계다. 무료 한도·세금·크레딧·계정별 할인·환율·앱 밖의 사용량은 별도로 반영하지 않는다. 지원하지 않는 모델과 과금 항목은 미확인으로 남긴다. 전체 가격표, 공식 출처, 캐시 토큰 계산과 초기화 정책은 [사용량 문서](../../usage.md)에 정리했다.

대표 회귀에는 일반·캐시 토큰 중복 방지, 실제 모델 ID별 그룹, 월·주 경계, 명시적인 0과 누락 구분, 재시도 비용 보존, 기록 OFF와 문장 기록 OFF의 독립성, 저장 실패 경고의 재실행 보존, 통계 초기화 후 오래된 콜백의 기록 부활 방지가 포함된다.

교차 검수에서 발견한 기록 OFF 빈 화면의 모순, 차트의 고정된 접근성 기간 설명, 저장 기록이 전혀 없을 때 누락 경고를 초기화할 수 없는 조건, 다크 모드 강조 글자 대비를 수정했다.

## 증거와 재현

- [전체 테스트 로그](usage-evidence/swift-test.log)
- [개발 앱 빌드·서명 로그](usage-evidence/build-app.log)
- [최적화 빌드 로그](usage-evidence/release-build.log)
- Native UI는 CUA의 접근성 트리와 실제 스크린샷으로 확인했다. 사용자 통계에 샘플을 넣거나 실제 API 키·녹음을 사용하지 않았다.
- 별도 미리보기는 `AppLaunch`의 DEBUG 조건과 전용 bundle identifier에서만 활성화된다. 실제 저장소·환경 설정·키를 로드하지 않으며 네트워크 요청을 거부한다. 창 제목에 샘플임을 계속 표시하고 녹음·설정·삭제·업데이트 동작은 비활성화한다.

```sh
swift test
DEVELOPMENT_SIGNING_IDENTITY='TechJuice Local Code Signing' ./scripts/build-app.sh
DEVELOPMENT_SIGNING_IDENTITY='TechJuice Local Code Signing' ./scripts/build-usage-preview.sh dark
```

미리보기 빌드 스크립트는 debug 앱을 먼저 빌드한 뒤 `build/usage-preview/OpenNoTypeUsagePreview.app`을 만든다. 테마 인수는 `light` 또는 `dark`이며 실제 Mac 테마와 사용자 설정은 바꾸지 않는다. 실행 중인 미리보기를 종료한 뒤 다시 빌드한다.

실제 사용 데이터의 암호화 백업은 Git에서 제외된 `build/private-backups/20260910-before-usage/Data`에 보존했다. 키는 복사하지 않았으며 복원에는 기존 Keychain 암호화 키가 필요하다. 공개 배포와 push는 수행하지 않았다.
