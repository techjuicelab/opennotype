# 0.1.21 실제 검증과 현재 사용 설정

확인일: **2026-10-02 미국 동부 시간**. 제품 소스 기준은 main `05f5ab1d7cf05aa6b06940b3a547ff72d54d3e36`이다. 이번 문서 추가는 기능·버전·앱 설정을 변경하지 않는다.

## 병합·CI·설치

- 0.1.21 검토 제한 변경은 [PR #12](https://github.com/techjuicelab/opennotype/pull/12)로 main에 병합됐다. 이전 0.1.20 교정·오류 유형 학습과 0.1.19 도움 기능도 이 커밋의 이력에 포함된다.
- [main CI](https://github.com/techjuicelab/opennotype/actions/runs/37013590922)는 Swift 665건(2건 skip, 실패 0), Python 171건과 개발 앱 패키징을 통과했다. 이 결과는 위 제품 커밋 기준이다.
- 이 Mac의 `/Applications/OpenNoType.app`은 **0.1.21 (23)**이다. 실행 파일 SHA-256은 `637fcbc9a82ec56ce3414db593b395f36bbd9ae7e8fb66424119f8237007766a`이다. community ad-hoc 서명이며 Apple 공증은 하지 않았다.
- 설치 앱의 TypeSafe 연결 시험은 `jev-1.13.0`으로 성공했다(단일 호출 0.22초). 연결 성공을 일반적인 판정 정확도나 지연 보장으로 해석하지 않는다.
- 사용자가 마이크·손쉬운 사용 권한을 허용했다고 확인했다. 앞선 실제 입력 시험에서 TextEdit 테스트 문장과 `JEV로 OpenNoType을 개선하고 싶어요.`의 한국어·영어 발음을 사용자가 정상 입력으로 확인했다. 이 발화 확인은 0.1.21의 새 마이크 전체 경로 시험과 구분한다.

현재 선택은 **Groq / Whisper Large v3 Turbo → OpenRouter / GPT-6 Luna → TypeSafe 직접 Jev 입력 전 교정**이다. 해결한 오류 유형의 후속 반영 옵션도 유지한다. 사용자가 현재 설정으로 사용해 보기로 했으므로 다른 STT 연결이나 새 모델 다운로드는 진행하지 않았다.

소스 병합·push와 공개 설치 파일 배포는 별개다. 확인 당시 최신 공개 GitHub 릴리스는 **v0.1.10**이며, 이번 문서 커밋은 새 릴리스를 발행하지 않는다.

## Jev 10초 제한 실제 API 시험

0.1.21은 최초 검토와 재검토 제한을 각각 **10초**로 늘렸다. 교정 생성 제한은 **8초**이며 응답이 먼저 오면 즉시 진행한다. 교정 경로의 최대 네트워크 대기는 10+8+10=28초다. 녹음·STT·최초 문장 생성·로컬 저장 시간은 별도다. 현재 동작과 모드별 실패 처리는 [Jev 설명](../../jev-review.md)에 기록했다.

제품 `ProviderClient`·`DecisionClient`·교정 흐름으로 합성 텍스트 8건을 실행했다. 당시 문장 모델은 `qwen/qwen3-30b-a3b-instruct-2507`, 검토는 TypeSafe `jev-1.13.0`이었다. 정상 사례 4건과 오류 결과를 주입한 사례 4건이다. 이 시험은 이후 선택한 Luna와 Jev의 통합 품질 시험이 아니다.

| 관측 | 결과 |
|---|---:|
| 최초 검토 완료 | 8/8 |
| 최초·재검토 Jev 요청 | 10/10 HTTP 200, 시간 초과 0 |
| 정상 결과 유지 | 4건 |
| 교정 후 재검토 통과 | 2건 |
| 교정 생성 HTTP 429로 입력 보류 | 2건 |
| 최초 검토 응답 | 0.129~0.510초 |
| 전체 API 요청 / 전체 실행 | 18회 / 21.322초 |

교정된 예:

| 원문 기준 | 주입한 잘못된 정리 | 최종 결과 |
|---|---|---|
| 3시·2명·15달러 | 4시·3명·150달러 | 3시·2명·15달러 복원 |
| 테스트 서버만 재시작, 운영 서버는 재시작 금지 | 두 서버 모두 재시작 | 테스트만 재시작·운영 금지 복원 |

잘못된 앱 이름(`GRAV`/`OpenType`)과 결제 조건 삭제도 Jev가 오류 신호로 잡았지만 문장 제공자의 교정 생성이 HTTP 429를 반환해 입력을 보류했다. 두 사례를 교정 성공으로 세지 않는다. 정상 유지 4건에는 `어 그`가 남은 사례도 있어, 검토 통과를 모든 말버릇 제거로 해석하지 않는다.

앞선 1.5초 시험의 최초 검토 완료는 3/8, 이번은 8/8이었다. 두 번의 시점·서비스 상태가 다르므로 제한 변경만으로 응답 속도나 정확도가 개선됐다는 인과 결론을 내리지 않는다. 2초 지연을 주입한 로컬 회귀에서 두 연결 방식의 이전 제한 실패와 새 제한 통과를 따로 확인했다.

참고 단가 예약은 $0.1418359(시험 계획 $0.15 이내), 문장 제공자 보고 비용과 Jev 추정 비용 합계는 **$0.00165421275**다. 비용 미확인 요청 2건을 0원으로 처리하지 않았으며, 예약은 계정의 강제 청구 한도가 아니다. 녹음 전송·실제 앱 자동 입력·개인 기록 읽기·영구 학습 저장은 이 시험에서 수행하지 않았다.

## 증거

- [Jev API 결과](jev-timeout-live.json.gz): 합성 입력·출력·검토 신호·시간·비용.
- [Jev 제한 비교 집계](jev-timeout-comparison.json), [당시 소스 해시](jev-timeout-source-manifest.json).
- [GPT-6 Luna 문장 모델 비교](text-model-value-comparison.md): 별도 16×2 합성 문장 실제 호출.
- [STT 후보 조사](stt-options.md): 공식 자료 조사이며 실제 음성 비교 결과가 아니다.
- [파일 SHA-256](evidence.sha256): 이 문서와 증거 파일의 확인값.

압축 JSON은 `gzip -dc 파일.json.gz`로 읽을 수 있다. API 키·1Password 참조 파일·개인 녹음·실제 문장 기록·원문 오류 응답은 보관 대상에서 제외했다. 소스 manifest의 `build/.../Main.swift` 해시는 당시 로컬 시험 harness 식별값이며, 제품 소스 및 합성 결과의 보관을 완전한 실행 환경 재현으로 주장하지 않는다.
