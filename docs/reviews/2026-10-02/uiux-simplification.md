## 화면 변화

홈은 준비 상태, 세 가지 작업, 음성·문장·Jev 연결 요약, 최근 결과 순서로 정리한다. Jev 연결 경로와 현재 검토 모드를 항상 요약에 표시하고 처리 설명은 펼쳐 볼 수 있게 한다. 사이드바와 중복된 사용량·사전·복구 카드는 줄이며, 복구할 녹음이 있을 때는 별도 진입 안내를 유지한다. 원문·결과·Jev 검토·복사 동작과 표시 조건은 보존한다.

AI 연결에서는 저장된 키의 관리 영역을 접고, 키 없음·변경·인증 대기는 펼쳐 보여 준다. 저장 상태와 오류 안내는 접힌 영역 밖에 표시한다. Jev 상세 정책, 오류 유형 학습, 보조 모델과 비교는 각각 한 단계로 나눠 펼친다. 선택한 모드의 실패 동작, 전송 대상, 추가 비용 안내는 계속 보인다.

모델 메뉴의 입력·출력 가격과 비용 순서는 유지한다. 모델 ID, 단가 기준, 공식 출처와 설명은 ‘가격 기준·모델 정보’에서 확인할 수 있다. 직접 입력한 모델의 가격 확인 안내는 항상 표시한다.

## 검증 범위

- 로컬 release 앱 빌드와 strict 코드 서명 검증 통과. 검토용 산출물은 `build/uiux-review/OpenNoType-0.1.24.app`이다.
- Python 190개 테스트 통과(로컬 환경상 3개 skip). 전체 XCTest는 새 브랜치의 GitHub CI에서 확인한다.
- 세 UI 파일의 구문·diff 검사와 독립 소스 검토 완료. 기존 설정 저장, Keychain, 음성 처리, Jev 판단·교정 코드는 변경하지 않는다. 키 저장·다시 읽기·검토·입력 연습 action과 binding도 유지한다.
- 네트워크·실제 Keychain·설정 저장이 차단된 기존 디자인 검증 앱에서 영문 light 홈과 한국어 dark AI 연결 레이아웃을 확인했다. 홈의 준비 상태와 연결 상세 펼치기·접기가 동작하고, 최근 결과·원문 비교·Jev 결과의 진입점이 남아 있다. 설정의 키 미준비 상태는 펼쳐져 있고 보조 설정은 접혀 있다.
- 설정 편집은 디자인 검증 앱에서 비활성화되므로 저장된 실제 키의 편집, 전체 키보드 포커스·VoiceOver, 모든 창 크기, 새 버전의 마이크→자동 입력 경로는 이 화면 검사로 확인하지 않았다. 실제 사용 설정을 변경하거나 새 UI를 설치한 증거로 확대하지 않는다.

## 검토 시점의 적용 상태

UI 개선본은 새 브랜치의 검토 대상으로 두며 main에 병합하거나 `/Applications` 앱을 교체하지 않는다. 화면 확인 후 디자인 검증 앱을 종료하고 기존 0.1.23 사용 앱을 다시 열었다. 설치 앱과 현재 사용 설정을 유지한 상태에서 UI/UX 작업을 별도로 검토할 수 있다. Apple 공증이나 공개 릴리스 발행은 하지 않았다.
