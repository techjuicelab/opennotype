확인일: **2026-10-02 미국 동부 시간**. 제품 소스는 main `05f5ab1d7cf05aa6b06940b3a547ff72d54d3e36`(0.1.21)이다. 시험 자체는 앱 설정을 변경하지 않았으며, 이후 사용자 요청으로 문장 정리를 OpenRouter GPT-6 Luna로 선택했다. Groq STT와 Jev 직접 연결은 유지했다.

Qwen의 응답 실패 4건(T10~T13)은 HTTP 429이며 문장 품질 오류와 구분했다. 정상 응답 12개 중 10개가 세 조건을 충족했다. 나머지는 GitHub의 영문 표기를 복원하지 않은 T02와 반복·말실수를 정리하지 않은 T15다. Luna는 16개 모두 충족했다. 중앙값은 오류 응답도 포함한 모든 시도 기준이다. p95는 Luna 4.12초, Qwen 15.69초였다.

T15 원문: “어 자료는 어제 보냈어요. 어디까지 말했지, 자료는 어제 보냈어요. 답장은 아직 안 왔어요.”

- Luna: “자료는 어제 보냈어요. 답장은 아직 안 왔어요.”
- Qwen: “어, 자료는 어제 보냈어요. 어디까지 말했지, 자료는 어제 보냈어요. 답장은 아직 안 왔어요.”

이 관측에서는 Luna가 유용한 선택이었다. 한 번의 작은 합성 문장 시험이며 사용자 발음·장문·모든 공급자·일반적인 정확도의 결론은 아니다.

## 방법과 한계

- 같은 [합성 16문장](../../fixtures/text-model-value.json)에 각 모델을 1회씩, 총 32회 호출했다. 실제 Core 요청·응답 파서를 사용했다. 평가용 출력 상한만 앱의 16,384토큰에서 1,024토큰으로 줄였다.
- 요청 제한 30초, 동시 실행 1개, 문항마다 모델 순서를 회전했다. 자동 재시도는 하지 않았다. 실제 공급자는 Luna OpenAI 16건, Qwen StreamLake 정상 응답 12건이었다.
- 예약 비용 $0.04856487720, 계획 한도 $0.10이었다. 공개가격 기반 예약은 계정의 강제 청구 한도가 아니다.
- 모델·가격·시간을 가린 A/B 출력을 별도 어시스턴트가 조건별 검토했고 주 어시스턴트가 전체 결과를 확인했다. 사람의 블라인드 평가가 아니다. A=Luna, B=Qwen이며 mapping을 함께 보관했다.
- 정규식 점수를 의미 정확도로 쓰지 않았다. Luna T08의 `1만 2천 원`은 자동 규칙에 걸렸지만 의미상 12,000원과 같아 조건 검토에서 통과했다.
- 비용은 응답의 `usage.cost` 합계다. 캐시·공급자·시간대가 비용·속도에 영향을 준다. 미확인 비용 4건을 0원으로 세지 않았다.
- 실제 녹음·STT·자동 입력·Jev 판정 품질은 이 비교의 대상이 아니며 개인 기록이나 영구 학습을 읽거나 쓰지 않았다.
