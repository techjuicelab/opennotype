# OpenNoType 0.2.11 (47) 검증 보고서

## 변경 범위

0.2.10의 시각 규격을 유지하면서 설정의 분류·명명·직접 이동·복귀 경로를 정리한다. [감사와 최종 이동표](settings-0.2.11-audit.md), [릴리스 노트](../../releases/v0.2.11.md)를 참고한다.

메인 포함 4개 에이전트가 실제 병렬로 전체 분류/중앙 이동, AI·Jev 연결 구조, 권한·홈 진입, 횡단 명명과 조회/실행 화면을 나누어 작업했다. 조사 후 공통 계약을 정하고 서로 다른 담당자가 교차 검토했다.

## 검증 상태

- Swift 최종 전체 검사: 1,224개 중 1,222개 통과·기존 opt-in 2개 제외·실패 0. 플랫폼 584개와 Core 640개를 분리 확인했다.
- Python 전체 검사: 209개 중 207개 통과·환경 조건 2개 제외·실패 0.
- 새 이동 경로 검사 3개는 목적 탭·잔여 상세 초기화·설정값 불변·키 미접근·입력 테스트 미준비를 검증한다. 최초 실행은 테스트 모델의 기본 초기화가 모의 키를 읽어 6개 assertion에서 실패했다. 캐시 초기화를 명시한 fixture로 바로잡은 뒤 단일 3개와 전체 검사가 통과했다. 제품의 키 접근 계약이나 assertion을 완화하지 않았다.
- DEBUG 합성 앱과 로컬 인증서 서명의 arm64 release 앱 빌드·strict 서명 검증이 통과했다.
- 별도 식별자 합성 앱에서 설정 6탭, 세 연결의 동일 구조, 자동 검토와 연결의 분리, Mac 권한·입력 테스트 상세, 사전 학습→개인정보 이동을 실제 창으로 확인했다.
- 검토 연결→공유 문장 키→공유 음성 키→뒤로 두 번을 확인했다. 닫기·Escape·다른 분류 선택, 비활성 권한 옵션의 도움말 열기/닫기·도움말 버튼 포커스 복귀도 확인했다.
- 모델 파일·메모리 상세의 미리보기는 상태와 실험 설정 링크만 표시하며, 실험 설정으로 이동할 때 기존 sheet가 닫히는 것을 확인했다. Home의 Mac 접근 권한 버튼은 상세를 직접 연다.
- 네이티브 검증은 합성 데이터·읽기 전용 옵션으로 진행했다. 실제 녹음·유료 API·외부 앱 입력을 실행한 검증이 아니다. 창은 기존 미리보기 창의 최소 폭 960pt 배치로 확인했으며 1120×760pt를 수동으로 정확히 측정한 결과는 아니다.
- 이 Mac 설치·원격 CI·공개 자산·Latest 검증은 다음 단계다. 완료된 실제 결과만 후속 기록에 추가한다.

## 검증 경계

실제 음성 인식 정확도, 유료 API 처리 품질, 모든 외부 앱 입력, 새 Mac Gatekeeper·Intel·VoiceOver 전수 검증은 이번 설정 정비의 검증 범위에 포함하지 않는다. 기존 사용자 API 키 값은 읽거나 출력하지 않으며 설치 직전의 최신 설정과 데이터를 기준으로 보존을 확인한다.
