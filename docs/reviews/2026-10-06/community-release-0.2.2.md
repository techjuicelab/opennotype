# 0.2.2 커뮤니티 배포 검증

대상은 `v0.2.2` / build34 / macOS14 이상 / arm64다. 사용자가 2026-10-06에 main 병합과 공개 배포를 요청했다. 이전 공개본은 `v0.1.26`(28)이다.

현재 이 보고서는 배포 준비 단계다. 최종 소스의 CI·메뉴바 수정 검증·main 병합·태그·공개 산출물 확인 결과를 완료한 뒤 아래에 기록한다. 이전 build33의 CI 결과나 실행 앱을 build34의 증거로 재사용하지 않는다.

## 배포 기능과 한계

받아쓰기 출력 언어 선택, 별도 번역 단축키, 원문·번역·당시 목표 언어 확인, 의미와 문장 흐름 보강 및 선택형 입력 전 번역 검토를 포함한다. 번역 검토는 기본 꺼짐인 실험 기능이며 추가 전송·비용이 있다. 실제 비교에서도 의미·표현 오류가 남고 정상 번역을 보류할 수 있다. 자동 재번역이나 정확도 보장은 아니다. [번역 검증 기록](native-translation-0.2.2.md)을 참고한다.

배포 방식은 기존 `community`를 유지한다. 앱은 ad-hoc 코드 서명, 업데이트 ZIP은 기존 Sparkle Ed25519 키로 서명하며 Developer ID·Apple 공증은 사용하지 않는다. [배포 운영 안내](../../updates.md)에 설치와 권한 재승인 범위를 설명한다.

## 최종 확인 결과

아직 공개 완료를 기록하지 않았다. 공개 파일·서명·최신 피드 확인과 실제 녹음·입력·자연 발화 품질·권한 유지 검증은 각각 구분한다.
