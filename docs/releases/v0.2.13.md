# 0.2.13 (49) — 입력 지연 제거와 로컬 모델 버전 고정

- 녹음 후 바로 입력: AI 요청마다 사용량 기록을 암호화 저장소에 저장하느라 다음 요청과 자동 입력이 늦어지던 문제를 고쳤습니다. 기록은 뒤에서 저장하고, 작업은 저장을 마친 뒤 끝납니다. 사용량 10,000건·기록 3,000개 합성 저장소에서 결과 준비 전 추가 대기가 약 1.65초에서 3 ms로 줄었습니다.
- 더 빠른 로컬 저장소: 암호화 저장소를 한 번 복호화한 뒤 파일이 바뀌지 않으면 재사용합니다. 같은 규모에서 화면 갱신 읽기는 102 ms에서 1 ms, 사용량 1건 저장은 420 ms에서 214 ms가 됐습니다. 저장 형식은 바꾸지 않았습니다.
- 안전한 녹음 종료: 녹음을 마칠 때 변환·저장 작업을 최대 5초만 기다리고, 제때 끝나지 않은 녹음은 앱을 멈추게 하지 않고 읽지 않은 채 삭제합니다. 실시간 미리보기는 저장 작업을 기다리지 않습니다.
- 로컬 모델 버전 고정: Whisper 모델·토크나이저·화자 모델을 고정한 공개 저장소 커밋에서만 받고, 파일별 크기와 SHA-256이 모두 일치해야 사용합니다. 일치하지 않는 파일은 지우고 준비를 실패로 끝냅니다. 이미 받은 같은 내용의 파일은 다시 받지 않습니다.
- 보안 취약점은 GitHub 비공개 제보로 받습니다.

기존 API 키·모델 설정·암호화 기록·입력 보호 정책은 유지합니다. 측정은 합성 데이터 기준이며 네트워크 지연을 포함하지 않습니다. 실제 마이크·다른 앱 입력·인식 정확도 향상을 측정한 배포는 아닙니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
