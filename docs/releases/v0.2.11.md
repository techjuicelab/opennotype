# 0.2.11 (47) — 설정 구조와 메뉴 일관성 개선

- AI 연결을 음성 인식·문장 처리·문장 검토(Jev)의 세 연결로 통일했습니다. 모두 같은 연결 설정 버튼을 사용하며, API 키와 연결 테스트를 자동 검토 방식에서 분리했습니다.
- 자동 검토 방식·번역 보호·추가 도움은 받아쓰기에서 조정합니다. 사용량·비용은 같은 이름의 독립 화면에서 확인합니다.
- 필수 Mac 접근 권한과 녹음 없는 입력 테스트는 앱 설정에서 제공합니다. 실험·진단에는 실험 옵션, 모델 비교, 처리 진단을 목적별로 모았습니다.
- 중복 옵션과 잘못된 이동 경로를 정리했습니다. 권한·검토 연결이 필요한 경우 해당 상세를 직접 열며, 공유 API 키를 확인한 뒤 이전 상세로 돌아갈 수 있습니다.
- 화면을 여는 버튼과 실제 비교·테스트를 시작하는 버튼을 구분하고, 사전의 교정 학습 설정도 정식 설정 화면으로 연결했습니다.

기존 API 키·모델 선택·암호화 기록·입력 보호·검토 실패 정책을 유지합니다. 이번 버전은 설정 탐색 개선이며 인식 정확도나 처리 속도 향상을 측정한 배포는 아닙니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
