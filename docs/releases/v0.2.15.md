# 0.2.15 (51) — UI/UX 전면 개선 및 로그인 항목 실행 창 안정화

- **로그인 항목 실행 시 관리 창 안정화**: macOS 로그인 항목 실행에서 SwiftUI 창 씬이 생성되지 않았을 때 AppKit 대체 관리 창으로 자동 전환해 메뉴바에서 즉시 창을 열 수 있게 했습니다. 창 위치·크기 자동 저장, 중복 SwiftUI 창 지연 정리 및 포커스 복구, 식별자 없는 외부 창 오인 차단을 함께 적용했습니다.
- **VoiceBar HUD 및 메뉴바 개선**: 디스플레이별 위치 기억, 모드 배지·15막대 실시간 파형, 복사·열기 액션이 포함된 상태별 토스트를 적용했습니다. 메뉴바에 준비 필요 바로가기와 받아쓰기 방식·출력 언어 빠른 전환 하위 메뉴를 추가했습니다.
- **관리 화면·단축키·안내 개선**: 첫 설치 시 안내 창 1회 자동 표시, 상단 상태 막대 정리, 홈 빠른 시작 카드·키캡 표시·앱 단축키(`⌘1`–`⌘5`, `⌘,`, `⌘F`, `⌘N`, `⌘⇧C`)를 추가했습니다. 멀티라인 `TextEditor` 포커스 시 `⌘F`는 에디터 내장 찾기 막대로 위임하며, 경고·미리보기 고지 배너와 자동 닫힘 성공 토스트(창이 화면에 보일 때만 타이머 동작)를 분리했습니다.
- **기록·사전·사용량·음성/설정 개선**: 기록 모드 필터·앱 친화 이름·일본어/중국어 및 줄바꿈을 지원하는 변경점 하이라이트·필터 결과 캐싱을 추가했습니다. 사전 분류 필터, 충돌 항목 덮어쓰기를 막는 안전한 삭제 되돌리기, 사용량 일별 차트 호버 툴팁, 음성 모델 직접 다운로드·취소, 2열 예시 비교 시트, 단축키 기본 복원 및 구조화된 도움말 팝오버를 적용했습니다.
- 0.2.14 (50)까지의 개선(영어 설정 분류 선택기 수정, 입력 지연 제거, 저장소 재사용, 녹음 종료 보호, 로컬 모델 고정·검증)을 그대로 포함합니다.

기존 API 키·모델 설정·암호화 기록·입력 보호 정책은 유지합니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
