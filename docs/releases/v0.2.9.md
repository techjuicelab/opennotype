# 0.2.9 (45) — 설정 정리와 음성 입력 개선

- 설정을 옵션 이름과 현재값 중심으로 정리했습니다. 긴 설명은 이름 옆 `?`에서 확인하고, 현재 미적용 이유·추가 비용·입력 보류 조건은 화면에 짧게 남깁니다. 키보드 탐색과 도움말 닫기 후 포커스 복원을 지원합니다.
- 홈의 최근 결과와 검토를 위로 옮겨 원문 비교·복사를 쉽게 찾을 수 있습니다.
- 준비된 로컬 모델로 인식한 문장을 AI 정리·자동 Jev 검토 없이 입력하는 **빠른 로컬 받아쓰기**를 추가했습니다. 말한 언어를 유지하는 해당 경로는 음성과 문장을 외부 AI로 보내지 않습니다.
- 누르는 동안 녹음과 짧게/길게 누르기 혼합 동작, 마이크 지정, 선택형 준비·종료 알림음과 녹음 중 시스템 음소거를 추가했습니다.
- Large v3·Small·Base 모델 선택, 모델 파일 관리와 미사용 시 메모리 해제를 지원합니다. 녹음 중 미리보기와 같은 음성으로 로컬 모델을 비교하는 도구는 선택형 실험 기능입니다.
- 녹음 중단·데이터 전달·종료 실패를 확인해 불완전 녹음의 자동 입력을 막는 보호와 실패 복구를 강화했습니다. 키보드 배열에 맞는 붙여넣기 키 해석도 추가했습니다.
- 앱을 열면 메뉴바에서 대기하고, 메뉴바에서 설정·기록 창을 다시 열 수 있습니다.
- 이전 공개 버전 이후 추가한 음성 작업 프롬프트 생성·Jev 검토·외부 앱 입력, 앱 활성화와 입력 준비 대기도 이번 공개 버전에 포함합니다. 홈의 프롬프트 녹음은 복사용이며 AI에 자동 제출하지 않습니다.

기존 설정과 AI 정리·toggle·Large v3 기본값을 유지합니다. 녹음 미리보기·효과음·음소거·번역 다듬기 등은 기본 꺼짐입니다. 번역 다듬기와 추가 검토를 켜면 요청·비용·대기가 늘 수 있습니다.

한영 혼용 인식 정확도나 체감 속도의 일반적인 향상을 입증한 릴리스는 아닙니다. 자동 테스트·합성 음성·네이티브 UI 검증과 실제 마이크·앱 입력·자연 발화 검증의 범위는 구분합니다. Apple silicon·macOS 14 이상을 지원합니다.
