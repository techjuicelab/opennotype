# 0.2.10 (46) — 전체 UI/UX 재디자인

- 앱 전체의 글자·행 높이·컨트롤·여백·패널 규격을 통일했습니다. 사이드바와 툴바를 간결하게 만들고, 긴 일반 설명은 항목 옆 `?` 도움말에서 확인하도록 정리했습니다. 현재 오류·추가 비용·입력 보류·미적용 이유는 짧게 남깁니다.
- 받아쓰기는 준비 상태와 최신 결과를 중심으로 바꿨습니다. 큰 기능 소개 카드 대신 단축키와 작업 진입을 모으고, 녹음·처리·결과·원문 비교·검토 흐름을 같은 크기 기준으로 정리했습니다.
- 기록은 목록과 선택한 한 건의 상세로 나눴습니다. 개인 사전은 검색·단어 목록·추가가 먼저 보이고, 편집은 시트에서, 교정 학습과 이름 후보는 탭에서 관리합니다.
- 설정을 받아쓰기 / 녹음·단축키 / AI 연결 / 개인정보 / 앱 관리 / 고급 도구로 나눴습니다. 관련 옵션은 같은 패널의 정렬된 행으로 묶고, 언어·표현 예시와 키·모델·화자·권한 상세도 함께 정리했습니다.
- 실패 녹음 복구는 기록의 별도 탭에서 제공합니다. 사용량·음성 모델·두 비교 도구·프롬프트·Jev 검토와 앱의 편집·비교·도움말 UI에도 같은 규격을 적용했습니다. macOS 파일 선택·시스템 확인·Sparkle 창은 기존 네이티브 동작을 유지합니다.

기존 기능·설정·키 저장·암호화 기록·실패 원음 수명·외부 앱 입력 보호·Jev 실패/보류 정책을 유지합니다. 이 버전은 UI/UX 재디자인이며 인식 정확도나 처리 속도의 일반적인 개선을 입증한 배포는 아닙니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
