# 0.2.12 (48) — AI 모델 선택 통일

- 온라인 음성 인식·문장 처리·보조 모델·문장 모델 비교에서 같은 모델 선택기를 사용합니다. 목록의 마지막 ‘직접 입력 (Custom)…’을 선택하면 모델 ID를 입력할 수 있습니다.
- 직접 입력은 ‘적용’ 또는 Return으로 확정합니다. 입력 중에는 기존 모델을 유지하며, 제공자 전환·외부 설정 변경·비활성 상태에서도 다른 연결에 초안이 저장되지 않도록 보호합니다.
- OpenAI·Claude 문장 모델과 OpenAI·Groq·OpenRouter 음성 모델 목록을 제공합니다. 모델 정보·참고 가격·확인일·출처는 같은 위치에서 확인합니다. 목록은 계정 사용 권한이나 인식 품질을 보장하지 않습니다.
- 문장 모델 비교도 같은 선택기에서 2~3개를 지정합니다. 직접 입력한 모델의 단가를 확인하지 못하면 비교 요청을 보내지 않으며, 기존 승인·예산·취소 보호를 유지합니다.
- 최근 OpenAI 모델·요청 정책·비용 계산 개선을 함께 반영합니다. GPT-6 Luna의 정리·수정·프롬프트는 reasoning none, 번역은 medium을 지정하고, 확인된 캐시·긴 문맥 요율을 비용 추정에 반영합니다. Claude 목록의 확인된 요율도 연결합니다.
- 로컬 음성 엔진과 Jev 검토 모델은 설치 파일·토크나이저 또는 검토 응답 계약에 묶인 지원 목록을 유지하고, 직접 입력이 제공되지 않는 이유를 도움말에 표시합니다.

기존 API 키·기본 모델·암호화 기록·입력 보호·검토 실패 정책을 유지합니다. 실제 인식 정확도·처리 속도 향상을 측정한 배포는 아닙니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
