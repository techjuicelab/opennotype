# 0.2.14 (50) — 영어 설정 화면 넘침 수정

- 영어 화면에서 설정 분류 선택기가 가장 긴 이름(‘Experiments & diagnostics’)에 맞춰 모든 칸을 넓혀, 설정 페이지 전체가 창보다 넓어지고 사이드바와 오른쪽 내용이 잘리던 문제를 고쳤습니다.
- 선택기에는 짧은 이름(Recording, Experiments)을 쓰고 페이지 제목은 전체 이름을 유지합니다. 창이 좁아 들어가지 않으면 메뉴 선택기로 바뀝니다. 한국어 화면은 같은 이름을 그대로 씁니다.
- 0.2.13 (49)의 개선(입력 전 사용량 저장 지연 제거, 저장소 재사용, 녹음 종료 보호, 로컬 모델 버전 고정·검증)을 그대로 포함합니다.

기존 API 키·모델 설정·암호화 기록·입력 보호 정책은 유지합니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
