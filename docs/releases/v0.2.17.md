# 0.2.17 (53) — 설정 재설계와 기능별 AI 모델

- **5개 탭 설정**: 설정을 받아쓰기, 녹음, AI·비용, 개인정보, 앱의 5개 탭으로 나눴습니다. 자주 바꾸는 항목은 바로 보이고, 자세한 항목은 펼쳐서 봅니다. 상단의 "AI 모델·비용" 버튼으로 AI 탭을 바로 엽니다.
- **기능별 AI 모델**: 받아쓰기 정리 외에 번역, 선택 문장 수정, 프롬프트 만들기, 번역 다듬기마다 모델을 따로 고를 수 있습니다. 따로 고르지 않은 기능은 지금처럼 정리 모델을 씁니다(번역 다듬기는 번역 모델을 먼저 따릅니다).
- **새 모델 후보 검색**: 공개 OpenRouter 목록과, 키가 이미 불러와진 제공자(OpenAI·Groq·Anthropic)의 목록에서 모델을 찾습니다. 첫 검색은 기준만 잡고, 그 뒤에 처음 보이는 모델을 "새 후보"로 표시합니다. OpenRouter 후보는 구조화된 출력을 지원하는 유료 텍스트 모델만 보여 줍니다.
- **호환성 테스트**: 고른 모델로 짧은 합성 요청을 실제 처리 경로에 보내 통과 여부, 걸린 시간, 응답한 모델, 비용을 보여 줍니다. 결과는 이 Mac에 저장됩니다.
- **단가와 비용**: 모델별 입력·출력 단가와 가격 출처, 이번 달 기능별 비용, 최근 사용량에 현재 모델 단가를 적용한 월 예상 비용, 선택형 월 예산을 보여 줍니다. 비용을 확인할 수 없는 요청은 0원이 아니라 "미확인"으로 셉니다.
- **API 키 정리**: 제공자별 키 상태를 한곳에서 보고 "키 확인"으로 확인합니다. 저장된 키는 직접 확인할 때만 Keychain에서 읽습니다.
- **Jev 검토**: 받아쓰기 정리 제공자가 OpenRouter가 아니어도, OpenRouter 키가 있으면 Jev 검토를 쓸 수 있습니다.
- 0.2.16 (52)의 AirPods 녹음 수정까지 그대로 포함합니다.

기존 API 키·모델 설정·암호화 기록·입력 보호 정책은 유지합니다. 기능별 모델과 월 예산은 새 설정 항목으로 추가되며 기존 설정 파일과 호환됩니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
