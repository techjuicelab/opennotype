# 0.2.16 (52) — AirPods 마이크 녹음 수정

- **AirPods가 기본 입력일 때 녹음됩니다**: 마이크를 시스템 기본값으로 두면 녹음 엔진이 macOS 기본 입력을 그대로 따라갑니다. 이전에는 기본 장치를 직접 지정해서 열었기 때문에, AirPods 헤드셋 마이크가 24 kHz로 바뀌어도 48 kHz 탭이 그대로 남았습니다. 그래서 "마이크를 준비하고 있어요"에서 5초를 기다린 뒤 "마이크에서 음성 데이터를 받지 못했습니다"로 끝났습니다. 이제 AirPods를 끼면 AirPods로, 빼면 원래 마이크로 녹음합니다.
- **설정에서 고른 마이크의 형식 변경 대응**: 첫 음성이 들어오기 전에 입력 형식이 바뀌면 같은 엔진에서 Core Audio 샘플레이트에 맞춰 다시 준비합니다(최대 3회). 설정에서 고른 블루투스 마이크가 1.5초 동안 무음이면 한 번 더 준비합니다.
- **앱 종료 방지**: 형식이 맞지 않아 입력 탭 생성이 거부되면 앱이 종료되지 않고 녹음 오류로 표시됩니다.
- 재준비가 일어나면 `app.opennotype.mac` / `recording` 로그에 남깁니다.
- 0.2.15 (51)까지의 개선을 그대로 포함합니다.

기존 API 키·모델 설정·암호화 기록·입력 보호 정책은 유지합니다.

Apple silicon·macOS 14 이상, community 배포(ad-hoc 앱 서명·Sparkle Ed25519 서명), Apple 공증 없음.
