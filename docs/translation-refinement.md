# 선택형 번역 문장 다듬기

이 문서는 `codex/translation-quality-pass`의 개발 기능을 설명합니다. 공개 v0.2.3 또는 현재 설치 앱에 포함되었다는 의미가 아닙니다.

## 처리 흐름

기본값은 꺼짐입니다. 설정의 입력·단축키 영역에서 **번역 문장 다듬기 · 실험 기능**을 켜면 다음 번역 처리부터 적용합니다. 받아쓰기의 번역 출력, 별도 번역 단축키, 복구 녹음 재시도와 기록의 문장 다시 처리가 대상입니다. 같은 언어 받아쓰기와 선택 문장 수정에는 적용하지 않습니다.

1. 기존 음성 인식과 번역으로 초안을 만듭니다.
2. 같은 문장 서비스·모델에 인식 원문, 초안, 목표 언어, 선택한 말투·형식, 관련 사전 힌트를 보내 한 번 다듬습니다. 주변 문맥은 이 추가 요청에서 재전송하지 않습니다.
3. 선택형 Jev 번역 보호가 켜져 있으면 **최종 번역안**을 한 번 검토합니다. 기존 보류 기준은 유지합니다.
4. 처리와 입력 조건을 통과한 최종 번역을 입력하고 기존 보관 설정에 따라 기록합니다. 기록 다시 처리는 미리보기만 만들며 기존 기록을 덮어쓰거나 자동 입력하지 않습니다.

다듬기 모델은 원문을 사실의 기준으로 삼고 초안을 신뢰되지 않은 후보로 취급합니다. 조건·부정·수량·불확실성·요청 강도·주체·독립적인 목적·의도적인 강조를 유지하면서 어색한 결합, 문장 구조와 불필요한 재진술을 다듬도록 요청합니다. 모호한 원문에서 뜻을 추측하거나 새 사실을 추가할 권한은 없습니다. 자연스럽고 충실한 초안은 그대로 반환할 수 있습니다.

## 제한과 실패 처리

- 추가 문장 요청은 최대 한 번이며 HTTP 오류도 재시도하지 않습니다. 최대 시간은 기존 요청 제한과 30초 중 작은 값입니다. 추가 시간과 API 비용이 발생할 수 있습니다.
- 원문과 초안의 합, 원문과 최종 번역의 합은 각각 UTF-8 24,000바이트 이내입니다. 전체 프롬프트는 64,000바이트 이내이며 잘라서 보내지 않습니다.
- 비어 있거나 유효하지 않은 응답, 크기 초과, 로컬 보존 검사 실패와 연결 실패는 자동 입력을 보류합니다. 원문이나 초안을 자동 입력하는 대체 경로는 없습니다.
- 취소 또는 진행 중 옵션·기록 보관 설정 해제로 늦게 온 결과가 입력되지 않도록 작업과 설정 세대를 확인합니다. 기록 삭제·보관 해제·새 작업은 초안 표시 상태를 정리합니다.
- 초안과 다듬기 상태는 메모리에만 표시합니다. 기존 기록 형식에 중간 초안은 추가하지 않습니다. 실패 응답도 과금될 수 있으므로 받은 사용량은 기존 사용량 보관 정책에 따라 집계합니다.

로컬 검사는 코드·URL 등 제한적인 문자 보존과 일부 시간 표현을 확인합니다. 모든 의미나 문체를 판정하지 않습니다. Jev도 뜻 보존 위험에 대한 참고 신호이며 원어민 표현의 품질 인증이 아닙니다. 다듬기 완료와 Jev 검토 완료, 실제 입력 성공은 별도로 표시합니다.

## 평가 방법

프롬프트 구현 전에 한국어 합성 발화 8개(영어 4·일본어 4)를 고정했습니다. 정답 번역을 제공하지 않고 의미 보존·금지 변경·허용 변형·자연스러움 기준을 평가에만 사용합니다. 이 기준은 모델 요청에 포함하지 않습니다. 작성자는 기존 문제 유형과 설계 방향을 알고 있으므로 독립적인 모집단이나 원어민 사람의 평가를 대표하지 않습니다.

실제 비교는 새 문장 8개와 알려진 문제 4개를 구분해 수행합니다. 각 원문에서 기존 경로로 초안을 한 번 생성하고, **그 동일한 초안**을 추가 단계에 전달합니다. 최대 24회 문장 요청이며 재시도와 Jev 호출은 하지 않습니다. 코드·입력·설정 지문을 묶어 보관하고, 두 결과의 표시 순서를 가린 뒤 의미 보존을 먼저, 자연스러움을 다음으로 검토합니다. HTTP 성공과 문자열 변경만으로 품질 개선으로 판정하지 않습니다.

구현·전송 계약 검증, 정식 Xcode CI, 실제 모델 품질 비교와 설치 앱 검증은 각각 별도의 증거입니다. 실제 평가가 완료되기 전에는 품질 개선 수치를 제시하거나 기본값을 켜지 않습니다.
