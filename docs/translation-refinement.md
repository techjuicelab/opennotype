# 선택형 번역 문장 다듬기

현재 `/Applications/OpenNoType.app`은 로컬 0.2.4(40)이며 공개 다운로드는 v0.2.3입니다. 이 실험 기능은 공개 v0.2.3에는 포함되지 않습니다. 5차의 제한된 품질 관찰에 따라 main에 반영하고 설치 파일·서명·첫 실행 전 설정과 암호화 데이터 보존을 확인했습니다. 실제 실행 경로와 창의 0.2.4(40) 표시도 확인했으나 Keychain·설정 준비가 진행 중입니다. 이때 마이크·손쉬운 사용은 ‘허용 필요’로 표시됐으며, 초기화 완료 전 표시만으로 권한이나 키가 유실됐다고 판단하지 않습니다. 사용자 인증 완료와 실제 입력 검증은 대기 중입니다. 후보39까지의 채택 보류 이력과 당시 판정은 유지합니다. [설치 기록](reviews/2026-10-07/local-install-0.2.4-build40.md)에서 파일 설치·실행·입력 준비를 구별합니다.

## 처리 흐름

기본값은 꺼짐입니다. 설정의 입력·단축키 영역에서 **번역 문장 다듬기 · 실험 기능**을 켜면 다음 번역 처리부터 적용합니다. 받아쓰기의 번역 출력, 별도 번역 단축키, 복구 녹음 재시도와 기록의 문장 다시 처리가 대상입니다. 출력 언어를 말한 언어 유지로 둔 일반 받아쓰기와 선택 문장 수정에는 적용하지 않습니다. 번역 출력 언어가 실제 발화 언어와 같아도 이 단계는 적용됩니다.

1. 기존 음성 인식과 번역으로 초안을 만듭니다.
2. 같은 문장 서비스·모델에 인식 원문, 초안, 목표 언어, 선택한 말투·형식, 관련 사전 힌트를 보내 한 번 다듬습니다. 주변 문맥은 이 추가 요청에서 재전송하지 않습니다.
3. 선택형 Jev 번역 보호가 켜져 있으면 **최종 번역안**을 한 번 검토합니다. 기존 보류 기준은 유지합니다.
4. 처리와 입력 조건을 통과한 최종 번역을 입력하고 기존 보관 설정에 따라 기록합니다. 기록 다시 처리는 미리보기만 만들며 기존 기록을 덮어쓰거나 자동 입력하지 않습니다.

다듬기 모델은 원문을 사실의 기준으로 삼고 초안을 신뢰되지 않은 후보로 취급합니다. 조건·부정·수량·불확실성·요청 강도·주체·독립적인 목적·의도적인 강조를 유지하면서 어색한 결합, 문장 구조와 불필요한 재진술을 다듬도록 요청합니다. 원문과 발화 안의 문맥이 뒷받침하지 않는 새 사실·관계·수행자를 추가할 권한은 없습니다. 자연스럽고 충실한 초안은 그대로 반환할 수 있습니다.

생성과 다듬기는 원문의 각 절에 있는 행동·상태·판단, 참여자와 화행의 관계를 기준으로 목표 언어의 서술을 구성합니다. 가벼운 두서없음을 강한 혼란으로 확대하지 않고, 전달하려는 내용과 말의 사전적 뜻풀이를 구별합니다. 같은 명제를 같은 기능으로 완곡하게 표현한 경우만 자연스럽게 합치며, 별개의 조건·판단·강조는 유지합니다. 도입 제안의 수락·거절과 이미 진행 중인 활동의 계속·중단도 구별합니다. 수동태·명사절·중단 표현 자체를 금지하지 않으며 그 문맥에서 어색할 때만 고칩니다. 원문이 뒷받침하는 개인 계획은 보존합니다.

## 수행자 표현 정책

사용자가 정한 후속 정책은 **생략된 주어라도 발화 문맥상 화자 자신의 일로 자연스럽게 읽히면 `I`를 허용**하는 것입니다. 판단·약속의 소유자와 행동 수행자는 구별하되, 문맥이 뒷받침하는 화자의 행동까지 무조건 비인칭으로 바꾸지 않습니다. 반대로 화자가 말한다는 이유만으로 모든 행동을 화자에게 돌리거나 원문에 없는 팀·관계를 만들지 않습니다. 명시된 다른 수행자, 담당자 미정, 역할 제한과 약속·의무·가능성의 범위는 유지합니다. 일본어의 자연스러운 주어 생략도 허용합니다.

이 정책은 로컬40에 반영한 계약입니다. [5차 비교](reviews/2026-10-07/translation-idiomatic-polish-round5-results.md)는 입력·초안·설정·평가 기준을 먼저 고정하고, 문맥상 화자 자신의 일인 경우와 명시된 타인·미정 수행자·서로 다른 소유 관계를 나누어 확인했습니다. [3차](reviews/2026-10-07/translation-idiomatic-polish-round3-results.md)와 [4차](reviews/2026-10-07/translation-idiomatic-polish-round4-results.md)는 당시 고정 기준에 따른 기록이며, 새 정책을 이유로 기존 의미 판정이나 선호를 소급 변경하지 않습니다. 자연스러운 표현, 의미 보존과 실제 설치·입력 성공은 각각 별도의 증거입니다. 이번 제한된 관찰만으로 모든 수행자 오류가 해결되거나 전반적인 자연스러움이 개선됐다고 결론내리지 않습니다.


## 제한과 실패 처리

- 추가 문장 요청은 최대 한 번이며 HTTP 오류도 재시도하지 않습니다. 최대 시간은 기존 요청 제한과 30초 중 작은 값입니다. 추가 시간과 API 비용이 발생할 수 있습니다.
- 원문과 초안의 합, 원문과 최종 번역의 합은 각각 UTF-8 24,000바이트 이내입니다. 전체 프롬프트는 64,000바이트 이내이며 잘라서 보내지 않습니다.
- 비어 있거나 유효하지 않은 응답, 크기 초과, 로컬 보존 검사 실패와 연결 실패는 자동 입력을 보류합니다. 원문이나 초안을 자동 입력하는 대체 경로는 없습니다.
- 취소 또는 진행 중 옵션·기록 보관 설정 해제로 늦게 온 결과가 입력되지 않도록 작업과 설정 세대를 확인합니다. 전체 기록 삭제·해당 미리보기 기록 삭제·보관 해제·새 작업은 초안 표시 상태를 정리합니다. 무관한 과거 기록 한 개를 삭제해도 현재 번역 작업은 계속할 수 있습니다.
- 초안과 다듬기 상태는 메모리에만 표시합니다. 기존 기록 형식에 중간 초안은 추가하지 않습니다. 실패 응답도 과금될 수 있으므로 받은 사용량은 기존 사용량 보관 정책에 따라 집계합니다.

로컬 검사는 코드·URL 등 제한적인 문자 보존과 일부 시간 표현을 확인합니다. 모든 의미나 문체를 판정하지 않습니다. Jev도 뜻 보존 위험에 대한 참고 신호이며 원어민 표현의 품질 인증이 아닙니다. 다듬기 완료와 Jev 검토 완료, 실제 입력 성공은 별도로 표시합니다.

## 평가 방법

최초 실험은 프롬프트 구현 전에 한국어 합성 발화 8개(영어 4·일본어 4)를 고정했습니다. 정답 번역을 제공하지 않고 의미 보존·금지 변경·허용 변형·자연스러움 기준을 평가에만 사용했습니다. 이 기준은 모델 요청에 포함하지 않았습니다. 작성자는 기존 문제 유형과 설계 방향을 알고 있으므로 독립적인 모집단이나 원어민 사람의 평가를 대표하지 않습니다.

당시 비교는 새 문장 8개와 알려진 문제 4개를 구분했습니다. 각 원문에서 기존 경로로 초안을 한 번 생성하고, **그 동일한 초안**을 추가 단계에 전달했습니다. 24회 문장 요청에 재시도와 Jev 호출은 없었습니다. 코드·입력·설정 지문을 묶어 보관하고, 두 결과의 표시 순서를 가린 뒤 의미 보존을 먼저, 자연스러움을 다음으로 검토했습니다. HTTP 성공과 문자열 변경만으로 품질 개선으로 판정하지 않습니다.

구현·전송 계약 검증, 정식 Xcode CI, 실제 모델 품질 비교와 설치 앱 검증은 각각 별도의 증거입니다. 평가 결과가 있다는 이유로 기본값을 켜거나 모든 번역의 품질을 보장하지 않습니다.

1차 24회와 후속 11회 실제 비교, 각 후보의 Xcode CI를 완료했습니다. 특정 약속·의무의 의미 오류는 후속에서 개선했지만 알려진 영어·일본어의 어색한 구조는 남아 일반적인 품질 향상은 입증되지 않았습니다. 기능 검사의 통과가 원어민 표현의 품질 합격을 뜻하지 않습니다. 사용자의 메인·설치 반영 요청에 따라 당시 기본값이 꺼진 실험 옵션으로 0.2.4(36)에 포함했고, 공개 v0.2.3에는 반영하지 않았습니다. [1차 평가](reviews/2026-10-06/translation-refinement-round1.md)와 [후속 결과 및 당시 적용 판단](reviews/2026-10-06/translation-refinement-round2.md)은 평가 시점의 기록으로 보존합니다.


이후 관용 표현 개선은 별도 반복 평가로 진행했습니다. [관용 표현 1차](reviews/2026-10-07/translation-idiomatic-polish-round1.md), [2차 준비](reviews/2026-10-07/translation-idiomatic-polish-round2.md), [2차 결과](reviews/2026-10-07/translation-idiomatic-polish-round2-results.md)는 각각 당시 결과와 채택 보류 사유를 보존합니다. 후속 지침과 최종 적용 범위는 [PR #27](https://github.com/techjuicelab/opennotype/pull/27)에 기록합니다. 조건당 한 응답인 선택된 합성 사례의 관측을 일반적인 품질 보장이나 사람 원어민 검수로 확대하지 않습니다.

5차는 OpenRouter `openai/gpt-6-luna`, `medium`으로 12회·6쌍을 비교했습니다. 신규 원문 4개와 알려진 일본어 원문 2개이며, 생성 3쌍과 동일 초안 정제 3쌍은 서로 다른 원문이므로 연속 처리 검증이 아닙니다. 네 AI는 같은 12개 출력에서 이번 기준의 명확한 의미 실패를 표시하지 않았고, 알려진 일본어 두 사례는 모두 후보를 선호했습니다. 개인 작업 영어는 흐름과 시간 참조의 정밀성에 대한 선호가 갈렸고 일본어의 긴 틀·영어 완곡 표현에도 주의가 남았습니다. 네 판독을 48개 독립 출력이나 통계적인 품질 입증으로 세지 않습니다.

이 근거로 기본 꺼짐인 실험 기능의 관용 표현·수행자 지침을 한정 채택했습니다. 기본 모델이나 사용자 선택은 자동 변경하지 않았습니다. 이번 실측은 한 모델·단일 응답 조건의 선택된 사례이며 사람 원어민 검수, 실제 마이크·대상 앱 입력 검증은 없습니다. [5차 결과](reviews/2026-10-07/translation-idiomatic-polish-round5-results.md)는 선호·해석 위험·CI와 설치 전 후보 검증을 구분해 기록합니다.
