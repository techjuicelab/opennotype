# 음성 번역 실측 기록

파싱 성공, 입력 전 보존 검사 통과, 의미 보존, 자연스러움은 서로 다른 결과다. 아래 평가는 Codex 에이전트의 합성 발화 판독이며 원어민 사람의 검수가 아니다. 사용자의 실제 녹음·키 값·인증 자료는 포함하지 않는다.

## 2026-10-05 제품 소스 `0ed0594`

차단된 3개는 응답 사용량과 고정 오류 분류만 남기고 출력은 반환하지 않았다. 그 문장 전체의 수행자·자연스러움은 판독하지 않았으며, 차단을 정상 번역 성공으로 집계하지 않았다. 반대로 명시된 `I`/`we`, 24시간 표기에서의 올바른 오후 변환, 코드 식별자와 일반 시각 표기 등 정상 반례도 함께 확인했다.

## 2026-10-06 공급자와 지침의 후속 비교

인용 범위 수정이 반영된 제품 `5fa9ca2`와 compact-v7 지침 사본을 동일 입력 26개로 비교했다. 기존 회귀 18개, 별도로 작성한 HU 6개, 앞서 출력이 없었던 QH 2개를 구별했다. 실제 `ProviderClient`와 보존 검사를 사용하고 공급자·모델·effort·전체 요청 fingerprint를 검증했다. 각 설정의 단일 실행이며 OpenRouter의 실제 upstream 공급자는 고정하지 않았다. 서로 다른 모델이나 공급자의 결과를 지침 하나의 인과 효과로 해석하지 않는다.

| 설정 | 반환 | 보존 검사 차단 | HTTP 429 사례 | 미호출 |
| --- | ---: | ---: | ---: | ---: |
| 제품 / OpenRouter `openai/gpt-6-luna` / `none` | 24 | 2 | 0 | 0 |
| compact-v7 / 같은 모델·effort | 25 | 1 | 0 | 0 |
| 제품 / Groq `openai/gpt-oss-120b` / `medium` | 6 | 0 | 1 | 19 |
| compact-v7 / 같은 모델·effort | 0 | 0 | 1 | 25 |

각 행의 입력은 26개다. 두 HTTP 429 사례는 각각 60초 뒤 한 번 재시도했으나 다시 제한됐다. 미호출 44개는 품질 미평가다. 저장된 HTTP 시도는 62회(200 58회, 429 4회)다. 초기 실행 중단 시 저장되지 않은 진행 중 요청은 알 수 없으며, 이 수치를 실제 전체 호출 수로 단정하지 않는다. 초기 Luna 응답 3개는 정확한 fingerprint를 확인해 재사용했다.

제품 Luna에서 NT03은 원문에 없는 `we`를 추가했고 HU706은 수량 맥락의 `total`을 `총액`으로 좁혔다. compact-v7은 HU706을 `합계`로 표현하고 NT10의 표기를 보존했지만 NT03의 수행자 추정은 남았다. GC404의 철회한 코드 값과 HU705의 정정 반복·설명도 완전히 정리하지 못했다. HO01의 사건 지시와 NT09의 일본어 테스트 표현에는 별도 주의가 있다. 일부 개선으로 지침 전체의 의미·자연스러움 통과를 선언하지 않으며 compact-v7을 제품에 채택하지 않았다.

Groq 제품 응답 6개에서도 수행자 추정과 일본어 표현 주의를 확인했다. Groq 후보는 반환이 없어 지침 개선 효과를 비교할 수 없다. QH 2개는 이번 Luna 설정에서 새 요청으로 반환됐으며 이전 Groq 시험의 재개 성공으로 집계하지 않는다.

제품 Luna 결과 SHA256: `95a2351879bc16e1847f27824ce3f69d0392e8f3ae24e73a334c53d13a2c8bce`.
compact-v7 Luna 결과 SHA256: `6435aca398a4569e42592ba28536ade1f6140ff26d79acf0a55ab51fe036986c`.
제품 Groq 결과 SHA256: `fd790455d4dfc43d42e0da372a6bc3491e0e1f5bd50d6177c94deb84339e47e2`.

Luna 52개가 보고한 비용 합계는 $0.005238030이며, Groq·429·초기 중단 중 미저장 요청 비용은 알 수 없다. 파싱·보존 검사 통과와 전체 의미·말투·자연스러움 통과를 구별한다. 이 판독은 에이전트 검토이며 원어민 사람 검수나 실제 마이크·대상 앱 삽입 시험이 아니다.

### 번역에만 추론을 켜는 v8 후보의 당시 준비 상태

제품 지침과 compact 지침을 각각 그대로 둔 채 Luna 번역 요청에만 `medium`을 적용하는 사본 두 개를 준비했다. 원문 받아쓰기·선택 문장 수정은 `none`, 다른 모델의 정책은 그대로다. 기존 비번역 요청 320개의 바이트 동일과 실제 ProviderClient 요청을 가로채는 18조합×3소스의 로컬 검사 54개를 확인했다. 정식 XCTest나 실제 모델 품질 통과와는 별도 근거다.

고정 26개와 추가 통합 사례 6개를 합친 입력 32개를 준비하되 두 그룹을 따로 집계한다. 추가 사례 작성자는 이전 출력 세 사례의 구절에 노출됐고, root도 추론 정책 동결 전에 입력을 읽었으므로 완전 무노출 시험으로 주장하지 않는다. 실행을 두 차례 시도했으나 모두 1Password 인증 시간 초과로 끝나 당시 두 후보의 실제 API 시험을 시작하지 못했다. 이후 재인증으로 아래 v8–v11 시험을 완료했다. 이 문단은 초기 시도의 기록이며 최종 인증·제품 상태를 뜻하지 않는다. `exclude`는 추론 내용을 숨기는 설정이며 청구되는 추론 토큰을 없애지 않는다.

채택 전에는 고정 사례의 수행자·조건·부정·수치·표기 보존, 철회한 값과 정정 골격의 정리, 인용 화자별 말투를 실제 반환에서 확인해야 한다. 출력 없는 차단이나 미호출은 품질 통과로 세지 않는다. 비용·지연과 정식 통합 검증, 실제 음성 및 입력 경계도 별도로 확인한다.


## 2026-10-06 재인증 후 최종 보강 v11

이하 시험은 Codex가 직접 실행했다. 초기 인증 실패를 API 호출로 집계하지 않으며 이전 후보의 출력 없는 상태와 구별한다. 실제 `ProviderClient`·보존 검사와 동결 소스 사본을 사용했다. 후보별 원문 묶음은 일부 겹치므로 모든 요청 수를 독립 발화 통과 수로 합치지 않는다.

v11의 총68 HTTP는 모두 단일 시도다. 자동 의미 수정 요청은0이고, 번역 반환은64개다. Luna48의 언어는 영어17·일본어16·한국어15이며, 알려진26·추가통합6·후속8·추가4·어휘4를 따로 대조했다. v10과 겹치는44개의 입력은 동일하다. HU706의 문서 위치와 일반 합계 보존은 개선됐지만 HU705의 `not two` 취소 대조는 다시 남았다. 이 정리 미충족을 의미 통과에 합쳐 삭제하지 않는다. HU701·HF906·HX1104에는 원문의 가능한 해석 범위를 좁히는 주의, HU704에는 관용 표현 주의가 있다.

기본 mini12의 GC404는 최종 코드 값을 미정 대안으로 바꾸고, QH601은 걷는 속도를 낮추라는 요청을 멈추라는 요청으로 바꾸며, HU706은 합계의 문서 위치를 빠뜨렸다. HU705·HF903은 의미 오류3과 별도로 정리 미충족이다. GC404에도 정정 흔적이 남지만 이를 별도 독립 의미 오류로 다시 합산하지 않는다.

합성 음성은 고유 WAV3개를 목표 언어4조합으로 요청했다. 실제 Whisper 전사 뒤 실제 Luna 번역에 연결했으며 A304의 비긴급 설명과 항목 유지 사이에 이유 연결어가 붙는 주의가 남았다. STT 비용·token은 미보고라 전체 음성 처리 비용을0 또는 완전한 비용으로 표시하지 않는다.

v11에서 OpenRouter가 보고한 합계는 input187,538/output13,638 tokens, 그중 reasoning10,619이며 비용은 USD0.018217105다. 추론 토큰은 출력 토큰에 포함되므로 다시 더하지 않는다. 번역 응답 지연 중앙값은 Luna48 3,486.5ms, mini12 1,373.5ms, 합성음성4의 전사부터 번역까지는4,065.5ms다. 한 번씩 실행했고 실제 upstream·캐시를 고정하지 않았으므로 모델별 보편 가격·지연·단일 지침의 인과 효과로 일반화하지 않는다.

최종 제품 지침·정책4개는 시험한 v11 동결 소스와 바이트가 동일하다. 받아쓰기·수정의 기존 요청320개 바이트 동일, 실제 provider wire18조합, 번역 점검 위치와 실패 시 원문 자동 입력 방지 경계를 별도로 검증했다. 정식 XCTest·개발 앱 CI와 실측 품질 판독은 서로 다른 검증이다. 최신 검증 및 출력·해시·작성자 노출 범위는 [최종 품질 검토](reviews/2026-10-06/native-translation-quality.md)와 [실측 증거](reviews/2026-10-06/native-translation-quality-evidence.json)에 기록한다.

추가 어휘4는 v11 소스 동결 약28초 뒤 작성됐다. 작성자는 지침 본문을 읽지 않았지만 이전 출력과 고수준 보강 방향에는 노출됐다. 후보 작성자는 입력 동결 뒤 내용을 읽었다. 완전 무노출 시험으로 주장하지 않는다. 모든 원래 기준을 유지했으며 참고 정답 문장을 제품 지침에 넣지 않았다. 실제 마이크·잡음·대상 앱 삽입·원어민 사람 검수는 이번 실측에서 수행하지 않았다. 공개 앱 설치·릴리스·PR 병합도 이 시험의 범위가 아니다.
