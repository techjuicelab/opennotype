# Handy에서 참고한 음성 입력 개선

**0.2.9 (45)**에 포함한 음성 입력 개선입니다. [릴리스 목록](https://github.com/techjuicelab/opennotype/releases)에서 다운로드를 확인하고, 게시·패키지·설치의 실제 검증 상태는 [0.2.9 배포 보고서](reviews/2026-10-15/release-0.2.9.md)를 참고하세요.
참고 대상은 [Handy v0.9.8](https://github.com/cjpais/Handy/releases/tag/v0.9.8)이며, Swift/AppKit 및 기존 WhisperKit 구조에 맞게 구현했습니다.

## 사용하는 곳

- **설정 → 입력·단축키**: 받아쓰기 처리, 단축키 동작, 녹음 마이크, 준비·종료 알림음, 녹음 중 시스템 음소거.
- **음성 모델**: Large v3 / Small / Base 선택, 모델 파일 준비·삭제, 메모리 유지 정책, 녹음 중 로컬 미리보기, 한영 혼용 음성 비교실.

이전 설정을 읽으면 기존 toggle 단축키, AI 문장 정리, Large v3와 모델 메모리 유지가 그대로 적용됩니다. 미리보기·효과음·시스템 음소거는 기본 꺼짐입니다.

설정의 긴 설명은 옵션명 옆 `?` 도움말에서 확인합니다. 현재값·미적용 이유·장치 연결 오류와 추가 요청·비용·입력 보류 안내는 기본 화면에 남습니다. 도움말을 열어도 설정이나 모델·API 요청은 실행하지 않습니다. [UI 개선과 검증 범위](reviews/2026-10-15/uiux-option-help.md)를 참고하세요.

## 빠른 로컬 받아쓰기

받아쓰기 처리에서 **빠른 로컬 받아쓰기**를 선택하고 출력 언어를 **말한 언어 유지**로 설정합니다. 선택한 로컬 모델을 먼저 준비해야 합니다.

음성 인식 원문을 AI 정리·자동 Jev 검토 없이 입력합니다. 클라우드 API 키가 필요하지 않고, 음성·문장을 외부 AI로 보내지 않습니다. 개인 사전은 로컬 인식 힌트에 사용하며, 인식 결과를 임의로 강제 치환하지 않습니다. 의미·인식 오류가 없어지는 기능은 아닙니다.

번역 출력, 선택 문장 수정, 프롬프트 만들기는 기존 AI 처리를 유지합니다. 기록에서 사용자가 별도로 AI 재처리를 실행하는 것도 별개 요청입니다.

기록에는 빠른 받아쓰기 여부를 저장합니다. 실패 녹음에는 AI 생략 여부와 로컬 모델 ID를 함께 저장하므로 **같은 설정으로 다시 처리**는 현재 설정을 바꾸었더라도 원래 오프라인 경로와 모델을 유지합니다. 복구 결과는 복사 전용이며 자동 입력하지 않습니다. 기존 24시간 만료·암호화·용량 제한을 유지합니다.

## 단축키와 오디오

- **한 번 누르기**: 기존 시작·종료 동작.
- **누르는 동안**: 누르면 시작, 떼면 종료.
- **혼합**: 300 ms 미만으로 누르면 다음 누름까지 녹음, 길게 누르면 떼는 순간 종료.

키를 떼는 이벤트가 비동기 녹음 준비보다 먼저 도착하면 준비 완료 후 종료합니다. 취소한 작업의 늦은 release는 다음 작업을 종료하지 않습니다.

마이크는 장치 UID로 선택하며 시스템 기본 입력 설정은 변경하지 않습니다. 지정한 장치가 연결되지 않았다면 다른 마이크로 몰래 전환하지 않고 시작 오류를 표시합니다. 실제 PCM을 받은 뒤 녹음 준비 완료 상태가 됩니다.

AVAudioEngine으로 입력을 받아 16 kHz mono PCM WAV로 변환합니다. 입력·출력 버퍼는 직렬 작업에서 변환·저장하고 종료할 때 남은 샘플을 처리합니다. 기기 변경이나 잠자기로 캡처가 중단되면 부분 녹음은 기존 실패 복구 경로로 전달합니다.

준비 후 callback·처리 진행과 전달 frame을 감시하고, 종료 중 발생한 오류도 확인해 불완전 녹음이 정상 전사·자동 입력으로 넘어가지 않도록 보호합니다. writer가 영구 정지한 경우의 비동기 종료·복구 완료까지 보장하는 설계는 아닙니다. 붙여넣기 직전에는 현재 키보드 배열의 Command+V 키를 해석하며 해석 실패 시 기존 ANSI V를 사용합니다. [후속 보호와 검증 경계](reviews/2026-10-15/handy-audit-followup.md)를 참고하세요.

시스템 음소거는 녹음 시작 시 기본 출력 장치에 적용합니다. 종료·취소·실패 때 원래 상태로 복원하며, 녹음 중 사용자 변경을 감지하면 덮어쓰지 않습니다. 녹음 중 출력 장치를 바꾸면 새 장치는 건드리지 않습니다. 음소거 지원이 없는 장치는 명시적인 시작 오류로 표시합니다. 음소거를 함께 켜면 준비 알림음은 생략하고 시각적인 준비 신호를 사용합니다.

## 로컬 모델과 미리보기

모델은 사용자가 명시적으로 준비할 때만 다운로드합니다. 모델 변경은 기존 다운로드를 삭제하지 않습니다. 파일 삭제는 선택한 모델의 전용 모델·토크나이저 폴더만 대상으로 하며 공유 파일·기록·사전·다른 모델은 보존합니다.

메모리 해제는 사용자가 선택한 미사용 시간 정책에 따라 수행합니다. 다운로드 파일은 유지하며 다음 사용에서 다시 로드합니다. 다시 로드하는 첫 녹음의 준비 시간은 늘어날 수 있습니다.

실험적 미리보기는 최근 **최대 12초**를 **약 3초 간격**으로 재인식합니다. 네이티브 streaming decoder나 최종 입력 대기 단축을 입증한 기능이 아닙니다. 화자 필터를 켠 경우 미리보기를 사용하지 않습니다. 미리보기는 외부 앱에 입력하거나 기록하지 않고, 확정 입력은 전체 녹음을 다시 인식합니다. 최종 인식이 미리보기보다 우선하며 종료·취소 후 늦은 결과를 표시하지 않습니다.

## 한영 혼용 음성 비교실

최대 60초의 비교용 음성을 녹음하거나 파일을 선택하고, 같은 음성을 이미 준비된 로컬 모델에 순차 입력합니다. 모델을 자동 다운로드하거나 외부 API에 요청하지 않습니다. 인식에는 개인 사전 없이 같은 조건을 사용합니다.

모델 준비 시간과 인식 시간을 따로 표시합니다. 정답을 입력하면 공백 제거·NFC 정규화 후 Unicode scalar 편집 거리로 CER을 계산합니다. 대소문자·문장부호도 비교하며, 정답이 없으면 CER을 계산하지 않습니다. 숫자 조각과 수동 고유명사·숫자·의미 오류 개수도 확인할 수 있습니다. 개별 샘플의 CER은 실사용 전체 정확도나 의미 충실성을 보장하지 않습니다.

비교용 녹음 파일은 종료 후 삭제하고, 반복 비교할 PCM은 화면을 닫거나 취소·지우기 전까지 메모리에만 둡니다. 가져온 원본 파일은 삭제하지 않습니다. 기존 기록·사용량 통계에 비교 샘플을 쓰지 않습니다.

## 검증 경계

자동 검증은 단축키 상태 전이, 오디오 변환·파일 권한, 음소거 소유권·복원, 미리보기/최종 인식 경합, 모델 캐시 삭제 범위, 기존 설정 복원, 빠른 입력의 외부 요청 차단과 실패 복구 경로를 대상으로 합니다.

실제 마이크의 첫음절·장치 전환·물리 음소거·단축키 제스처, 한국어·영어 혼용 자연 발화의 정확도 및 체감 속도는 실제 장치와 음성으로 확인해야 합니다. 새 Nemotron/Parakeet 엔진을 도입하거나 기존 한국어 기본 모델을 교체하지 않았습니다.
