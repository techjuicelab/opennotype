# OpenNoType — 확정 요구사항

상태: 2026-09-09 역인터뷰 완료, 사용자 개발 승인. 구현/실측 완료를 뜻하지 않는다.

## 제품과 배포
- MIT 오픈소스. 개인/상업적 수정·재배포 허용. 재사용 코드 및 모델의 별도 라이선스 검증 필요.
- 첫 공개 버전은 Apple Silicon(M1 이후) macOS. 이후 Windows/iOS/Android 확장.
- 자체 회원가입/운영 서버 없이 사용자 API 키로 AI 제공자 직접 호출. 키는 Keychain에 보관.
- OpenAI·Groq·OpenRouter 키 하나로 STT와 텍스트 처리. Claude 키만 있으면 로컬 음성 인식 후 Claude 텍스트 처리. 어떤 제공자를 골라도 녹음과 텍스트는 그 제공자에게만 직접 전송한다.
- 사용자용 서명·공증 설치 파일과 자동 업데이트, GitHub 소스 공개.

## 입력과 언어
- 기본 받아쓰기: 말투·의미 보존. 추임새·불필요한 반복·명확한 자기수정 제거.
- "오전 7시에 볼까… 아닌가… 오후 3시에 보자" → "오후 3시에 보자."
- 결론이 없으면 불확실성 보존. 이름/숫자/날짜/조건/부정/확신 정도를 임의 변경하지 않는다.
- 한 문장 안의 다국어와 원래 표기 보존. weather/rain/API를 한글 발음이나 번역어로 강제 변환하지 않는다.
- 번역은 녹음 종료 후 확정 결과 삽입. 한국어↔영어 품질 최우선, 일본어·중국어 추가 지원.
- 직역 대신 목표 언어권의 자연스러운 표현으로 의도·말투·뉘앙스 전달.
- 선택한 문장을 음성 지시로 수정. 일반 Ask Anything/웹 검색은 첫 버전 제외.

## 녹음과 화자
- 최대 540초. 480초부터 Voice bar에 60→0초 카운트다운. 540초 자동 종료 후 처리.
- 주변 사람·TV 발화 배제 요구. 소음 억제/화자 식별/겹말 분리를 혼동하지 않는다.
- 최초 목소리 등록 허용. 등록 원본 삭제, 목소리 특징만 기기에 보관, 사용자 삭제 제공.
- 사용자 음성 실제 등록과 타인/TV/겹말 평가 전에는 검증 완료로 표시하지 않는다.

## 개인화와 개인정보
- 사용자 교정 자동 학습. 앱이 방금 삽입한 텍스트만 제한적으로 관찰.
- 대소문자와 제한된 고유명사 철자 교정만 자동 저장. 임의의 한글↔영문 변경·일반 단어 교체는 검토 후 직접 등록. 로컬 사전 편집·삭제, 자동 학습 켜기·끄기와 마지막 학습 되돌리기.
- 문맥 수집 기본 꺼짐, 앱별 opt-in. 커서 앞 최대 1,000자만 선택한 AI 제공자에 전송.
- 앱별 작성 방식은 형식·말투 열거값만 텍스트 요청에 동봉한다. 앱 이름·번들 식별자는 전송하지 않는다. 음성 인식 힌트는 개인 사전 표기(최대 24개)와 개발 프로필의 고정 용어를 포함하며, OpenAI의 문맥 지원 모델에만 고정 참고 문장과 상황 문장을 추가한다.
- 보안 입력란 제외. 수집 문맥은 기록에 저장하지 않는다.
- 결과 텍스트 로컬 암호화 30일 기본. 보관 기간 변경/기록 끄기/개별·전체 삭제.
- 성공한 녹음 원본 즉시 삭제. 실패한 녹음만 파일별 로컬 암호화 최대 24시간. 재시도 성공/직접 삭제/만료 시 삭제. 신규 보관은 파일당 25 MB·전체 100 MB 상한을 적용하며 기존 녹음을 한도 때문에 자동 삭제하지 않는다.
- 실제 API 전송은 제공자 정책 적용. 로컬 기록 정책을 제공자 보관 정책으로 오해시키지 않는다.

## 실사용 검증 대상
Claude, Codex, Antigravity, KakaoTalk, Telegram, Discord, 메모, Notion, Obsidian.
각 앱에서 핫키·녹음·받아쓰기·번역·선택 문장 수정·실패 복구·포커스 변경·클립보드 보존을 확인한다.
텍스트를 입력하되 메시지 전송(Enter)은 하지 않는다.

## 품질 검증 원칙
- 빌드 성공, 단위 테스트, 모델 문서만으로 실제 한국어 정확도/자연스러운 번역/화자 배제/다른 앱 입력 성공을 주장하지 않는다.
- 미구현·실기기 미검증·API 미검증 상태를 구분해 기록한다.
- 실사용 키나 사용자 음성이 없으면 그 사실을 명시하고, 실행 가능한 앱과 검증 절차까지 준비한다.

## 받아쓰기 품질 개선 — 추가 역인터뷰 합의

기본 견본과 앱별 작성 방식에 관한 추가 인터뷰 결과다. 위의 의미·개인정보 보존 원칙을 유지하며, 문장 구조 보존을 다음 범위로 구체화한다.

- 사전 등록 여부와 관계없이 발화 문맥에서 의도가 명확한 음성 인식 오류를 교정한다. 예: 개발 작업의 `커미 처리` → `commit 처리`. 불분명한 이름·리터럴·숫자는 추측하지 않는다.
- 명확한 제품·서비스명과 기술 용어는 해당 영문 표기를 사용한다. 일반 외래어 `파일`, `프로젝트`, `폴더`는 한글로 둔다. 사용자가 등록한 관련 표기는 우선 참고한다.
- 불필요한 반복, 중간 재시작 구절, 조사·문법을 정리하고 문장을 재구성한다. 의도적 강조, 시제, 부정·조건, 확신 정도, 질문·부탁·약속의 강도는 보존한다.
- 공통 견본은 일상 대화·업무 메시지·메모·언어 혼용을 다룬다. 개발 전문 용어는 개발 프로필과 개인 사전으로 보강한다.
- 녹음 시작 앱의 프로필로 문장 정리·형식을 자동 적용한다. 반말·존댓말은 원래대로 유지하고, 사용자가 해당 앱에 문체를 지정한 경우에만 변경한다.
- 앱 프로필은 사용자가 변경할 수 있다. 여러 용도로 쓰는 Claude나 미확인 앱·브라우저는 일반 프로필로 시작한다. 앱 이름으로 웹사이트나 수신자를 추정하지 않는다.
- 프로필 선택은 주변 문맥 수집 동의와 별개다. 발화 문맥을 사용한 교정은 다른 앱의 텍스트 수집을 기본 허용한다는 의미가 아니다.
- AI가 스스로 고친 표기는 개인 사전에 자동 등록하지 않는다. 실제 삽입 결과에 대한 사용자의 표기 수정만 자동학습 대상으로 삼는다.
- 첫 개선판은 현재 기본 모델을 유지한다. 견본·교정 규칙·불필요한 대기를 먼저 개선하고 동일 음성 비교 후 모델 변경을 판단한다.

공통 견본, 기대 결과 및 검증 경계는 [받아쓰기 견본](dictation-baseline.md)에 정리한다.

## 2026-09-12 반복 정리와 정보 보존 개선

- 불필요한 반복 단어뿐 아니라 같은 뜻으로 되풀이한 어구·문장과 중간 재시작을 정리한다. 중복을 한 번으로 합치는 것은 허용하되, 서로 다른 정보를 대표 문장 하나로 요약하지 않는다.
- 재시작하거나 같은 요청을 다시 말하면서 추가한 대상·시각·기한·이유·조건·예외는 완성된 문장으로 이어받는다. 뒤 문장만 남기면서 앞에서 한 번만 말한 행동이나 이름을 잃지 않는다.
- 자기 정정은 수정한 범위에만 적용한다. 예를 들어 `오전 10시에 리뷰할까, 아니 오후 2시로 하자`는 시각을 바꾸되 `리뷰`를 유지한다. 수량을 정정해도 `정도`, `살까?` 같은 범위·태도는 유지한다.
- 명확히 폐기한 값은 남기지 않으며, 결정을 못 한 선택지는 임의로 하나로 줄이지 않는다. 강조, 반복되는 실제 행동, 횟수, 대조, 인용, 코드·URL은 단순 중복으로 보지 않는다.
- 사전 항목은 같은 개념인 경우의 표기 힌트다. 문맥이 일반적인 `사과했어요`이면 동음이의어 사전 `사과 → SAGWA`를 적용하지 않는다. 명시적으로 유지하라고 말한 리터럴은 사전보다 우선한다.
- 기존 문장 처리 요청 한 번 안에서 정리·보존 점검을 수행한다. 모든 숫자를 무조건 남기는 검사나 길이 비율·정규식으로 원문을 삭제/복원하는 규칙은 적용하지 않는다.
- 합성 문장으로 이전·개선 프롬프트를 같은 모델과 설정에서 비교한다. 전송·JSON 성공, 빈 출력의 적절성, 반복 제거, 의미·단어 보존을 별도로 평가한다. 예상 정답과의 문자열 일치는 의미 품질 점수로 사용하지 않는다.

공식 Typeless 설명은 비교할 제품 동작의 근거이며 내부 모델·알고리즘이나 한국어 무손실 정확도를 입증하지 않는다. 실험 범위와 결과는 [비교 문서](reviews/2026-09-12/typeless-comparison.md)에 구분한다.

## 2026-09-11 모든 앱 입력 범위

- 자동 입력은 앱 종류와 무관하게 ⌘V 붙여넣기를 기본 경로로 사용한다. 손쉬운 사용 직접 쓰기는 붙여넣기 경로를 쓸 수 없을 때(클립보드 보존 불가, 키 이벤트 생성 불가, 원래 앱을 앞으로 가져오지 못함)만 대신 사용하고, 이미 보낸 붙여넣기 뒤에는 겹쳐 쓰지 않는다.
- Electron/Chromium 앱과 터미널은 손쉬운 사용 대체 없이 붙여넣기만 사용한다. Chromium은 빈 입력창의 placeholder 문구를 AXValue로 노출하므로, 붙여넣기 전용 대상은 "값이 바뀌었고 결과를 포함한다" 조건으로 입력을 확인한다.
- 붙여넣기용 클립보드 항목은 nspasteboard.org 관례(TransientType·ConcealedType)로 표시해 클립보드 관리자가 기록하지 않게 하고, 입력 확인 뒤 원래 내용을 복원한다.
- 이전 버전 notype(`space.techjuicelab.notype`)이 실행 중이고 같은 단축키를 쓰면 앱 시작, 녹음 시작, 해당 앱 실행·종료 시점에 경고한다. 경고는 설정뿐 아니라 홈 화면과 플로팅 바에서도 보인다.

## 2026-09-10 안정성·사용성 개선 범위

아래는 전반 검토 후 승인받은 구현 범위다. 구현 여부와 실제 검증 결과는 [검증 상태](verification.md)에서 구분한다.

- 선택 문장 수정은 반영 직전에 원래 앱·입력란·전체 텍스트·선택 범위를 다시 확인한다. 읽어 확인할 수 없거나 대상이 달라졌으면 자동 입력을 멈추고 결과를 복사할 수 있게 한다. 받아쓰기·번역의 같은 앱 내 입력란 이동 정책과 구분한다.
- 손쉬운 사용 쓰기가 수락되거나 전달 여부가 불확실하면 시간 초과를 쓰기 실패로 단정하지 않는다. 지연 입력과 중복될 수 있는 추가 붙여넣기를 하지 않는다. 전송되지 않음과 전달 후 확인 불가를 구분한다.
- 자동 학습은 대소문자, 내부 대문자를 포함한 이름의 제한된 철자 교정, `GR5Q → GROQ` 같은 한 글자 오인식으로 좁힌다. `Cat → Car`나 임의의 한글↔영문 변경은 자동 저장하지 않는다. `proposedCorrection`은 공통 조사·숫자를 제외한 단일 표기를 검토용으로 제안할 뿐 자동 학습을 허용하지 않는다.
- 교정 학습은 기록 저장과 별도로 끌 수 있다. 끄면 새 교정 관찰·등록을 중단하고 기존 사전은 유지한다. 같은 실행에서 마지막 학습 한 건을 되돌릴 수 있으며, 이후 사용자가 바꾼 항목을 덮어쓰지 않는다. 검토 후보의 편집란 채우기와 사전 저장은 별도 동작이다.
- 실패 녹음은 ‘같은 설정’과 ‘현재 설정으로 복구’를 구분한다. 현재 설정 경로는 제공자·모델·로컬 인식·목소리 필터·번역 언어 변경 및 전송 대상을 확인한다. 두 경로 모두 현재 사전과 녹음 당시 작성 프로필을 사용하며 만료를 연장하지 않고 결과는 복사하도록 표시한다.
- 사용자가 선택한 로컬 기능은 기존 모델·토크나이저 캐시만 읽어 자동 준비한다. 누락·손상 캐시를 자동 다운로드로 복구하지 않는다. 최초 다운로드와 다시 준비는 명시적 버튼으로 시작하고 취소를 제공한다. 취소 뒤 늦은 준비 결과를 새 상태에 적용하지 않는다.
- 시작하기 화면에서 키 저장과 실제 연결 검증을 구분하고, 마이크·손쉬운 사용·필요 모델의 준비 상태 및 API 없는 입력 연습을 제공한다. 거부된 마이크 권한은 시스템 설정으로 안내하고, 로그인 실행은 시스템의 승인 상태를 반영한다.
- 페이지 전환 시 상단으로 이동하고 현재 메뉴 선택을 접근성 정보로 제공한다. 깨지거나 길이·중복·키 조합이 잘못된 단축키 설정은 해당 필드만 기본값으로 복구한다.
- OpenRouter는 모델 공급자로 요청을 중개하며, 전사 API에 채팅용 `allow_fallbacks` 등의 라우팅 제한을 보내도 공급자 고정을 보장할 수 없다. 적용되지 않는 STT 옵션을 제거하고 실제 전송 경계를 설정과 안내에 표시한다.
- 저장소에서 메타데이터와 실패 녹음 음성을 별도 암호화한다. 이전 형식은 유효한 음성을 새 파일로 저장·재검증한 뒤 메타데이터를 교체하며, 중간 실패 시 이전 저장소를 보존한다. 기존 녹음은 마이그레이션 때 한도 때문에 버리지 않고, 한도를 넘으면 새 저장을 거절한다. 일반 기록 조회에서 음성 전체를 반복해 읽지 않는다.
