# UI/UX 시안 검증 기록

대상은 같은 폴더의 [index.html](index.html)입니다. **네이티브 앱의 구현·설치·실행 검증이 아닙니다.** 실제 마이크·API·Keychain·설정 저장·클립보드 동작은 실행하지 않았습니다.

## 브라우저에서 실제 확인한 항목

`ego-browser`의 독립 작업 공간에서 로컬 HTML 파일을 열어 아래 14개 확인을 수행했고 모두 기대 결과를 확인했습니다.

| 확인 | 결과 |
| --- | --- |
| 1280×960 라이트 화면의 가로 넘침 | 없음. 기본 설정 화면 전체가 뷰포트 안에 표시됨 |
| 옵션 `?` 클릭과 도움말 제목·화면 경계 | 팝오버 표시, 해당 옵션 제목, 화면 안 배치 확인 |
| `Escape` 닫기와 포커스 복원 | 호출한 `?` 버튼으로 복귀 |
| 다른 `?` 클릭 | 기존 도움말을 닫고 한 개만 표시 |
| 바로 입력 선택 후 번역 출력으로 변경 | 바로 입력의 저장값 유지, AI 처리 사용 중·현재 미적용 안내 |
| 번역에서 일반 입력 전 교정 선택 | 일반 받아쓰기 검토 미적용으로 표시 |
| 입력 전 확인과 번역 검토를 함께 선택 | 번역 검토의 추가 요청·실패 시 보류 계약 표시 |
| 별도 번역 단축키 언어 변경 후 다른 옵션 조작 | 별도 언어값 유지, 켜진 번역 다듬기의 실험 표시 유지 |
| 다크 모드 | 색상 전환과 설정 컨트롤 표시 확인 |
| 입력 보류 화면 | 결과와 이유·복사 행동을 첫 위치에 표시 |
| 다른 기록 선택 후 결과 복사 화면 | 선택한 기록과 모달 문장이 일치 |
| 모델 관리에서 삭제 확인으로 이동 후 닫기 | 원래 관리 버튼으로 포커스 복원 |
| 900×640 창 | 가로 넘침 없음. 필요한 내용은 세로 스크롤 |
| 작은 창의 도움말 | 팝오버가 화면 경계 안에 표시됨 |

복사 버튼은 복사할 예시 문장을 보여 주는 모달을 엽니다. 실제 클립보드를 바꾸거나 복사가 완료됐다고 표시하지 않습니다.

## 4개 에이전트의 교차 검토와 수정

메인과 세 에이전트가 각자 맡은 구조·기능 계약·시각 규칙을 다시 대조했습니다. 다음 문제를 시안에서 수정했습니다.

- 번역 중 Jev의 일반 받아쓰기 교정 계약이 잘못 표시되던 부분.
- 별도 번역 단축키 언어가 재렌더링 때 초기화되던 부분.
- 선택한 기록과 복사·검토 모달의 예시 문장 불일치.
- 현재 기능에 없는 받아쓰기 복구용 원문 직접 입력 동작의 노출.
- 중첩 확인창 종료 후 원래 버튼 포커스 복원.
- 개인 사전 자동 학습을 수동 검토만 하는 것처럼 설명한 부분.
- 이름 후보에 앱별 문체 도움말이 연결되던 부분.
- 화면 크기·스크롤로 도움말이 닫힐 때의 포커스 처리와 팝오버 내부 스크롤.
- 번역 다듬기를 켰을 때 실험 표시가 사라지던 부분.

## 정적 확인

- JavaScript를 추출해 구문 검사 통과.
- Markdown 코드 블록 경계와 로컬 파일 링크 확인.
- 한국어 문서·시안에서 가나 문자 없음 확인.
- 실제 AppIcon 원본의 로컬 로딩 확인. 외부 이미지·폰트·패키지 요청 없음.
- 기록한 [source-baseline.json](source-baseline.json)의 앱 소스 10개가 검증 종료 직전에도 같은 SHA-256임을 확인.
- 이 작업에서 추가·수정한 파일은 `design/uiux/2026-10-15/` 아래 시안·문서·스크린샷뿐입니다.

시각 담당 에이전트는 명시적인 기본 색상 14쌍의 대비를 계산해 모두 5.35:1 이상임을 확인했습니다. 비활성·투명도·포커스·모든 네이티브 렌더링 상태를 포함한 WCAG 통과 판정은 아닙니다.

## 후속 네이티브 검증

실제 View 개선 시 SwiftUI 컴파일·기존 UI 관련 검사, `popover`의 키보드·VoiceOver·포커스 복원, 작은 창·다크 모드, 녹음 중 도움말 읽기, 외부 앱 입력 대상 보존을 다시 검증해야 합니다.

앱의 녹음·추론·검토·입력 정책을 시안의 표현에 맞추어 임의로 바꾸지 않습니다. 실제 개선 작업도 메인 포함 최소 4개의 에이전트를 병렬 운영한다는 사용자 요구를 유지합니다.
