- 내장 image_gen 도구를 사용해 각 시안을 개별 생성했습니다.
- 정확한 최종 생성 프롬프트 6개는 prompts.json에 저장했습니다.
- 원본 PNG는 각각 1254 × 1254px이며 알파 채널을 포함합니다.
- 실제 브라우저에서 6개 이미지와 32px 및 64px 미리보기를 밝은 배경, 어두운 배경으로 시각 확인했습니다.
- 기능 전달은 01, 친근한 인상은 05를 우선 후보로 제안합니다.
- 현재는 선택용 시안입니다. 앱 리소스로 채택하는 단계에서는 선택한 시안을 다듬고 macOS 아이콘 크기 및 패키지로 정리합니다.
