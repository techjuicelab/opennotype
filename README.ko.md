메인 0.2.7에 [음성 작업 프롬프트 만들기](docs/prompt-composition.md)를 포함합니다. 코드·직접 설계 없이 요구사항을 정리하고 Jev 검토 후 다른 앱에서 단축키로 녹음한 결과를 원래 입력창에 자동 입력합니다. 홈 녹음은 결과를 복사해 사용하며 재처리·원문 수정은 미리보기로 표시합니다. 공개 다운로드에는 아직 포함되지 않습니다.

**0.2.3 안정화:** 앱 하단에 실제 버전·build를 표시하고 배포 안내를 정리했습니다. 번역 지침 보강 후보는 영어·일본어 실제 비교 64회에서 목표 개선을 확인하지 못해 제외했으며, 번역 동작은 공개 0.2.2와 같습니다. [비교 결과와 한계](docs/reviews/2026-10-06/native-translation-0.2.3.md)를 참고하세요.

**0.2.2의 새 기능:** 받아쓰기 출력 언어를 영어·일본어·한국어로 선택하면 평소 단축키로 바로 번역 입력할 수 있으며, 기본값은 말한 언어 유지입니다. 요약·창작 강도를 적용하지 않고 뜻과 말투를 유지하도록 선택한 문장 모델에 요청합니다. 별도 번역 단축키는 자체 목표 언어를 유지하며, 최근 결과와 기록에서 인식 원문·번역·당시 언어를 비교할 수 있습니다. 모델에 따라 뜻이나 표현을 잘못 옮길 수 있습니다. [설정과 품질 확인 범위](docs/native-translation.md)를 참고하세요.

OpenNoType은 MIT 라이선스의 macOS 음성 입력 앱입니다. 녹음을 시작하면 말을 글로 바꾸고, 선택한 AI 제공자가 추임새·불필요한 반복·명확한 자기수정을 정리한 뒤 커서 위치에 완성된 문장을 입력합니다. 원래 의미와 말투, 한 문장에 섞인 여러 언어의 표기를 보존하는 것이 목표입니다. 받아쓰기에서 확실히 식별한 기술명은 한글 발음으로 말해도 `OpenRouter`, `1Password` 같은 공식 표기로 정리하며, 일반 한국어와 명시적으로 요청한 표기는 유지합니다.

**커뮤니티 배포의 검증 범위:** 합성 문장 정리와 Jev 검토·교정은 실제 API로 시험했으며, 일부 설치·화면·입력 경로도 검증했습니다. 자연 발화 품질과 대상 앱 9개의 전체 입력 흐름은 추가 검증이 필요합니다. 다른 제품과의 기능 동등성을 보장하지 않습니다. 버전별 결과와 남은 범위는 [검증 상태](docs/verification.md)에 기록합니다.

초기 문장 정리와 기록 재처리의 비교 근거는 [Typeless 비교 기준](docs/typeless-comparison.md), [0.1.9 구현 보고서](docs/reviews/2026-09-12/typeless-integration.md), [당시 실제 모델 비교](docs/reviews/2026-09-12/faithful-cleanup-live-comparison.md)에 보존합니다. 작은 합성 표본의 결과는 일반적인 품질 우위를 뜻하지 않습니다.

**[0.2.3 버전](https://github.com/techjuicelab/opennotype/releases/tag/v0.2.3)**은 **커뮤니티 배포 · Apple 공증 없음** 방식이며 앱의 ad-hoc 코드 서명과 업데이트의 Ed25519 서명을 사용합니다. 피드·공개 키가 없는 기존 개발 설치본은 최초 1회 수동 교체가 필요합니다. [최초 설치 안내](docs/mac-installation.md), [업데이트 운영 안내](docs/updates.md), [0.2.3 배포 검증](docs/reviews/2026-10-06/community-release-0.2.3.md), [Apple의 앱별 수동 허용 안내](https://support.apple.com/102445)를 참고하세요. [0.1.26 배포 검증](docs/reviews/2026-10-05/community-release-0.1.26.md)은 해당 버전의 과거 기록으로 보존합니다.

0.1.14부터 신규 설치는 영어로 시작합니다. **설정 → Mac·일반 → 앱 언어**에서 **English / 한국어**를 선택할 수 있고 기존 한국어 설치는 한국어를 유지합니다. 화면 언어와 받아쓰기·번역 언어는 별개입니다. [언어 설정과 버전 정책](docs/interface-language.md)을 참고하세요.

## v0.2.3의 기능

- 받아쓰기, 번역, 선택한 문장을 음성 지시로 수정.
- 받아쓰기와 번역 단축키의 출력 언어를 각각 선택하고, 원문·번역·당시 목표 언어를 최근 결과와 기록에서 비교.
- 범용 표기 견본과 문맥 오인식 교정, 조사·문장 재구성. [견본과 기대 결과](docs/dictation-baseline.md).
- 받아쓰기 표현 방식 6개와 **0~100** AI 편집 강도. 기본은 **현재 받아쓰기 · 강도 0**이며, API 호출 없는 예시 비교와 명시적 적용을 지원합니다. [표현 방식과 적용 범위](docs/dictation-expression.md).
- 앱별 작성 형식·말투 설정. 기본은 말한 반말·존댓말 유지.
- 저렴한 OpenRouter 문장 모델 20개와 Groq 2개에 입력/출력 단가·확인일 표시. [모델 선택과 비교](docs/text-models.md).
- 기존 OpenRouter 키 또는 TypeSafe 전용 키 중 선택하는 실험적 [Jev 문장 검토](docs/jev-review.md). 입력 후 검토, 입력 전 보호 또는 **입력 전 교정**을 선택할 수 있습니다. 교정 모드는 현재 문장 모델로 최대 한 번 교정한 뒤 Jev로 재검토하며, 실패·시간 초과·미해결이면 자동 입력을 보류합니다. 자동 검토는 기본 꺼짐이며 API 비용이 추가됩니다.
- **입력 전 보호 → 번역도 입력 전에 검토**를 직접 켜면 검토 요청 한 번을 추가하고, 불확실·실패·취소에서는 자동 입력을 보류합니다. 기본 꺼짐인 실험 기능이며 정상 번역도 보류할 수 있고 자동 재번역·교정은 하지 않습니다.
- Jev의 선택형 오류 유형 학습과 이름·세부 변경 검토. 학습과 추가 자동 도움 기능은 기본 꺼짐이며 정확도를 보장하지 않습니다. 영문 표기 제안은 확인 후 사전에 저장·되돌릴 수 있고, 저장 자체에는 API 호출이 없으며 이미 입력한 글은 바꾸지 않습니다.
- 직접 비교·복사하는 Jev 개선안과 확인한 정답을 기준으로 하는 모델 비교. 최근 번역·선택 수정도 명시적으로 검토할 수 있습니다. 추가 전송 내용과 비용을 확인한 뒤 실행하며, 추천 모델의 적용은 직접 선택합니다.
- 변경 가능한 전역 단축키와 작은 녹음 막대.
- 포커스를 확인한 결과 삽입과 클립보드 대체 경로. 메시지 전송용 Enter는 누르지 않습니다.
- 최대 9분 녹음과 마지막 1분 카운트다운.
- 개인 사전 등록·수정·삭제, 제한된 교정 학습 켜기·끄기와 마지막 학습 되돌리기, JSON 가져오기·내보내기.
- 로컬 암호화 기록, 보관 기간 변경, 검색, 원문·결과 비교와 각각 복사, 받아쓰기·번역 수동 재처리, 개별/전체 삭제.
- 모델별 요청 횟수·음성 길이·토큰·일별 활동과 사용 비용. 공급자 보고 금액·추정 금액·미확인을 구분합니다. [집계 기준](docs/usage.md).
- 최대 24시간 보관하는 암호화 실패 녹음과 재처리. 같은 설정 또는 현재 설정으로 복구할 수 있으며, 선택 문장 수정의 재처리에는 원문을 다시 입력합니다.
- 선택적으로 사용하는 로컬 음성 인식과 실험 단계의 내 목소리 필터.

자동 입력은 모든 앱에서 ⌘V 붙여넣기를 먼저 사용합니다. 붙여넣기는 키 입력을 받는 모든 앱(터미널, Electron 편집기, 노트 앱, 브라우저)에 닿지만, 손쉬운 사용 API 직접 쓰기는 많은 앱이 성공을 보고하면서도 화면에 반영하지 않기 때문입니다. 클립보드를 보존할 수 없거나 키 이벤트를 만들 수 없거나 원래 앱을 앞으로 가져오지 못한 경우에만 손쉬운 사용 쓰기로 대신하며, 이미 보낸 붙여넣기 뒤에 손쉬운 사용 쓰기를 겹쳐 보내지 않습니다. Electron 기반 편집기·브라우저·터미널은 손쉬운 사용 대체 없이 붙여넣기만 사용합니다. 붙여넣기에 쓴 클립보드 내용은 입력 확인 뒤 원래대로 복원하고, 클립보드 관리자가 기록하지 않도록 임시 항목으로 표시합니다. 대상 앱에 글을 전달하지 못한 경우에는 복사할 수 있도록 결과를 보여 주고, 전달했지만 확인하지 못한 경우는 조용한 알림으로 표시합니다.

처리 중 다른 앱이 앞으로 나왔다면 글을 쓰던 앱으로 먼저 돌아갑니다. 선택 문장 수정은 반영 직전에 원래 입력란·전체 텍스트·선택 범위가 그대로인지 다시 확인하며, 달라졌거나 읽어 확인할 수 없으면 자동 입력을 멈춥니다. 받아쓰기·번역은 같은 앱의 다른 입력란으로 커서를 옮겼을 때 현재 입력란에 붙여넣을 수 있습니다.

설정 › 입력·단축키는 알려진 실행 중 앱(ChatGPT·notype)의 저장된 조합과 Karabiner의 명확한 단순 규칙이 겹치면 경고를 표시합니다. 저장된 설정의 겹침은 해당 앱이 실제로 키를 선점했다는 증거는 아닙니다. 그 밖의 겹침은 단축키를 누를 때 다른 앱이 앞으로 나오는 것으로 드러날 수 있습니다. 한쪽 단축키를 바꿔 주세요.

받아쓰기 출력은 말한 언어 유지·영어·일본어·한국어 중에서 선택합니다. 별도 번역 단축키에는 중국어 간체/번체도 있습니다. 언어를 선택할 수 있다는 사실이 실제 품질 검증 완료를 뜻하지 않습니다.

## 사용할 수 있는 API 키

| 내 API 키 | 음성을 글로 바꾸는 단계 | 정리·번역·수정 단계 |
| --- | --- | --- |
| OpenAI | OpenAI에 직접 요청 | OpenAI에 직접 요청 |
| Groq | Groq에 직접 요청 | Groq에 직접 요청 |
| OpenRouter | OpenRouter를 통해 모델 공급자에 요청 | OpenRouter를 통해 모델 공급자에 요청 |
| Claude / Anthropic | 음성 API 없음 — 로컬 모델 또는 다른 음성 제공자 선택 | Anthropic에 직접 요청 |

음성 인식과 문장 정리의 제공자를 각각 선택할 수 있습니다. 예를 들어 **Groq 음성 인식 + OpenRouter 문장 정리**를 사용하면 두 서비스의 키를 각각 Keychain에 저장합니다. 같은 제공자라면 키 하나를 공유합니다. Claude는 문장 처리에 사용할 수 있으며, 음성은 다른 제공자의 API 또는 Mac의 로컬 모델로 인식합니다.

OpenRouter는 중개 서비스이므로 같은 모델을 선택해도 실제 처리 공급자가 달라질 수 있습니다. 특히 음성 전사 API는 채팅용 공급자 고정·대체 공급자 제한 설정을 적용하지 않으며, 이 앱은 특정 전사 공급자로의 고정을 보장하지 않습니다. [OpenRouter 공식 전사 안내](https://openrouter.ai/blog/tutorials/transcription-on-openrouter/)

Groq 음성 인식은 **설정 → AI 연결 → 음성 인식**에서 Groq와 모델을 선택하고 키를 저장합니다. **문장 정리**에서는 제공자와 모델, 필요한 경우 별도의 키를 선택합니다. 음성은 Whisper Large v3 Turbo / Large v3, 문장 정리는 GPT OSS 120B / 20B를 메뉴로 제공하며, 다른 모델 ID도 직접 입력할 수 있습니다. 모델 목록은 앱에 포함된 선택지이며 계정별 이용 권한을 조회한 결과는 아닙니다. 제공자를 바꿔도 기존 제공자의 키와 모델 설정은 유지됩니다.

OpenNoType 자체 회원가입이나 운영 서버는 없습니다. 선택한 제공자의 API 계정·모델 사용 권한·잔액은 필요합니다. ChatGPT나 Claude의 채팅 구독과 API 과금은 별도입니다. 로컬 음성 인식을 켜더라도 문장 처리에는 선택한 클라우드 API를 사용합니다.

기본 모델 이름은 앱에서 변경할 수 있습니다. 자세한 요청 방식과 제한은 [AI 제공자 문서](docs/ai-providers.md)를 참고하세요.

## 일반 사용자 설치

**Apple Silicon M1 이후, macOS 14 이상**을 지원합니다. [v0.2.3 GitHub Release](https://github.com/techjuicelab/opennotype/releases/tag/v0.2.3)에서 DMG를 내려받아 `OpenNoType.app`을 **Applications**에 복사해 실행하세요. 일반 설치에는 Xcode·Swift·Homebrew가 필요하지 않습니다. 클라우드 음성 인식을 선택하면 로컬 모델을 다운로드할 필요도 없습니다.

현재 공개 배포는 **커뮤니티 배포 · Apple 공증 없음**입니다. macOS가 실행을 차단하면 [Apple의 앱별 허용 절차](https://support.apple.com/102445)를 따르세요. 마이크·손쉬운 사용 권한과 필요한 API 키는 각 Mac에서 한 번 준비합니다. 앱을 교체한 뒤 Keychain 확인이 나타나면 직접 인증해 주세요.

[검증 후 설치하는 단독 스크립트와 첫 실행 안내](docs/mac-installation.md)를 제공합니다. [새 Mac 설치 기록](docs/reviews/2026-10-01/macbook-installation.md)과 [0.1.26 배포 검증](docs/reviews/2026-10-05/community-release-0.1.26.md)은 각 시점의 버전과 확인 범위를 기록한 자료입니다.

## 개발자 빌드와 실행

첫 지원 대상은 **macOS 14 이상, Apple Silicon M1 이후 Mac**입니다. Intel Mac·Windows·iPhone·Android용 빌드는 아직 제공하지 않습니다.

Swift 6을 제공하는 Xcode 또는 Command Line Tools를 준비합니다. 앱 빌드는 SwiftUI·Observation을 실제로 컴파일하는 SDK 사전 검사를 먼저 실행합니다. 기본 SDK가 실패하면 설치된 26.5 SDK를 검사하고, `MACOS_SDK_PATH`를 명시하면 그 SDK만 사용합니다. 전체 `swift test`에는 XCTest를 제공하는 Xcode가 필요합니다. 저장소를 받은 폴더에서 실행하세요.

```sh
./scripts/build-app.sh
open build/OpenNoType.app
```

이 스크립트는 arm64 앱을 만들고 로컬 개발용 임시 서명을 적용합니다. Developer ID 서명·공증을 마친 배포 파일을 만드는 명령은 아닙니다. 최적화한 로컬 빌드는 다음과 같습니다.

```sh
CONFIGURATION=release ./scripts/build-app.sh
```

1. **설정 → AI 연결**에서 음성 인식과 문장 정리의 제공자·모델을 각각 선택하고 필요한 API 키를 저장합니다. 키는 macOS Keychain에 보관합니다. ‘저장됨’은 실제 연결 검증과 별개이며, 바꾼 키는 저장해야 적용됩니다.
2. **마이크**와 **손쉬운 사용** 권한을 허용합니다. 마이크를 거부했다면 앱의 시스템 설정 열기 버튼으로 허용 상태를 바꿀 수 있습니다. 손쉬운 사용 권한이 없으면 녹음을 시작하지 않습니다.
3. 로컬 음성 인식을 선택했다면 **음성 모델**에서 처음 한 번 모델을 다운로드합니다. **시작하기**에서 필요한 모델·목소리 등록의 준비 상태를 확인할 수 있습니다.
4. **시작하기 → 입력 연습**을 준비한 뒤 원하는 입력창에서 받아쓰기 단축키를 누릅니다. 녹음·API 호출 없이 고정된 테스트 문장만 입력합니다.
5. 글을 입력할 앱의 입력창을 클릭한 뒤 단축키로 녹음을 시작합니다.

| 동작 | 기본 단축키 |
| --- | --- |
| 받아쓰기 | `⌥ Space` |
| 번역 | `⌥ ⇧ Space` |
| 선택 문장 수정 | `⌃ ⌥ Space` |

단축키를 다시 누르면 녹음을 마칩니다. 선택 문장 수정은 먼저 바꿀 문장을 선택해야 합니다. 단축키가 다른 앱과 충돌하면 설정에서 바꿀 수 있습니다.

**⌘,**로 설정을 엽니다. 설정은 **AI 연결 / 입력·단축키 / 개인정보 / Mac·일반**으로 나뉩니다. 시작하기에는 현재 사용할 음성·문장 모델이 표시되며, 메뉴바에서도 사용량 화면으로 바로 이동할 수 있습니다.

**설정 → 입력·단축키 → 받아쓰기 표현**에서 **현재 받아쓰기 / 간결하게 / 핵심 요약 / 명확하게 / 자세하게 / 창의적으로**를 선택하고 편집 강도를 **0~100**으로 조절합니다. 기본은 **현재 받아쓰기 · 강도 0**입니다. **예시 비교…**는 녹음·전송·API 호출 없이 고정 합성 예시를 보여 주며, 둘러보기와 닫기·Escape는 설정을 바꾸지 않습니다. 예시 창에서 **적용**을 누르면 다음 녹음부터 받아쓰기에만 적용됩니다. 번역·선택 문장 수정에는 적용하지 않으며, 실제 결과는 발화와 모델에 따라 달라집니다. 표현 설정 자체는 추가 API 요청을 만들지 않지만 토큰 비용은 달라질 수 있습니다.

**설정 → 입력·단축키**에서 받아쓰기 출력 언어와 별도 번역 단축키의 언어를 각각 선택합니다. 언어 예시를 둘러보는 동안 설정은 바뀌지 않으며 **적용**을 눌러 저장합니다. 번역에는 받아쓰기의 요약·창작 강도를 적용하지 않고 녹음 시작 당시 언어·말투를 사용합니다.

**설정 → AI 연결 → Jev 문장 검토**의 **입력 전 교정**은 말한 언어 유지 받아쓰기에 적용됩니다. 필요한 경우 같은 문장 모델로 한 번 교정하고 재검토를 통과한 결과만 입력하며 실패·시간 초과·미해결이면 보류합니다. 교정·재검토의 참고 단가 예약액은 US$0.05 이내로 제한하지만 실제 청구액을 보장하는 한도는 아닙니다. 말한 언어 유지 받아쓰기의 기존 **입력 전 보호**는 검토 실패·시간 초과에 기존 결과를 입력하고 미검토 상태를 표시합니다. **입력 후 검토·학습**은 이미 입력한 글을 바꾸지 않습니다. 번역·선택 수정은 직접 검토도 지원하며, 선택형 오류 유형 학습과 추가 도움 기능은 [Jev 안내](docs/jev-review.md)를 참고하세요.

번역을 자동 검토하려면 **입력 전 보호 → 번역도 입력 전에 검토**를 직접 켭니다. 기본 꺼짐인 실험 기능으로 원문·번역·목표 언어·선택 말투를 한 번 추가 전송해 시간과 비용이 늘어납니다. 모든 요청 항목의 위험 점수가 0.1 이하일 때만 입력하며, 점수는 실제 정확도로 보정된 확률이 아니므로 정상 번역도 보류할 수 있습니다. 실패·취소·보호 해제에서는 입력을 보류하고 원문으로 자동 대체하거나 번역을 자동 교정하지 않습니다. 보류 결과는 원문과 비교한 뒤 직접 복사하세요. [번역 설정과 검토 범위](docs/native-translation.md)를 참고하세요.

**사용량**에서 기간과 제공자별로 조회합니다. 이 Mac에서 기록 기능이 켜진 뒤의 요청부터 집계하며, 이전 기록이나 앱 밖에서 쓴 사용량은 가져오지 않습니다. 통계 기록은 기본으로 켜져 있고 **설정 → 개인정보**에서 문장 기록과 별도로 끌 수 있습니다. 숫자·모델 정보만 암호화해 최근 10,000건까지 보관합니다. 추정 비용은 실제 청구액과 다를 수 있으며, 미확인 금액을 0으로 표시하지 않습니다.

## 로컬 모델과 내 목소리 필터

기본 다국어 Whisper Large v3 모델의 가중치는 약 **627 MB**입니다. 토크나이저와 기기별 Core ML 캐시는 추가 공간을 사용합니다. 다운로드가 끝나도 첫 모델 준비에 시간이 더 걸릴 수 있습니다. 모델은 준비 버튼을 눌렀을 때 내려받습니다.

선택한 로컬 기능에 필요한 파일이 이미 있으면 앱 실행이나 해당 기능 사용 때 캐시만 읽어 준비합니다. 파일이 없거나 손상되었을 때 자동으로 다운로드하지 않으며, **음성 모델** 화면에서 다운로드·재준비를 시작해야 합니다. 준비 중에는 취소를 요청할 수 있습니다. Core ML 로딩처럼 즉시 중단되지 않는 작업이 있더라도 취소한 준비의 늦은 결과는 UI에 적용하지 않습니다.

실험 단계의 내 목소리 필터는 약 **14 MB**의 별도 모델을 사용하며 **기본적으로 꺼져 있습니다**. 필터를 사용하려면 자신의 목소리를 별도로 등록합니다. 등록 원음은 삭제하고 256차원 목소리 특징을 암호화 저장합니다.

이 필터는 등록한 목소리와 비슷한 단독 발화 구간을 남깁니다. **겹쳐 말하는 목소리를 분리하는 기능은 아닙니다.** TV나 타인의 말이 남거나 내 말이 빠질 수 있습니다. 합성 음성으로 구현 경로를 검사했지만 실제 사용자·TV·겹말 환경의 성능은 아직 검증하지 않았습니다. 본인 인증 기능으로 사용하지 않습니다.

구현 방식과 실증 범위는 [로컬 음성 문서](docs/local-audio.md)에 정리합니다.

| 내보낸 사전 JSON | 사용자가 선택한 위치에 표기 사전을 암호화하지 않은 파일로 저장합니다. |

교정 학습은 앱이 방금 입력한 텍스트만 같은 입력창에서 제한된 시간 동안 관찰합니다. 일반 키보드 입력 전체를 수집하는 방식은 아닙니다. 크거나 불확실한 문장 변경은 검토 대상으로 보여 주며 문장 전체를 자동으로 사전에 등록하지 않습니다.

자동 학습은 대소문자 교정, `OpenAI`처럼 내부 대문자가 있는 이름의 제한된 철자 교정, `GR5Q → GROQ`처럼 대문자 이름 안의 숫자 한 글자 오인식에 한정합니다. `Cat → Car` 같은 일반 단어 교체나 임의의 한글↔영문 변경은 자동 등록하지 않습니다. 검토 후보의 **표기 확인하고 등록**은 단어를 편집란에 넣을 뿐이며, 사용자가 표기를 확인하고 저장해야 등록됩니다. 공통 조사와 앞뒤의 동일 숫자는 후보에서 제외하므로 `아이폰15 → iPhone15`는 `아이폰 → iPhone`을 검토합니다. 버전·날짜·금액 변경과 한글 이름의 다른 한글 표기로의 교정은 직접 등록해야 합니다.

입력 완료가 확인된 받아쓰기 후 같은 입력창에서 최대 30초 동안 교정을 확인하며, 수정이 약 3초 유지되면 적격 교정을 학습합니다. 입력이나 수정 내용을 확인할 수 없는 앱은 직접 등록해야 합니다. **교정한 표기 자동 학습**은 기록 저장과 별도로 끌 수 있고, 끄면 새 교정을 관찰·등록하지 않으며 기존 사전은 유지합니다. 같은 앱 실행 중 마지막 자동 학습 한 건을 되돌릴 수 있습니다. 해당 항목을 이후에 변경했다면 되돌리기가 현재 내용을 덮어쓰지 않습니다. 검토 후보는 기록 저장을 켰을 때 마지막 한 건을 암호화해 보관하며 기록 보관 기간을 따릅니다.

저장소는 AES-GCM으로 암호화하고 임의 생성한 키를 Keychain에 보관합니다. 키가 없거나 파일 검증에 실패하면 기존 파일을 보존하며 저장을 중단합니다. 기록을 복원하려면 해당 Keychain 키도 필요합니다.

텍스트·사전 등의 메타데이터와 실패 녹음 음성을 별도 암호화 파일에 보관하므로 일반 기록 조회에서 녹음 전체를 읽지 않습니다. 이전 저장 형식은 유효한 실패 녹음을 새 파일로 쓰고 다시 검증한 뒤 메타데이터를 교체합니다. 중간에 실패하면 이전 저장소를 유지합니다. 기존 녹음은 마이그레이션 때 용량 때문에 삭제하지 않으며, 한도를 넘으면 새 녹음 저장을 거절합니다. 실패 녹음을 삭제하거나 만료될 때까지 기다린 뒤 다시 사용할 수 있습니다.

**같은 설정으로 다시 처리**는 녹음 당시 제공자·모델·인식 방식·필터·번역 언어를 사용합니다. **현재 설정으로 복구**는 확인한 현재 값으로 바꾸어 처리하므로 모델 오류나 필터 문제에서 벗어날 수 있습니다. 두 경로 모두 현재 개인 사전과 녹음 당시 작성 프로필을 사용하고, 원래 24시간 만료 시각을 늘리지 않습니다. 성공한 재처리의 음성은 삭제되며 결과는 자동 입력하지 않고 복사하도록 표시합니다.

이 로컬 보관 정책이 AI 제공자의 보관·학습·보안 정책을 대신 보장하지는 않습니다.

## 개발과 검증

```sh
scripts/macos-preflight.sh --tests
swift test --sdk "$(scripts/macos-preflight.sh --print-sdk)"
scripts/build-app.sh
```

일반 테스트에는 유료 API 키가 필요하지 않습니다. 제공자 테스트는 테스트용 전송 계층을 사용하고, 암호화 저장소 테스트는 실제 사용자의 Keychain 대신 독립적인 키 저장소를 사용합니다. 로컬 모델을 내려받는 통합 테스트는 [검증 문서](docs/verification.md)에서 별도로 설명합니다.

기록된 검증에는 실제 API를 사용한 합성 문장 정리·Jev 검토·교정, 일부 Mac 설치·언어 전환·외부 앱 붙여넣기, 버전별 자동 검사가 포함됩니다. [검증 상태](docs/verification.md), [0.1.26 예시 비교 검증](docs/reviews/2026-10-03/expression-example-preview.md), [0.1.26 공개 배포 검증](docs/reviews/2026-10-05/community-release-0.1.26.md)은 각 시점의 결과와 남은 범위를 구분합니다. 과거 버전의 통과 결과나 고정 합성 예시는 앱 전체의 실사용 품질을 보장하지 않습니다.

문제를 제보할 때 앱·macOS 버전, 하드웨어, 제공자·모델 이름, 재현 단계를 알려 주세요. 짧은 합성 예시를 사용하고 API 키·개인 녹음·사적인 문장을 올리지 마세요.

## 배포·검증 현황과 남은 작업

- 현재 커뮤니티 배포는 Developer ID·Apple 공증 없이 ad-hoc 앱 서명과 Sparkle Ed25519 서명을 사용합니다. Apple 자격을 준비하면 별도 공증 모드를 선택할 수 있으며 공증 실패 시 자동 전환하지 않습니다.
- 공개 다운로드는 **v0.2.3 (35)**이며 소스는 [v0.2.3 태그](https://github.com/techjuicelab/opennotype/tree/v0.2.3)에 있습니다. 피드·공개 키가 없는 기존 개발 설치본은 최초 1회 수동 설치가 필요합니다. 합성 시험 앱의 Sparkle 교체·변조 거부와 실제 제품의 업데이트·권한·Keychain 접근 유지는 별도 확인 범위입니다. [업데이트 운영 안내](docs/updates.md)를 참고하세요.
- 실제 API를 사용한 합성 시험과 일부 입력 검증은 기록되어 있습니다. 자연 발화부터 대상 앱 9개 입력까지의 전체 흐름, 다양한 사용자·기기·모델에서의 품질은 추가 검증이 필요합니다.
- 실제 사용자 목소리·TV·겹말 및 자연스러운 번역 평가.
- Windows·iPhone·Android 확장. 플랫폼별 권한과 입력 방식은 별도 구현이 필요합니다.

일반 질문 답변과 웹 검색은 첫 버전 범위에서 제외합니다. [공개 배포 패키징 스크립트](scripts/package-release.sh)와 [배포 가이드](docs/releasing.md)는 마련되어 있지만, 스크립트가 있다는 사실이 실제 공증 배포 완료를 뜻하지는 않습니다.
