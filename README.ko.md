# OpenNoType

**말은 편하게. 글은 또렷하게. 내 API 키로 쓰는 Mac 음성 입력.**

[English](README.md) · [검증 상태](docs/verification.md) · [라이선스](LICENSE)

OpenNoType은 MIT 라이선스의 macOS 음성 입력 앱입니다. 녹음을 시작하면 말을 글로 바꾸고, 선택한 AI 제공자가 추임새·불필요한 반복·명확한 자기수정을 정리한 뒤 커서 위치에 완성된 문장을 입력합니다. 원래 의미와 말투, 한 문장에 섞인 여러 언어의 표기를 보존하는 것이 목표입니다.

**현재는 개발 미리보기입니다.** 소스에서 앱을 빌드할 수 있지만 정식 배포와 실사용 검증을 모두 마친 상태는 아닙니다. 합성 문장 정리는 실제 API로 비교했으며, 자연 발화 품질과 대상 앱 9개의 전체 입력 흐름은 추가 검증이 필요합니다. 다른 제품과의 기능 동등성을 보장하지 않습니다.

이 **0.1.9 버전**은 기록의 원문·결과 각각 복사와 현재 설정을 사용하는 수동 재처리·사용량 기록을 추가합니다. 두 정리 브랜치와 개정 통합 후보를 비교한 뒤 기본 프롬프트는 Codex `233fd1f` 버전을 그대로 유지했습니다. 같은 합성 사례 9개에서 정리 통과는 Codex 7개, 개정 후보 6개였고 의미 보존은 둘 다 9개였습니다. 작은 표본의 결과이므로 일반적인 우위를 뜻하지 않습니다. 추가한 대조 명세와 평가 도구는 채택하고 후보 규칙은 실험 증거로 보존합니다. [Typeless 비교 기준](docs/typeless-comparison.md), [구현·검증 보고서](docs/reviews/2026-09-12/typeless-integration.md), [실제 모델 비교](docs/reviews/2026-09-12/faithful-cleanup-live-comparison.md)를 참고하세요.

**0.1.10 버전**은 업데이트 설정 화면과 서명·공증 검사를 포함한 GitHub Releases/Sparkle 배포 워크플로를 추가합니다. 정식 피드와 서명 키는 아직 설정하지 않아 자동 업데이트는 비활성 상태이며, 실제 업데이트 설치까지의 흐름도 검증 전입니다. [업데이트 설정·최초 설치 안내](docs/updates.md)를 참고하세요.

## 구현한 기능

- 받아쓰기, 번역, 선택한 문장을 음성 지시로 수정.
- 범용 표기 견본과 문맥 오인식 교정, 조사·문장 재구성. [견본과 기대 결과](docs/dictation-baseline.md).
- 앱별 작성 형식·말투 설정. 기본은 말한 반말·존댓말 유지.
- 변경 가능한 전역 단축키와 작은 녹음 막대.
- 포커스를 확인한 결과 삽입과 클립보드 대체 경로. 메시지 전송용 Enter는 누르지 않습니다.
- 최대 9분 녹음과 마지막 1분 카운트다운.
- 개인 사전 등록·수정·삭제, 제한된 교정 학습 켜기·끄기와 마지막 학습 되돌리기, JSON 가져오기·내보내기.
- 로컬 암호화 기록, 보관 기간 변경, 검색, 원문·결과 비교와 각각 복사, 받아쓰기·번역 수동 재처리, 개별/전체 삭제.
- 모델별 요청 횟수·음성 길이·토큰·일별 활동과 사용 비용. 공급자 보고 금액·추정 금액·미확인을 구분합니다. [집계 기준](docs/usage.md).
- 최대 24시간 보관하는 암호화 실패 녹음과 재처리. 같은 설정 또는 현재 설정으로 복구할 수 있으며, 선택 문장 수정의 재처리에는 원문을 다시 입력합니다.
- 선택적으로 사용하는 로컬 음성 인식과 실험 단계의 내 목소리 필터.

자동 입력은 모든 앱에서 ⌘V 붙여넣기를 먼저 사용합니다. 붙여넣기는 키 입력을 받는 모든 앱(터미널, Electron 편집기, 노트 앱, 브라우저)에 닿지만, 손쉬운 사용 API 직접 쓰기는 많은 앱이 성공을 보고하면서도 화면에 반영하지 않기 때문입니다. 클립보드를 보존할 수 없거나 키 이벤트를 만들 수 없거나 원래 앱을 앞으로 가져오지 못한 경우에만 손쉬운 사용 쓰기로 대신하며, 이미 보낸 붙여넣기 뒤에 손쉬운 사용 쓰기를 겹쳐 보내지 않습니다. Electron 기반 편집기·브라우저·터미널은 손쉬운 사용 대체 없이 붙여넣기만 사용합니다. 붙여넣기에 쓴 클립보드 내용은 입력 확인 뒤 원래대로 복원하고, 클립보드 관리자가 기록하지 않도록 임시 항목으로 표시합니다. 대상 앱에 글을 전달하지 못한 경우에는 복사할 수 있도록 결과를 보여 주고, 전달했지만 확인하지 못한 경우는 조용한 알림으로 표시합니다.

처리 중 다른 앱이 앞으로 나왔다면 글을 쓰던 앱으로 먼저 돌아갑니다. 선택 문장 수정은 반영 직전에 원래 입력란·전체 텍스트·선택 범위가 그대로인지 다시 확인하며, 달라졌거나 읽어 확인할 수 없으면 자동 입력을 멈춥니다. 받아쓰기·번역은 같은 앱의 다른 입력란으로 커서를 옮겼을 때 현재 입력란에 붙여넣을 수 있습니다.

설정 › 입력·단축키는 알려진 실행 중 앱이 같은 단축키를 저장해 두었을 때(현재는 ChatGPT 채팅 바의 ⌥Space) 경고를 표시합니다. 그 밖의 겹침은 단축키를 누를 때 다른 앱이 앞으로 나오는 것으로 드러날 수 있습니다. 한쪽 단축키를 바꿔 주세요.

번역 대상은 한국어·영어·일본어·중국어 간체/번체입니다. 한국어↔영어 품질을 먼저 평가하며, 언어를 선택할 수 있다는 사실이 실제 품질 검증 완료를 뜻하지 않습니다.

## 사용할 수 있는 API 키

| 내 API 키 | 음성을 글로 바꾸는 단계 | 정리·번역·수정 단계 |
| --- | --- | --- |
| OpenAI | OpenAI에 직접 요청 | OpenAI에 직접 요청 |
| Groq | Groq에 직접 요청 | Groq에 직접 요청 |
| OpenRouter | OpenRouter를 통해 모델 공급자에 요청 | OpenRouter를 통해 모델 공급자에 요청 |
| Claude / Anthropic | Mac의 로컬 Whisper 모델 | Anthropic에 직접 요청 |

OpenAI·Groq·OpenRouter는 해당 서비스의 API 키 하나로 두 단계를 처리합니다. Claude는 먼저 Mac에서 음성을 인식하므로 별도 음성 API 키가 필요하지 않습니다. 다른 제공자를 사용할 때도 로컬 음성 인식을 켤 수 있습니다.

OpenRouter는 중개 서비스이므로 같은 모델을 선택해도 실제 처리 공급자가 달라질 수 있습니다. 특히 음성 전사 API는 채팅용 공급자 고정·대체 공급자 제한 설정을 적용하지 않으며, 이 앱은 특정 전사 공급자로의 고정을 보장하지 않습니다. [OpenRouter 공식 전사 안내](https://openrouter.ai/blog/tutorials/transcription-on-openrouter/)

Groq는 **설정 → AI 연결 → Groq**에서 키를 저장한 뒤 음성 인식 모델과 문장 정리 모델을 각각 선택합니다. 음성은 Whisper Large v3 Turbo / Large v3, 문장 정리는 GPT OSS 120B / 20B를 메뉴로 제공하며, 다른 모델 ID도 직접 입력할 수 있습니다. 모델 목록은 앱에 포함된 선택지이며 계정별 이용 권한을 조회한 결과는 아닙니다. 제공자를 바꿔도 기존 제공자의 키와 모델 설정은 유지됩니다.

OpenNoType 자체 회원가입이나 운영 서버는 없습니다. 선택한 제공자의 API 계정·모델 사용 권한·잔액은 필요합니다. ChatGPT나 Claude의 채팅 구독과 API 과금은 별도입니다. 로컬 음성 인식을 켜더라도 문장 처리에는 선택한 클라우드 API를 사용합니다.

기본 모델 이름은 앱에서 변경할 수 있습니다. 자세한 요청 방식과 제한은 [AI 제공자 문서](docs/ai-providers.md)를 참고하세요.

## 빌드와 실행

첫 지원 대상은 **macOS 14 이상, Apple Silicon M1 이후 Mac**입니다. Intel Mac·Windows·iPhone·Android용 빌드는 아직 제공하지 않습니다.

Swift 6을 제공하는 Xcode 또는 Command Line Tools를 준비합니다. 기록된 개발 도구 모음은 Swift 6.3.3입니다. 저장소를 받은 폴더에서 실행하세요.

```sh
./scripts/build-app.sh
open build/OpenNoType.app
```

이 스크립트는 arm64 앱을 만들고 로컬 개발용 임시 서명을 적용합니다. Developer ID 서명·공증을 마친 배포 파일을 만드는 명령은 아닙니다. 최적화한 로컬 빌드는 다음과 같습니다.

```sh
CONFIGURATION=release ./scripts/build-app.sh
```

1. **설정**에서 AI 제공자를 선택하고 API 키를 저장합니다. 키는 macOS Keychain에 보관합니다. ‘저장됨’은 실제 연결 검증과 별개이며, 바꾼 키는 저장해야 적용됩니다.
2. **마이크**와 **손쉬운 사용** 권한을 허용합니다. 마이크를 거부했다면 앱의 시스템 설정 열기 버튼으로 허용 상태를 바꿀 수 있습니다. 손쉬운 사용 권한이 없으면 녹음을 시작하지 않습니다.
3. Claude나 로컬 인식을 사용한다면 **음성 모델**에서 처음 한 번 모델을 다운로드합니다. **시작하기**에서 필요한 모델·목소리 등록의 준비 상태를 확인할 수 있습니다.
4. **시작하기 → 입력 연습**을 준비한 뒤 원하는 입력창에서 받아쓰기 단축키를 누릅니다. 녹음·API 호출 없이 고정된 테스트 문장만 입력합니다.
5. 글을 입력할 앱의 입력창을 클릭한 뒤 단축키로 녹음을 시작합니다.

| 동작 | 기본 단축키 |
| --- | --- |
| 받아쓰기 | `⌥ Space` |
| 번역 | `⌥ ⇧ Space` |
| 선택 문장 수정 | `⌃ ⌥ Space` |

단축키를 다시 누르면 녹음을 마칩니다. 선택 문장 수정은 먼저 바꿀 문장을 선택해야 합니다. 단축키가 다른 앱과 충돌하면 설정에서 바꿀 수 있습니다.

**⌘,**로 설정을 엽니다. 설정은 **AI 연결 / 입력·단축키 / 개인정보 / Mac·일반**으로 나뉩니다. 시작하기에는 현재 사용할 음성·문장 모델이 표시되며, 메뉴바에서도 사용량 화면으로 바로 이동할 수 있습니다.

**사용량**에서 기간과 제공자별로 조회합니다. 이 Mac에서 기록 기능이 켜진 뒤의 요청부터 집계하며, 이전 기록이나 앱 밖에서 쓴 사용량은 가져오지 않습니다. 통계 기록은 기본으로 켜져 있고 **설정 → 개인정보**에서 문장 기록과 별도로 끌 수 있습니다. 숫자·모델 정보만 암호화해 최근 10,000건까지 보관합니다. 추정 비용은 실제 청구액과 다를 수 있으며, 미확인 금액을 0으로 표시하지 않습니다.

## 로컬 모델과 내 목소리 필터

기본 다국어 Whisper Large v3 모델의 가중치는 약 **627 MB**입니다. 토크나이저와 기기별 Core ML 캐시는 추가 공간을 사용합니다. 다운로드가 끝나도 첫 모델 준비에 시간이 더 걸릴 수 있습니다. 모델은 준비 버튼을 눌렀을 때 내려받습니다.

선택한 로컬 기능에 필요한 파일이 이미 있으면 앱 실행이나 해당 기능 사용 때 캐시만 읽어 준비합니다. 파일이 없거나 손상되었을 때 자동으로 다운로드하지 않으며, **음성 모델** 화면에서 다운로드·재준비를 시작해야 합니다. 준비 중에는 취소를 요청할 수 있습니다. Core ML 로딩처럼 즉시 중단되지 않는 작업이 있더라도 취소한 준비의 늦은 결과는 UI에 적용하지 않습니다.

실험 단계의 내 목소리 필터는 약 **14 MB**의 별도 모델을 사용하며 **기본적으로 꺼져 있습니다**. 필터를 사용하려면 자신의 목소리를 별도로 등록합니다. 등록 원음은 삭제하고 256차원 목소리 특징을 암호화 저장합니다.

이 필터는 등록한 목소리와 비슷한 단독 발화 구간을 남깁니다. **겹쳐 말하는 목소리를 분리하는 기능은 아닙니다.** TV나 타인의 말이 남거나 내 말이 빠질 수 있습니다. 합성 음성으로 구현 경로를 검사했지만 실제 사용자·TV·겹말 환경의 성능은 아직 검증하지 않았습니다. 본인 인증 기능으로 사용하지 않습니다.

구현 방식과 실증 범위는 [로컬 음성 문서](docs/local-audio.md)에 정리합니다.

## 개인정보와 보관

| 데이터 | 처리 방식 |
| --- | --- |
| API 키 | macOS Keychain에 저장하고 선택한 제공자의 인증에 사용합니다. |
| 녹음 음성 | 클라우드 인식이면 선택한 음성 제공자에게 보냅니다. 로컬 인식이면 Mac에서 처리합니다. |
| 전사문과 개인 사전 | 정리·번역·수정을 위해 선택한 텍스트 제공자에게 보냅니다. |
| 수정할 원문 | 선택 문장 수정에 사용해 제공자에게 보내며, 선택 원문이나 주변 문맥을 별도 기록으로 보관하지 않습니다. |
| 작성 방식 | 선택된 형식·말투 값(예: `development` / `preserve`)만 문장 처리 요청에 함께 보냅니다. 글을 쓰는 앱의 이름이나 번들 식별자는 보내지 않습니다. |
| 음성 인식 힌트 | 개인 사전 표기 최대 24개(개발 프로필에서는 고정 개발 용어 7개 추가)를 전사문 형식의 prompt로 클라우드 음성 제공자에게 보냅니다. 문맥을 이해하는 OpenAI 모델(`gpt-transcribe`, `gpt-4o-transcribe`, `gpt-4o-mini-transcribe`)에는 고정 참고 문장과 한 줄 상황 설명도 함께 보냅니다. 로컬 Whisper는 아무것도 보내지 않습니다. |
| 커서 문맥 | 기본 꺼짐, 앱별 허용. 커서 앞 최대 1,000자만 보내고 기록에 저장하지 않습니다. |
| 기록 | 처음 인식한 글과 최종 결과를 암호화해 기본 30일 보관합니다. 직접 삭제할 때까지 계속 보관할 수도 있고, 새 기록 저장을 별도로 끌 수도 있습니다. |
| 사용량 통계 | 요청·모델·토큰·음성 길이·비용 정보만 암호화해 최근 10,000건까지 보관합니다. 문장 기록과 별도이며 통계에는 문장·원음·API 키를 넣지 않습니다. |
| 실패 녹음 | 음성 파일별 로컬 암호화 보관, 24시간 만료. 신규 저장은 파일당 25 MB·전체 100 MB 한도를 적용하며 암호화 부가 공간도 포함합니다. 앱 실행 중 1분마다, 시작 및 저장소 접근 때 정리합니다. 앱이 꺼져 있으면 다음 실행 때 정리합니다. |
| 성공 녹음·등록 원음 | 각각의 처리·등록 경로를 마치면 임시 녹음을 삭제합니다. |
| 목소리 특징 | 앱에서 삭제할 때까지 로컬 암호화 저장소에 보관합니다. |
| 내보낸 사전 JSON | 사용자가 선택한 위치에 표기 사전을 암호화하지 않은 파일로 저장합니다. |

교정 학습은 앱이 방금 입력한 텍스트만 같은 입력창에서 제한된 시간 동안 관찰합니다. 일반 키보드 입력 전체를 수집하는 방식은 아닙니다. 크거나 불확실한 문장 변경은 검토 대상으로 보여 주며 문장 전체를 자동으로 사전에 등록하지 않습니다.

자동 학습은 대소문자 교정, `OpenAI`처럼 내부 대문자가 있는 이름의 제한된 철자 교정, `GR5Q → GROQ`처럼 대문자 이름 안의 숫자 한 글자 오인식에 한정합니다. `Cat → Car` 같은 일반 단어 교체나 임의의 한글↔영문 변경은 자동 등록하지 않습니다. 검토 후보의 **표기 확인하고 등록**은 단어를 편집란에 넣을 뿐이며, 사용자가 표기를 확인하고 저장해야 등록됩니다. 공통 조사와 앞뒤의 동일 숫자는 후보에서 제외하므로 `아이폰15 → iPhone15`는 `아이폰 → iPhone`을 검토합니다. 버전·날짜·금액 변경과 한글 이름의 다른 한글 표기로의 교정은 직접 등록해야 합니다.

입력 완료가 확인된 받아쓰기 후 같은 입력창에서 최대 30초 동안 교정을 확인하며, 수정이 약 3초 유지되면 적격 교정을 학습합니다. 입력이나 수정 내용을 확인할 수 없는 앱은 직접 등록해야 합니다. **교정한 표기 자동 학습**은 기록 저장과 별도로 끌 수 있고, 끄면 새 교정을 관찰·등록하지 않으며 기존 사전은 유지합니다. 같은 앱 실행 중 마지막 자동 학습 한 건을 되돌릴 수 있습니다. 해당 항목을 이후에 변경했다면 되돌리기가 현재 내용을 덮어쓰지 않습니다. 검토 후보는 기록 저장을 켰을 때 마지막 한 건을 암호화해 보관하며 기록 보관 기간을 따릅니다.

저장소는 AES-GCM으로 암호화하고 임의 생성한 키를 Keychain에 보관합니다. 키가 없거나 파일 검증에 실패하면 기존 파일을 보존하며 저장을 중단합니다. 기록을 복원하려면 해당 Keychain 키도 필요합니다.

텍스트·사전 등의 메타데이터와 실패 녹음 음성을 별도 암호화 파일에 보관하므로 일반 기록 조회에서 녹음 전체를 읽지 않습니다. 이전 저장 형식은 유효한 실패 녹음을 새 파일로 쓰고 다시 검증한 뒤 메타데이터를 교체합니다. 중간에 실패하면 이전 저장소를 유지합니다. 기존 녹음은 마이그레이션 때 용량 때문에 삭제하지 않으며, 한도를 넘으면 새 녹음 저장을 거절합니다. 실패 녹음을 삭제하거나 만료될 때까지 기다린 뒤 다시 사용할 수 있습니다.

**같은 설정으로 다시 처리**는 녹음 당시 제공자·모델·인식 방식·필터·번역 언어를 사용합니다. **현재 설정으로 복구**는 확인한 현재 값으로 바꾸어 처리하므로 모델 오류나 필터 문제에서 벗어날 수 있습니다. 두 경로 모두 현재 개인 사전과 녹음 당시 작성 프로필을 사용하고, 원래 24시간 만료 시각을 늘리지 않습니다. 성공한 재처리의 음성은 삭제되며 결과는 자동 입력하지 않고 복사하도록 표시합니다.

이 로컬 보관 정책이 AI 제공자의 보관·학습·보안 정책을 대신 보장하지는 않습니다.

## 개발과 검증

```sh
swift test
swift build --product OpenNoType
```

일반 테스트에는 유료 API 키가 필요하지 않습니다. 제공자 테스트는 테스트용 전송 계층을 사용하고, 암호화 저장소 테스트는 실제 사용자의 Keychain 대신 독립적인 키 저장소를 사용합니다. 로컬 모델을 내려받는 통합 테스트는 [검증 문서](docs/verification.md)에서 별도로 설명합니다.

문제를 제보할 때 앱·macOS 버전, 하드웨어, 제공자·모델 이름, 재현 단계를 알려 주세요. 짧은 합성 예시를 사용하고 API 키·개인 녹음·사적인 문장을 올리지 마세요.

## 정식 배포 전 남은 작업

- Developer ID 서명과 공증.
- Sparkle 업데이트 피드와 서명 키 설정. 현재 개발 빌드의 자동 업데이트는 비활성 상태입니다.
- 실제 유료 API 호출과 대상 앱 9개의 전체 입력 흐름 검증.

- Windows·iPhone·Android 확장. 플랫폼별 권한과 입력 방식은 별도 구현이 필요합니다.
